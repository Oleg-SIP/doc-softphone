---
title: Glossary
sidebar_position: 99
description: The terms of IP telephony and of AI Softphone used in this documentation, in one place.
---

| Term | Meaning |
| --- | --- |
| **Account** | A line: a SIP username on a PBX or with a provider. You can be signed in on several. See [Setting up a SIP account](/sip-accounts/setup). |
| **Assistant** | What the prompter is asked to be while it listens: subtitles, a translation, or suggestions for what to say. See [Prompter](/ai-processing/prompter#assistants). |
| **BLF** (Busy Lamp Field) | A button that dials an extension and shows by a lamp whether it is free, ringing or busy. See [Buttons](/sip-accounts/buttons). |
| **Call waiting** | What the phone does when somebody rings while you are already on a call. See [Calls settings](/sip-accounts/calls#call-waiting). |
| **Capture** | Recording a conversation held in another application, such as Zoom, Teams or Meet. See [Capture](/capture/). |
| **Category** | What a conversation was about; one per conversation. See [Dictionaries](/ai-processing/dictionaries). |
| **Codec** | The way the voice is encoded for the line. The phone offers a list of them and the other end picks one. See [Calls settings](/sip-accounts/calls#audio-formats). |
| **Conference** | Calls joined into one. |
| **CTI** | Computer telephony integration: a program on the computer placing and watching calls. See [Local REST API](/integration/rest-api). |
| **DTMF** | The tones of the keypad, sent during a call. |
| **Extension** | The internal number of a person or a device on a PBX. |
| **IP PBX** | The telephone exchange of an office, running on a network; also called a softswitch. |
| **Language model** | The AI that reads a transcript and writes about it. See [Processing](/ai-processing/processing). |
| **Prompt** | What a language model is asked. See [Personal Prompt Studio](/ai-processing/prompt-studio). |
| **Prompter** | A window that shows what is said during a call as it is said, and suggestions for what to answer. See [Prompter](/ai-processing/prompter). |
| **Recogniser** | The service that turns audio into text (speech recognition). See [Transcription](/ai-processing/transcription). |
| **Red flag** | A thing in a conversation that needs attention, with the evidence and the time. See [Dictionaries](/ai-processing/dictionaries#red-flags). |
| **Rehearsal** | Playing a recorded conversation into the prompter instead of a call, to try an assistant out. See [Prompter](/ai-processing/prompter#rehearsing-on-a-recording). |
| **Registration** | The phone telling the PBX where it is, so that calls reach it. A green dot on the account means it is registered. |
| **Rule** | A step that runs by itself, in order, on every conversation. See [Processing](/ai-processing/processing#rules). |
| **SIP** | The protocol phones and PBXs use to set up calls. |
| **Tag** | A label; several may be true of one conversation. See [Dictionaries](/ai-processing/dictionaries#tags). |
| **Token** | Two things: the **Token** of the local API, a password for other programs; and the tokens a language model counts, the unit of the monthly **Token limit**. |
| **Transcript** | A conversation as text, turn by turn, in step with the audio. |
| **Webhook** | A request the phone sends to another system when a call starts, changes or ends. See [Webhooks](/integration/webhooks). |
| **Wideband** | A codec with a wider range of sound than a phone line has, so the voice is clearer. |
