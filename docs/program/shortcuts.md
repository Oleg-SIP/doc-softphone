**Settings → Shortcuts** lists the keyboard shortcuts of the phone.

<Shot name="16_settings_shortcuts" alt="Settings → Keyboard shortcuts" />

| Action | Shortcut on macOS | **Everywhere** |
| --- | --- | --- |
| **Answer a call** | ⌃⌥A | off |
| **Hang up** | ⌃⌥E | off |
| **Hold or resume** | ⌃⌥H | off |
| **Mute the microphone** | ⌃⌥M | off |
| **Show or hide the phone** | ⌃⌥S | on |

(⌃ is Control and ⌥ is Option.)

## Changing a shortcut

Click the shortcut and press the new combination. Clicking it again, or pressing Escape, clears it.

**Everywhere** is a check box next to each one. Off, the shortcut works while the phone is the program you are using. On, it works from any program: *it takes the combination from the rest of the desktop*, so other programs no longer get it. Only **Show or hide the phone** is global by default, because it has to bring the phone up from wherever you are.

**Restore defaults** puts all five back.
