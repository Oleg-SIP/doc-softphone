**Settings → Startup** decides how the program starts, what closing its window does, and what happens when you click a phone number in another program.

<Shot name="15_settings_startup" alt="Settings → Startup" />

## Autostart

| Setting | Default | What it does |
| --- | --- | --- |
| **Start the phone when I log in** | off | Starts the program with your session, so it takes calls from the moment you sit down. |
| **Start minimized, without a window** | off | Starts it without showing a window. Available only with the setting above. |

## Close

**Keep the phone running when the window is closed**, on by default. A closed window is not a hung-up phone: calls still arrive, and the icon in the notification area (the menu bar on macOS) brings the window back. Turn this off and closing the window quits the program.

## Call links

A link that starts with `tel:`, `callto:` or `sip:` — a phone number on a web page, in an email or in a CRM — can be opened by this program.

- **Open call links with this phone** makes the program the one that opens them. The button is grey when it already is.
- **Call straight away, without pressing Call** — off by default. A clicked number arrives in the dialler and waits there; turn this on to ring it the moment it arrives.
