The write-up of a conversation is made by prompts. The program comes with eleven, and you can change them in plain language, duplicate them and add your own. They are listed under **Prompts** in [Settings → Processing](processing.md).

## The prompts that come with the program

| Prompt | What it writes |
| --- | --- |
| **Summary** | The main points, decisions and next steps in one short paragraph. |
| **One-line summary** | A short title to recognise the conversation in a list. |
| **Action items** | Who agreed to do what, and when, with the words they said. |
| **Topics** | The subjects that were covered, in a few words. |
| **Names and numbers** | People, companies, dates, amounts and references. |
| **Category** | Files the conversation under one of your [categories](dictionaries.md). |
| **Tags** | Puts your [tags](dictionaries.md) on it, so it can be found later. |
| **Red flags** | Problems, with the evidence and the time in the conversation. |
| **A question about this call** | Answers a question you ask about one conversation, from its transcript. |
| **Sales quality** | Reviews the conversation against sales criteria you can edit. |
| **Support quality** | Judges how well the problem was understood and handled. |

## Making it yours

- Change what a prompt asks, in plain language.
- Duplicate a prompt to try a variant.
- Choose the model for each prompt — on your own machine or in the cloud.
- Set the order in which prompts run, switch them on and off, and make them conditional: for example, a sales review runs only on calls filed as **Sales**.
- Keep your own categories, tags and red flags in [Dictionaries](dictionaries.md).
- Cap the cost with the [monthly limits](processing.md#limits).

The original prompts can be restored from **Settings**.
