**Contacts** and **History** open in the same window, **Contacts and calls**, as two tabs. The window stands beside the phone, so you can look a number up while you talk.

![Contacts](https://ai-softphone.com/screenshots/macos/en/light/directory.png)

## Contacts

- **Search** filters the list as you type.
- **Add** creates a contact.
- Each contact is listed with a name and a number. An incoming call from a known number shows the contact's name — that is how caller ID matching works.

## History

The call log, newest first. It shows incoming, outgoing, missed and declined calls. Missed and declined calls can also be read through the [local REST API](../integration/rest-api.md) (`/history?missed=true`, `/history?declined=true`).
