**Settings** opens a window with a list of tabs on the left. The tabs are in groups separated by lines.

| Group | Tab | What is in it |
| --- | --- | --- |
| Telephony | **Accounts** | SIP accounts: [Setting up a SIP account](../sip-accounts/setup.md) |
| | **Devices** | [Microphone, speakers, ringtone and other sounds](../sip-accounts/devices.md) |
| | **Calls** | Call behaviour and the priority of the codecs |
| | **Buttons** | Buttons that follow other extensions (BLF) |
| | **Recording** | Recording of calls |
| | **Capture** | [External recording](../external-recording/setup.md) of meetings held in other applications |
| AI | **Processing** | [Automatic processing, spending limits, language models and prompts](../ai-processing/processing.md) |
| | **Transcription** | [Recognisers](../ai-processing/transcription.md) |
| | **Dictionaries** | [Categories, tags and red flags](../ai-processing/dictionaries.md) |
| Program | **Appearance** | The language of the interface and the theme (light or dark); they change without a restart |
| | **Startup** | How the program starts |
| | **Shortcuts** | Hotkeys |
| | **Integration** | [Local REST API and webhooks](../integration/rest-api.md) |
| | **Diagnostics** | The diagnostics level; see [Diagnostics](../troubleshooting/diagnostics.md) |
| | **Modules** | Optional parts of the program |

:::note
The tabs **Calls**, **Buttons**, **Recording**, **Capture**, **Appearance**, **Startup**, **Shortcuts** and **Modules** are not described in detail yet.
:::
