**Asetukset → Moduulit** luettelee ohjelman osat. *Kaikki, mitä tämä puhelin tekee, on jokin näistä.* Yhden kytkeminen pois tulee voimaan heti ja jättää sen, mitä se on jo tallentanut, paikoilleen.

<Shot name="19_settings_modules" alt="Asetukset → Moduulit" />

Jokaisella moduulilla on valintaruutu, nimi, rivi siitä, mitä se tekee, ja oikealla sen tila — **Käynnissä** käytössä olevalle moduulille. Niiden kahden moduulin, joista muut riippuvat, **Sovellus** ja **Paikallinen tietokanta**, valintaruudut ovat harmaita: niitä ei voi poistaa käytöstä.

<Shot name="19b_settings_modules_scrolled" alt="Asetukset → Moduulit: luettelon loppuosa" />

| Moduuli | Mikä se on |
| --- | --- |
| **Sovellus** | Pääikkuna, asetukset, kuvakkeet ja niin edelleen. |
| **Paikallinen tietokanta** | Paikallisena tallennustilana käytetty tietokanta. |
| **Selainkäyttöliittymä** | Joitakin toimintoja paikallisessa selaimessa: [REST API:n](/integration/rest-api) sivut. |
| **Painikkeet** | Numeronvalitsimen vieressä olevat [painikkeet](/sip-accounts/buttons) ja niiden merkkivalot. |
| **Kaappaus** | Toisessa sovelluksessa käytävän [keskustelun tallentaminen](/capture/). |
| **Diagnostiikka** | SIP-jäljitys, mediatilastot ja laskurit: [Diagnostiikka](/troubleshooting/diagnostics). |
| **Sanastot** | Luokat, tunnisteet ja merkit — koodit, joihin kaikki muu viittaa: [Sanastot](/ai-processing/dictionaries). |
| **Hakemisto** | Osoitekirja: [Yhteystiedot](/interface/contacts-history). |
| **Integraatio** | Paikallinen API ja webhookit: [Integraatio](/integration/rest-api). |
| **Mediavarasto** | Keskustelujen kirjasto ja niiden säilytysaika: [Tallenteet](/recordings/recordings-window). |
| **Käsittely** | Kehotteet ja niitä laukaisevat säännöt: [Käsittely](/ai-processing/processing). |
| **Tallennus** | Puheluiden tallentaminen ja siitä kertominen toiselle osapuolelle: [Puheluiden tallentaminen](/recordings/call-recording). |
| **Puhelinliikenne** | SIP, tilit, puhelut, numeronvalitsin ja puheluhistoria. |
| **Litterointi** | Tunnistimet, niitä ohjaava jono ja niiden tuottamat litteroinnit: [Litterointi](/ai-processing/transcription). |

Poista moduuli käytöstä, niin se on poissa: ei asetuksia, ei valikkokohtaa, eikä mitään siitä ole käynnissä. Poista käytöstä moduuli, jota et tarvitse — esimerkiksi **Integraatio** tietokoneella, jossa mikään muu ei keskustele puhelimen kanssa — tai pidä puhelin, joka on pelkkä puhelin, kun työpiste ei muuta tarvitse. Paketti on sama kummassakin tapauksessa: ei ole mitään ostettavaa eikä mitään avattavaa.
