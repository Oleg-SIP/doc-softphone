title: Pojmovnik

description: Pojmovi IP telefonije i AI Softphonea korišteni u ovoj dokumentaciji, na jednom mjestu.
---

| Pojam | Značenje |
| --- | --- |
| **Račun** | Linija: SIP korisničko ime na centrali ili kod operatera. Možete biti prijavljeni na više njih. Pogledajte [Postavljanje SIP računa](/sip-accounts/setup). |
| **BLF** (Busy Lamp Field) | Gumb koji bira interni broj i lampicom pokazuje je li slobodan, zvoni ili je zauzet. Pogledajte [Gumbi](/sip-accounts/buttons). |
| **Poziv na čekanju** | Što telefon radi kad vas netko nazove dok ste već u razgovoru. Pogledajte [Postavke poziva](/sip-accounts/calls#call-waiting). |
| **Hvatanje** | Snimanje razgovora održanog u drugoj aplikaciji, poput Zooma, Teamsa ili Meeta. Pogledajte [Hvatanje](/capture/). |
| **Kategorija** | O čemu je bio razgovor; jedna po razgovoru. Pogledajte [Rječnici](/ai-processing/dictionaries). |
| **Kodek** | Način na koji se glas kodira za liniju. Telefon nudi njihov popis, a druga strana bira jedan. Pogledajte [Postavke poziva](/sip-accounts/calls#audio-formats). |
| **Konferencija** | Pozivi spojeni u jedan. |
| **CTI** | Integracija računala i telefonije: program na računalu upućuje i prati pozive. Pogledajte [Lokalni REST API](/integration/rest-api). |
| **DTMF** | Tonovi tipkovnice koji se šalju tijekom poziva. |
| **Interni broj** | Unutarnji broj osobe ili uređaja na centrali. |
| **IP centrala** | Telefonska centrala ureda koja radi u mreži; zove se i softswitch. |
| **Jezični model** | Umjetna inteligencija koja čita prijepis i piše o njemu. Pogledajte [Obrada](/ai-processing/processing). |
| **Uputa** | Ono što se traži od jezičnog modela. Pogledajte [Personal Prompt Studio](/ai-processing/prompt-studio). |
| **Prepoznavač** | Usluga koja zvuk pretvara u tekst (prepoznavanje govora). Pogledajte [Prijepis](/ai-processing/transcription). |
| **Upozoravajući signal** | Nešto u razgovoru što traži pozornost, s dokazom i vremenom. Pogledajte [Rječnici](/ai-processing/dictionaries#red-flags). |
| **Registracija** | Telefon javlja centrali gdje je, kako bi pozivi do njega stigli. Zelena točka uz račun znači da je registriran. |
| **Pravilo** | Korak koji se izvodi sam, redom, na svakom razgovoru. Pogledajte [Obrada](/ai-processing/processing#rules). |
| **SIP** | Protokol kojim telefoni i centrale uspostavljaju pozive. |
| **Oznaka** | Naljepnica; na jedan razgovor ih može vrijediti više. Pogledajte [Rječnici](/ai-processing/dictionaries#tags). |
| **Token** | Dvije stvari: **Token** lokalnog API-ja, lozinka za druge programe; i tokeni koje broji jezični model, jedinica mjesečne **Granice tokena**. |
| **Prijepis** | Razgovor kao tekst, replika po replika, usklađen sa zvukom. |
| **Webhook** | Zahtjev koji telefon šalje drugom sustavu kad poziv počne, promijeni se ili završi. Pogledajte [Webhookovi](/integration/webhooks). |
| **Širokopojasni** | Kodek sa širim rasponom zvuka nego što ga ima telefonska linija, pa je glas jasniji. |
