**Postavke → Moduli** navodi dijelove programa. *Sve što ovaj telefon radi jedan je od njih.* Isključivanje jednoga djeluje odmah i ostavlja na mjestu ono što je već spremio.

<Shot name="19_settings_modules" alt="Postavke → Moduli" />

Svaki modul ima potvrdni okvir, naziv, redak o tome što radi, a desno svoje stanje — **Radi** za uključeni modul. Potvrdni okviri dvaju modula o kojima ostali ovise, **Aplikacija** i **Lokalna baza podataka**, sivi su: ne mogu se isključiti.

<Shot name="19b_settings_modules_scrolled" alt="Postavke → Moduli: ostatak popisa" />

| Modul | Što je |
| --- | --- |
| **Aplikacija** | Glavni prozor, postavke, ikone i tako dalje. |
| **Lokalna baza podataka** | Baza podataka koja se koristi kao lokalno spremište. |
| **Sučelje u pregledniku** | Neke značajke u lokalnom pregledniku: stranice [REST API-ja](/integration/rest-api). |
| **Gumbi** | [Gumbi](/sip-accounts/buttons) pokraj polja za biranje i lampice na njima. |
| **Hvatanje** | [Snimanje razgovora](/capture/) koji teče u drugoj aplikaciji. |
| **Dijagnostika** | SIP trag, statistika medija i brojači: [Dijagnostika](/troubleshooting/diagnostics). |
| **Rječnici** | Kategorije, oznake i upozoravajući signali — kodovi na koje pokazuje sve ostalo: [Rječnici](/ai-processing/dictionaries). |
| **Imenik** | Adresar: [Kontakti](/interface/contacts-history). |
| **Integracija** | Lokalni API i webhookovi: [Integracija](/integration/rest-api). |
| **Medijsko spremište** | Knjižnica razgovora i koliko se dugo čuvaju: [Snimke](/interface/recordings). |
| **Obrada** | Upute i pravila koja ih okidaju: [Obrada](/ai-processing/processing). |
| **Snimanje** | Snimanje poziva i obavještavanje druge strane o tome: [Snimanje poziva](/recordings/call-recording). |
| **Telefonija** | SIP, računi, pozivi, polje za biranje i povijest poziva. |
| **Prijepis** | Prepoznavači, red koji ih pokreće i prijepisi koje stvaraju: [Prijepis](/ai-processing/transcription). |

Isključite modul i nema ga: nema postavki za njega, nema stavke izbornika, ništa od njega ne radi. Isključite modul koji vam ne treba — primjerice **Integracija** na računalu gdje ništa drugo ne razgovara s telefonom — ili zadržite telefon koji je samo telefon, ako je to sve što radnom mjestu treba. Paket je u oba slučaja isti: nema se što kupiti ni otključati.
