---

**Nustatymai → Moduliai** pateikia programos dalis. *Viskas, ką šis telefonas daro, yra vienas iš jų.* Vieno išjungimas įsigalioja iš karto ir palieka vietoje tai, ką jis jau įrašė.

<Shot name="19_settings_modules" alt="Nustatymai → Moduliai" />

Kiekvienas modulis turi žymimąjį langelį, pavadinimą, eilutę apie tai, ką jis daro, o dešinėje — jo būseną: **Veikia** įjungtam moduliui. Dviejų modulių, nuo kurių priklauso kiti, **Programa** ir **Vietinė duomenų bazė**, žymimieji langeliai pilki: jų išjungti negalima.

<Shot name="19b_settings_modules_scrolled" alt="Nustatymai → Moduliai: likusi sąrašo dalis" />

| Modulis | Kas tai |
| --- | --- |
| **Programa** | Pagrindinis langas, nustatymai, piktogramos ir panašiai. |
| **Vietinė duomenų bazė** | Duomenų bazė, naudojama kaip vietinė saugykla. |
| **Naršyklės sąsaja** | Kai kurios funkcijos vietinėje naršyklėje: [REST API](/integration/rest-api) puslapiai. |
| **Mygtukai** | [Mygtukai](/sip-accounts/buttons) šalia numerio rinkiklio ir jų lemputės. |
| **Fiksavimas** | Kitoje programoje vykstančio [pokalbio įrašymas](/capture/). |
| **Diagnostika** | SIP sekimas, medijos statistika ir skaitikliai: [Diagnostika](/troubleshooting/diagnostics). |
| **Žodynai** | Kategorijos, žymos ir įspėjamieji signalai — kodai, į kuriuos rodo visa kita: [Žodynai](/ai-processing/dictionaries). |
| **Katalogas** | Adresų knyga: [Kontaktai](/interface/contacts-history). |
| **Integracija** | Vietinis API ir žiniatinklio kabliai: [Integracija](/integration/rest-api). |
| **Medijos saugykla** | Pokalbių biblioteka ir kiek laiko jie laikomi: [Įrašai](/interface/recordings). |
| **Apdorojimas** | Nurodymai ir juos paleidžiančios taisyklės: [Apdorojimas](/ai-processing/processing). |
| **Įrašymas** | Skambučių įrašymas ir pranešimas apie tai kitai pusei: [Įrašai](/recordings). |
| **Telefonija** | SIP, paskyros, skambučiai, numerio rinkiklis ir skambučių istorija. |
| **Užrašas** | Atpažintuvai, juos varanti eilė ir jų kuriami iššifruoti tekstai: [Užrašas](/ai-processing/transcription). |

Išjunkite modulį, ir jo nebėra: nėra jo nustatymų, meniu punkto, niekas iš jo neveikia. Išjunkite modulį, kurio jums nereikia — pavyzdžiui, **Integracija** kompiuteryje, kuriame niekas kitas su telefonu nebendrauja —, arba palikite telefoną, kuris yra tik telefonas, jei darbo vietai daugiau nieko nereikia. Paketas abiem atvejais tas pats: nėra ko pirkti ir nėra ko atrakinti.
