title: Речник на термините

---

| Термин | Значение |
| --- | --- |
| **Профил** | Линия: SIP потребителско име в централа или при доставчик. Можете да сте влезли в няколко едновременно. Вижте [Настройване на SIP профил](/sip-accounts/setup). |
| **BLF** (Busy Lamp Field) | Бутон, който набира вътрешен номер и с лампичка показва дали е свободен, звъни или е зает. Вижте [Бутони](/sip-accounts/buttons). |
| **Изчакване на повикване** | Какво прави телефонът, когато някой ви звъни, докато вече сте в разговор. Вижте [Настройки на обажданията](/sip-accounts/calls#call-waiting). |
| **Улавяне** | Записване на разговор, проведен в друго приложение, като Zoom, Teams или Meet. Вижте [Улавяне](/capture/). |
| **Категория** | За какво е бил разговорът; по една на разговор. Вижте [Речници](/ai-processing/dictionaries). |
| **Кодек** | Начинът, по който гласът се кодира за линията. Телефонът предлага списък с кодеци, а отсрещният край избира един. Вижте [Настройки на обажданията](/sip-accounts/calls#audio-formats). |
| **Конференция** | Обаждания, обединени в едно. |
| **CTI** | Интеграция на компютъра и телефонията: програма на компютъра провежда и следи обаждания. Вижте [Локален REST API](/integration/rest-api). |
| **DTMF** | Тоновете на клавиатурата, изпращани по време на обаждане. |
| **Вътрешен номер** | Вътрешният номер на човек или устройство в централата. |
| **IP централа** | Телефонната централа на офиса, която работи в мрежата; наричана още softswitch. |
| **Езиков модел** | Изкуственият интелект, който чете стенограмата и пише за нея. Вижте [Обработка](/ai-processing/processing). |
| **Указание** | Това, което се иска от езиковия модел. Вижте [Personal Prompt Studio](/ai-processing/prompt-studio). |
| **Разпознавач** | Услугата, която превръща звука в текст (разпознаване на реч). Вижте [Стенограма](/ai-processing/transcription). |
| **Предупредителен сигнал** | Нещо в разговора, което изисква внимание, с доказателството и момента. Вижте [Речници](/ai-processing/dictionaries#red-flags). |
| **Регистрация** | Телефонът съобщава на централата къде се намира, за да стигат обажданията до него. Зелена точка до профила означава, че е регистриран. |
| **Правило** | Стъпка, която се изпълнява сама, по ред, върху всеки разговор. Вижте [Обработка](/ai-processing/processing#rules). |
| **SIP** | Протоколът, с който телефоните и централите установяват обаждания. |
| **Етикет** | Отметка; към един разговор може да се отнасят няколко. Вижте [Речници](/ai-processing/dictionaries#tags). |
| **Токен** | Две неща: **Токен** на локалния API, парола за други програми; и токените, които брои езиковият модел — единицата на месечната **Граница за токени**. |
| **Стенограма** | Разговорът като текст, реплика по реплика, синхронизиран със звука. |
| **Уебкукичка** | Заявка, която телефонът изпраща към друга система, когато обаждане започне, се промени или приключи. Вижте [Уебкукички](/integration/webhooks). |
| **Широколентов** | Кодек с по-широк звуков обхват от този на телефонната линия, така че гласът е по-ясен. |
