**Definições → Módulos** lista as partes do programa. *Tudo o que este telefone faz é um destes.* Desligar um faz efeito de imediato e deixa onde está o que já guardou.

<Shot name="19_settings_modules" alt="Definições → Módulos" />

Cada módulo tem uma caixa, um nome, uma linha que diz o que faz e, à direita, o seu estado — **A funcionar** para um módulo ligado. As caixas dos dois módulos de que os outros dependem, **Aplicação** e **Base de dados local**, estão cinzentas: não podem ser desligados.

<Shot name="19b_settings_modules_scrolled" alt="Definições → Módulos: o resto da lista" />

| Módulo | O que é |
| --- | --- |
| **Aplicação** | A janela principal, as definições, os ícones e assim por diante. |
| **Base de dados local** | A base de dados usada como armazenamento local. |
| **Interface de navegador** | Algumas funções num navegador local: as páginas da [API REST](/integration/rest-api). |
| **Botões** | Os [botões](/sip-accounts/buttons) ao lado do marcador, e as suas luzes. |
| **Captura** | [Gravar uma conversa](/capture/) que decorre noutra aplicação. |
| **Diagnóstico** | O traço SIP, as estatísticas de média e os contadores: [Diagnóstico](/troubleshooting/diagnostics). |
| **Dicionários** | Categorias, etiquetas e sinais — os códigos para os quais tudo o resto aponta: [Dicionários](/ai-processing/dictionaries). |
| **Diretório** | A lista de contactos: [Contactos](/interface/contacts-history). |
| **Integração** | A API local e os webhooks: [Integração](/integration/rest-api). |
| **Arquivo de média** | A biblioteca de conversas e durante quanto tempo são guardadas: [Gravações](/recordings/recordings-window). |
| **Processamento** | As instruções e as regras que as disparam: [Processamento](/ai-processing/processing). |
| **Gravação** | Gravar chamadas, e avisar o interlocutor disso: [Gravar chamadas](/recordings/call-recording). |
| **Telefonia** | SIP, contas, chamadas, o marcador e o registo de chamadas. |
| **Transcrição** | Os reconhecedores, a fila que os alimenta e as transcrições que produzem: [Transcrição](/ai-processing/transcription). |

Desligue um módulo e ele desaparece: nada de definições para ele, nada de entrada de menu, nada dele a funcionar. Desligue um módulo de que não precisa — por exemplo **Integração** num computador onde nada mais fala com o telefone — ou fique com um telefone que é só um telefone, quando é tudo o que um posto precisa. O pacote é o mesmo em qualquer caso: não há nada para comprar nem nada para desbloquear.
