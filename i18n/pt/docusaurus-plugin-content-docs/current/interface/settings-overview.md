As **Definições** abrem como um separador à direita do telefone, com uma lista dos separadores de definições na margem esquerda. A lista está em grupos separados por linhas: a **Visão geral** sozinha, depois a telefonia, a IA, o próprio programa e, por fim, **Módulos** e **Acerca**.

## Visão geral {#overview}

<Shot name="04_settings_overview" alt="Definições → Visão geral: a lista de verificação do que está configurado" />

A **Visão geral** é uma lista de verificação do que é preciso para tirar o máximo partido do programa. No topo conta os passos — na imagem *10 passos feitos* com um ponto verde e *faltam 8 passos* com um vermelho — e uma barra mostra a parte feita. Cada passo é uma linha com um ponto: verde para um passo feito, vermelho para um que falta.

*Carregue numa linha para ler para que serve e abrir onde se configura.* A seta no fim da linha expande-a.

| Grupo | Passos |
| --- | --- |
| **Chamadas** | Adicionar uma conta; Fazer uma chamada; Atender uma chamada; Gravar uma chamada |
| **Captura de outras aplicações** | Ligar a captura; Capturar uma conversa; Dar um nome a uma captura |
| **Transcrição** | Adicionar um reconhecedor; Transcrever uma conversa |
| **Processamento** | Adicionar um modelo; Processar uma transcrição |
| **Gravações** | Procurar no que foi dito; Exportar uma gravação; Exportar um resumo |
| **Aplicação** | Arrancar com o computador; Mantê-lo actualizado |
| **Comentários** | Enviar o relatório alargado; Diga-nos o que acha |

<Shot name="04b_settings_overview_scrolled" alt="O resto da lista de verificação Visão geral" />

Os passos são um guia, não uma obrigação: um passo que não lhe interessa pode ficar vermelho.
