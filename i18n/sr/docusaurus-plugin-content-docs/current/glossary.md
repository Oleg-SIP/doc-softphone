| Појам | Значење |
| --- | --- |
| **Налог** | Линија: SIP корисничко име на централи или код оператера. Можете бити пријављени на више њих. Погледајте [Подешавање SIP налога](/sip-accounts/setup). |
| **BLF** (Busy Lamp Field) | Дугме које бира интерни број и лампицом показује да ли је слободан, звони или је заузет. Погледајте [Дугмад](/sip-accounts/buttons). |
| **Позив на чекању** | Шта телефон ради када вас неко позове док сте већ у разговору. Погледајте [Подешавања позива](/sip-accounts/calls#call-waiting). |
| **Хватање** | Снимање разговора одржаног у другој апликацији, као што су Zoom, Teams или Meet. Погледајте [Хватање](/capture/). |
| **Категорија** | О чему је био разговор; једна по разговору. Погледајте [Речници](/ai-processing/dictionaries). |
| **Кодек** | Начин на који се глас кодира за линију. Телефон нуди њихов списак, а друга страна бира један. Погледајте [Подешавања позива](/sip-accounts/calls#audio-formats). |
| **Конференција** | Позиви спојени у један. |
| **CTI** | Интеграција рачунара и телефоније: програм на рачунару упућује и прати позиве. Погледајте [Локални REST API](/integration/rest-api). |
| **DTMF** | Тонови тастатуре који се шаљу током позива. |
| **Интерни број** | Унутрашњи број особе или уређаја на централи. |
| **IP централа** | Телефонска централа канцеларије која ради у мрежи; зове се и softswitch. |
| **Језички модел** | Вештачка интелигенција која чита препис и пише о њему. Погледајте [Обрада](/ai-processing/processing). |
| **Упутство** | Оно што се тражи од језичког модела. Погледајте [Personal Prompt Studio](/ai-processing/prompt-studio). |
| **Препознавач** | Услуга која звук претвара у текст (препознавање говора). Погледајте [Преписивање](/ai-processing/transcription). |
| **Упозорење** | Нешто у разговору што тражи пажњу, са доказом и временом. Погледајте [Речници](/ai-processing/dictionaries#red-flags). |
| **Регистрација** | Телефон јавља централи где је, како би позиви стигли до њега. Зелена тачка поред налога значи да је регистрован. |
| **Правило** | Корак који се изводи сам, редом, на сваком разговору. Погледајте [Обрада](/ai-processing/processing#rules). |
| **SIP** | Протокол којим телефони и централе успостављају позиве. |
| **Ознака** | Етикета; на један разговор их може важити више. Погледајте [Речници](/ai-processing/dictionaries#tags). |
| **Жетон** | Две ствари: **Жетон** локалног API-ја, лозинка за друге програме; и жетони које броји језички модел, јединица месечне **Границе жетона**. |
| **Препис** | Разговор као текст, реплика по реплика, усклађен са звуком. |
| **Веб-кука** | Захтев који телефон шаље другом систему када позив почне, промени се или заврши. Погледајте [Веб-куке](/integration/webhooks). |
| **Широкопојасни** | Кодек са ширим опсегом звука него што га има телефонска линија, па је глас јаснији. |
