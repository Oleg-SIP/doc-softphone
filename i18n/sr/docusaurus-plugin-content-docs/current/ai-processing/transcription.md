**Подешавања → Преписивање** одређује како звук постаје текст: на ком језику и којим препознавачем.

<Shot name="25_transcription" alt="Подешавања → Преписивање: језик и четири препознавача" />

Разговор се преписује када то затражите у [прозору Снимци](/recordings/recordings-window), или сам ако је у [Обради](/ai-processing/processing) укључено **Обрађуј разговоре самостално**. Препознавач на сопственом рачунару не кошта ништа; онај у облаку наплаћује по минуту звука.

## Језик {#language}

**Језик** је двословни код језика према ISO 639-1 (`en`, `de`, `es`, `fr`, `sr`…). Оставите га празним и одлучује препознавач — то је исправно, осим ако су ваши позиви на језику који стално погрешно чује.

## Препознавачи {#recognisers}

Препознавач је услуга претварања говора у текст којој телефон шаље звук. Притисните **Додај** да га додате; дугме **Испробај** у обрасцу проверава да ли услуга заиста одговара. Сваки је наведен са својим називом, а испод њега са моделом и адресом своје услуге. На слици су четири:

| Назив | Модел | Адреса |
| --- | --- | --- |
| **X.ai** | *(празно: подразумевани модел услуге)* | `https://api.x.ai/v1` |
| **ElevenLabs** | `scribe_v2` | `https://api.elevenlabs.io/v1` |
| **Deepgram** | `nova-2` | `https://api.deepgram.com/v1` |
| **OpenAI** | `gpt-4o-transcribe` | `https://api.openai.com/v1/` |

Онај означен као **Подразумевано** десно у свом реду (на слици **X.ai**) користи се када не изаберете други. Можете их имати неколико. Падајући мени изнад преписа у [прозору Снимци](/recordings/recordings-window#the-transcript-and-the-write-up) наводи преписе које је направио сваки препознавач.

Модел може да остане празан. Услуга тада користи свој подразумевани.

## Који модел изабрати {#which-model-to-choose}

Табела наводи моделе за претварање говора у текст четири услуге са слике. Модели **подебљано** су они подешени на слици. За препознавач X.ai модел је празан, па се користи подразумевани модел услуге, **`grok-voice-transcribe-2.0`**.

| Услуга и адреса | Модел | Чему служи |
| --- | --- | --- |
| **OpenAI**<br />`https://api.openai.com/v1` | `gpt-transcribe` | Модел који OpenAI препоручује за снимљени говор на изворном језику. |
| | **`gpt-4o-transcribe`** | Препис опште намене. |
| | `gpt-4o-mini-transcribe` | Лакша, јефтинија варијанта горњег. |
| | `gpt-4o-transcribe-diarize` | Означава ко када говори. Користите га само ако вам то треба. |
| | `whisper-1` | Старији модел Whisper, задржан за посебне намене као што су временске ознаке речи и титлови. |
| **ElevenLabs**<br />`https://api.elevenlabs.io/v1` | **`scribe_v2`** | Препис опште намене на више од 90 језика, са раздвајањем говорника. |
| | `scribe_v2_medical` | Исто, прилагођено клиничком звуку. |
| | `scribe_v1` | Прва генерација; застарео, користите `scribe_v2`. |
| **Deepgram**<br />`https://api.deepgram.com/v1` | `nova-3` | Најбољи Deepgram-ов модел опште намене, за састанке, бучан и вишејезичан звук. |
| | **`nova-2`** | Претходна генерација; задржите је за језике које `nova-3` још не подржава. |
| | `enhanced` | Старији ниво са мање грешака од `base`. |
| | `base` | Најстарији ниво, за велике количине. |
| | `whisper` | Whisper који покреће Deepgram. |
| **X.ai**<br />`https://api.x.ai/v1` | **`grok-voice-transcribe-2.0`** | Подразумевани; 25 језика. |
| | `grok-voice-transcribe-1.0` | Застарео: услуга га преусмерава на `2.0`. |

Шта је корисно знати пре избора:

- **Величина датотеке.** OpenAI прима датотеке до 25 MB; X.ai до 500 MB. Дуг разговор може бити већи него што услуга у облаку прихвата.
- **Цена.** Услуге у облаку наплаћују по минуту звука, а цене се разликују по моделу и мењају се; прочитајте их на страници услуге пре него што пређете.
- **Језици.** Свака услуга има сопствени списак; проверите свој и подесите код у пољу [Језик](#language) ако препознавач погрешно погађа.
- **Модели у реалном времену**, као што су `scribe_v2_realtime` или Deepgram-ов `flux`, намењени су преносима уживо и нису у табели: телефон преписује готове снимке.

Списак модела услуге се често мења. Ако овде недостаје модел који желите, актуелни списак налази се у документацији саме услуге — [OpenAI](https://developers.openai.com/api/docs/guides/speech-to-text), [ElevenLabs](https://elevenlabs.io/docs/capabilities/speech-to-text), [Deepgram](https://developers.deepgram.com/docs/models-languages-overview), [X.ai](https://docs.x.ai/developers/model-capabilities/audio/speech-to-text) — **Модел** је назив тачно онакав какав га даје услуга.

## Сопствени модели {#your-own-models}

Препознавач не мора да буде услуга у облаку. Телефон може да користи **било који модел доступан преко API-ја компатибилног са OpenAI** — сучеља `POST /v1/audio/transcriptions` —, било да ради локално на вашем рачунару или на сопственом серверу. Звук никада не напушта ваше просторије, ништа се не наплаћује по минуту и нема ограничења количине.

Да бисте га додали, притисните **Додај** и упишите:

- **адресу** сервера, до и укључујући `/v1`, на пример `http://localhost:8000/v1` за сам рачунар или `http://asr.local:8080/v1` за сервер у вашој мрежи;
- назив **модела** тачно онакав какав га наводи сервер, на пример `openai/whisper-large-v3-turbo`.

### Шта може да се користи {#what-can-be-used}

Уобичајен избор је **Whisper**, OpenAI-јев отворени модел за препознавање говора. Бесплатан је за коришћење, разуме стотинак језика и долази у неколико величина: мали модел ради на обичном рачунару, велики су приметно тачнији и најбоље им је дати графичку картицу.

| Модел | Напомене |
| --- | --- |
| `whisper-large-v3` | Најтачнији Whisper. За сервер са GPU-ом. |
| `openai/whisper-large-v3-turbo` | Бржа верзија `large-v3` са малим губитком тачности. |
| `Systran/faster-whisper-large-v3` | `large-v3` претворен за погон faster-whisper; бржи и штедљивији са меморијом. |
| `medium`, `small`, `base` | Мањи модели Whisper, за рачунар без графичке картице. |

Whisper је модел око ког су ови сервери изграђени. Неки од њих могу да служе и друге моделе за препознавање говора, као што је NVIDIA Parakeet.

### Сервери који нуде API компатибилан са OpenAI {#servers-that-offer-the-openai-compatible-api}

Модел мора да покреће сервер који нуди крајњу тачку `/v1/audio/transcriptions` компатибилну са OpenAI. Ови то раде:

| Сервер | Шта је |
| --- | --- |
| [vLLM](https://docs.vllm.ai/en/latest/serving/online_serving/speech_to_text/) | Сервер модела високих перформанси. Након покретања служи Whisper на `http://localhost:8000/v1`. |
| [Speaches](https://github.com/speaches-ai/speaches) | Сервер за говорне моделе, „Ollama за говор”, изграђен на faster-whisper-у. Модел учитава када се први пут затражи. |
| [whisper.cpp](https://github.com/ggml-org/whisper.cpp) | Ефикасно покреће Whisper на CPU-у, укључујући Apple silicon. Његов `whisper-server` покреће се са `--inference-path /v1/audio/transcriptions`. |
| [LocalAI](https://localai.io/) | Директна замена за OpenAI која моделе покреће локално. |

Сваки други сервер који нуди исту крајњу тачку ради на исти начин. Ако сервер тражи кључ, упишите га као за услугу у облаку.

Пре него што се ослоните на сервер, направите пробни снимак и погледајте препис у [прозору Снимци](/recordings/recordings-window): разговор на језику који модел слабо познаје то одмах показује.
