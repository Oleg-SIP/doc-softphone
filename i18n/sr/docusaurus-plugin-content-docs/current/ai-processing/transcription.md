**Подешавања → Преписивање** наводи препознаваче: услуге које претварају звук у текст, за завршене разговоре и, за [шаптача](../interface/prompter.md), док разговор траје.

<Shot name="25_transcription" alt="Подешавања → Преписивање: пет препознавача" />

Разговор се преписује када то затражите у [прозору Снимци](/interface/recordings), или сам од себе ако је у одељку [Обрада](/ai-processing/processing) укључено **Обрађуј разговоре самостално**. Препознавач на вашој сопственој машини не кошта ништа; онај у облаку наплаћује минут звука.

## Препознавачи {#recognisers}
Препознавач је услуга за препознавање говора којој телефон шаље звук. **Додај** додаје нови; дугме **Испробај** на његовој картици проверава да ли услуга заиста одговара. Сваки је на списку са својим називом, а испод њега са моделом и адресом своје услуге. На слици их је пет:

| Назив | Модел | Адреса |
| --- | --- | --- |
| **X.ai** | *(празно: подразумевани модел услуге)* | `https://api.x.ai/v1` |
| **ElevenLabs** | `scribe_v2` | `https://api.elevenlabs.io/v1` |
| **Deepgram** | `nova-2` | `https://api.deepgram.com/v1` |
| **OpenAI** | `gpt-4o-transcribe` | `https://api.openai.com/v1/` |
| **Vosk** | *(нема)* | `ws://localhost:2700`, сервер на овом рачунару |

Две ознаке десно у реду говоре за шта је препознавач подразумеван. Сат светли код подразумеваног **за преписе** — на слици **X.ai** —, који се користи када не изаберете други. Муња светли код подразумеваног **за шаптача** — на слици **Vosk**. Можете имати више препознавача; падајући списак изнад преписа у [прозору Снимци](/interface/recordings#transcript-or-write-up-the-drop-down) приказује преписе које је направио сваки од њих.

## Картица препознавача {#the-recognisers-card}
Притисак на препознавач отвара његову картицу.

| Поље | Шта је |
| --- | --- |
| **Назив** | Назив на списковима. |
| **Врста** | Врста услуге, од које зависи како телефон разговара с њом: **Сагласно са OpenAI (Whisper, OpenAI)**, **Deepgram**, **ElevenLabs (Scribe)**, **xAI (Grok)**, **AssemblyAI**, **Soniox**, **Speechmatics** и три које раде на вашој сопственој машини — **Vosk**, **WhisperLive** и **NVIDIA Riva**. **Yandex SpeechKit** се нуди када је у одељку [О програму](../application/about.md) изабрана земља Русија или нека од њених суседа. |
| **Адреса за преписе** | Куда се шаљу завршени разговори. |
| **Адреса за шаптача** | Куда иде звук уживо док разговор траје. *Празно се изводи из суседне адресе*, као `wss://api.x.ai` на слици. |
| **Кључ** | Кључ услуге. *Чува се у привеску овог рачунара, никада у датотеци с подешавањима.* |
| **Испробај** | Пита услугу и каже шта је одговорила, на пример *Одговорио је и нуди 3 модела*. |
| **Модел за преписе** и **Модел за шаптача** | Модел тачно онако како га услуга назива. *Празно не шаље име модела*, а услуга користи свој подразумевани; где га добављач објављује, картица га наводи. За врсту без избора поље се не приказује. |
| **Подразумевано за преписе** | Чини овај препознавач оним који се користи када не изаберете други. |
| **Подразумевано за шаптача** | Чини овај препознавач оним којим слуша нови помоћник шаптача. |
| **Укључено** | Искључен препознавач остаје на списку, али се не користи. |

**Напредна подешавања** отварају остатак картице. Вредности које су најважније:

<Shot name="43b_recogniser_advanced" alt="Напредна подешавања препознавача: границе, како се секу одговори, језик" />

| Поље | Шта ради |
| --- | --- |
| **Област** | Област услуге, ако их има више. |
| **Шаљи две стране одвојено** | Позив се снима са две особе на два канала, и управо по томе препознавач зна ко је шта рекао. Искључите то за сервер који тврди да то уме, а не уме. |
| **Тражи ко говори** | Разликује особе унутар једног канала када на њему говори више њих. |
| **Бројеве писати цифрама** | Износи, датуми и бројеви телефона враћају се онако како се пишу, а не исписани речима. |
| **Граница слања**, **Граница трајања** | Највећа датотека у бајтовима и најдужи снимак у секундама које ће овај телефон послати. |
| **Захтева одједном** | Колико захтева сме да буде у току истовремено. |
| **Заврши одговор након**, **Споји кратке одговоре у року од**, **Размак међу репликама** | За шаптача: колико времена без нових речи завршава одговор, колико кратак одговор чека следећи да би се спојио с њим, и колико тишине завршава реплику када је препознавач сам не означи. У милисекундама. |
| **Језик** | Двословни код језика према ISO 639-1 (`en`, `de`, `es`, `fr`, `sr`…). Оставите га празним и препознавач одлучује сам — то је исправно, осим ако су ваши позиви на језику који он упорно погрешно чује. |
| **Додатно** | Један `name = value` по реду, прослеђује се услузи непромењен. Оставите празно, осим ако сервер нешто документује. |
| **Чекање, минути** | Колико чекати препис. Празно то израчунава из трајања снимка. |
| **Цена по минуту** | Колико кошта минут звука уживо према ценовнику услуге. Шаптач показује колико је сесија коштала и зауставља се на свом [месечном ограничењу](prompter.md#spending). |

## Препознавање уживо за шаптача {#live-recognition-for-the-prompter}
[Шаптачу](../interface/prompter.md) треба препознавач који слуша док неко говори — током, а не готовом датотеком. То могу ове врсте: **Deepgram**, **ElevenLabs (Scribe)**, **xAI (Grok)**, **Сагласно са OpenAI** (са преписивањем OpenAI у реалном времену), **AssemblyAI**, **Soniox** и **Speechmatics** у облаку, **Yandex SpeechKit** тамо где се нуди, и **Vosk**, **WhisperLive** и **NVIDIA Riva** на вашој сопственој машини. Препознавач на вашој сопственој машини задржава глас саговорника у кући и не кошта ништа.

Како да га користите: отворите његову картицу, проверите **Адреса за шаптача** (или је пустите да се изведе), изаберите **Модел за шаптача** где услуга нуди више њих — модели уживо се често разликују од оних за датотеке, попут ElevenLabs `scribe_v2_realtime` — и притисните **Испробај**. Означите **Подразумевано за шаптача** да би нови помоћници слушали њиме.

Шта је добро знати пре избора:

- **Преписи или шаптач.** Модел за говор уживо не прима готову датотеку, а већина модела за датотеке не уме да слуша уживо. Зато картица има два поља, **Модел за преписе** и **Модел за шаптача**.
- **Величина датотеке.** OpenAI прима датотеке до 25 МБ, X.ai до 500 МБ. Дуг разговор може бити већи него што услуга у облаку прима.
- **Цена.** Услуге у облаку наплаћују минут звука, а цене се разликују по моделу и мењају; прочитајте их на страници саме услуге пре преласка. Препознавач на вашој сопственој машини не кошта ништа.
- **Језици.** Свака услуга има свој списак; проверите свој и подесите код у пољу **Језик** у напредним подешавањима препознавача ако погађа погрешно.

Списак модела услуге се често мења. Ако овде недостаје модел који желите, актуелни списак је у документацији саме услуге — [OpenAI](https://developers.openai.com/api/docs/guides/speech-to-text), [Deepgram](https://developers.deepgram.com/docs/models-languages-overview), [ElevenLabs](https://elevenlabs.io/docs/capabilities/speech-to-text), [Speechmatics](https://docs.speechmatics.com/speech-to-text/models), [X.ai](https://docs.x.ai/developers/model-capabilities/audio/speech-to-text), [Soniox](https://soniox.com/docs/stt/models), [AssemblyAI](https://www.assemblyai.com/docs/getting-started/models), [Yandex SpeechKit](https://yandex.cloud/en/docs/speechkit/stt/models), [Vosk](https://alphacephei.com/vosk/models), [WhisperLive](https://github.com/collabora/WhisperLive), [NVIDIA Riva](https://docs.nvidia.com/deeplearning/riva/user-guide/docs/asr/asr-overview.html) — а **Модел** је назив тачно онакав какав га даје услуга.

## Сопствени модели {#your-own-models}

Препознавач не мора да буде услуга у облаку. Телефон може да користи **било који модел доступан преко API-ја компатибилног са OpenAI** — сучеља `POST /v1/audio/transcriptions` —, било да ради локално на вашем рачунару или на сопственом серверу. Звук никада не напушта ваше просторије, ништа се не наплаћује по минуту и нема ограничења количине.

Да бисте га додали, притисните **Додај** и упишите:

- **адресу** сервера, до и укључујући `/v1`, на пример `http://localhost:8000/v1` за сам рачунар или `http://asr.local:8080/v1` за сервер у вашој мрежи;
- назив **модела** тачно онакав какав га наводи сервер, на пример `openai/whisper-large-v3-turbo`.

### Шта може да се користи {#what-can-be-used}

Уобичајен избор је **Whisper**, OpenAI-јев отворени модел за препознавање говора. Бесплатан је за коришћење, разуме стотинак језика и долази у неколико величина: мали модел ради на обичном рачунару, велики су приметно тачнији и најбоље им је дати графичку картицу.

| Модел | Напомене |
| --- | --- |
| `whisper-large-v3` | Најтачнији Whisper. За сервер са GPU-ом. |
| `openai/whisper-large-v3-turbo` | Бржа верзија `large-v3` са малим губитком тачности. |
| `Systran/faster-whisper-large-v3` | `large-v3` претворен за погон faster-whisper; бржи и штедљивији са меморијом. |
| `medium`, `small`, `base` | Мањи модели Whisper, за рачунар без графичке картице. |

Whisper је модел око ког су ови сервери изграђени. Неки од њих могу да служе и друге моделе за препознавање говора, као што је NVIDIA Parakeet.

### Сервери који нуде API компатибилан са OpenAI {#servers-that-offer-the-openai-compatible-api}

Модел мора да покреће сервер који нуди крајњу тачку `/v1/audio/transcriptions` компатибилну са OpenAI. Ови то раде:

| Сервер | Шта је |
| --- | --- |
| [vLLM](https://docs.vllm.ai/en/latest/serving/online_serving/speech_to_text/) | Сервер модела високих перформанси. Након покретања служи Whisper на `http://localhost:8000/v1`. |
| [Speaches](https://github.com/speaches-ai/speaches) | Сервер за говорне моделе, „Ollama за говор”, изграђен на faster-whisper-у. Модел учитава када се први пут затражи. |
| [whisper.cpp](https://github.com/ggml-org/whisper.cpp) | Ефикасно покреће Whisper на CPU-у, укључујући Apple silicon. Његов `whisper-server` покреће се са `--inference-path /v1/audio/transcriptions`. |
| [LocalAI](https://localai.io/) | Директна замена за OpenAI која моделе покреће локално. |

Сваки други сервер који нуди исту крајњу тачку ради на исти начин. Ако сервер тражи кључ, упишите га као за услугу у облаку.

Пре него што се ослоните на сервер, направите пробни снимак и погледајте препис у [прозору Снимци](/interface/recordings): разговор на језику који модел слабо познаје то одмах показује.
