**Подешавања** се отварају као картица десно од телефона, са списком картица подешавања уз леву ивицу. Списак је у групама раздвојеним линијама: **Преглед** засебно, затим телефонија, вештачка интелигенција, сам програм и на крају **Модули** и **О програму**.

## Преглед {#overview}

<Shot name="04_settings_overview" alt="Подешавања → Преглед: контролни списак онога што је подешено" />

**Преглед** је контролни списак онога што је потребно да из програма извучете највише. На врху броји кораке — на слици *10 корака готово* са зеленом тачком и *преостаје 8 корака* са црвеном — а трака показује обављени део. Сваки корак је ред са тачком: зеленом за обављен корак, црвеном за онај који још преостаје.

*Притисните ред да прочитате чему служи и отворите место где се подешава.* Стрелица на десном крају реда га проширује.

| Група | Кораци |
| --- | --- |
| **Позиви** | Додајте налог; Позовите некога; Јави се на позив; Снимите позив |
| **Хватање из других апликација** | Укључите хватање; Ухватите разговор; Дајте му име |
| **Преписивање** | Додајте препознавач; Препишите разговор |
| **Обрада** | Додајте модел; Обрадите препис |
| **Снимци** | Тражите у ономе што је речено; Извезите снимак; Извезите сажетак |
| **Апликација** | Покрећи са рачунаром; Држите га ажурним |
| **Повратна информација** | Шаљи проширени извештај; Реците нам шта мислите |

<Shot name="04b_settings_overview_scrolled" alt="Остатак контролног списка Преглед" />

Кораци су водич, а не обавеза: корак који вам не треба може да остане црвен.
