**Подешавања → Модули** наводи делове програма. *Све што овај телефон ради јесте један од њих.* Искључивање важи одмах и оставља оно што је већ сачувано тамо где јесте.

<Shot name="19_settings_modules" alt="Подешавања → Модули" />

Сваки модул има поље за потврду, назив, ред о томе шта ради, а десно своје стање — **Ради** за укључен модул. Поља за потврду два модула од којих остали зависе, **Апликација** и **Локална база података**, сива су: не могу да се искључе.

<Shot name="19b_settings_modules_scrolled" alt="Подешавања → Модули: остатак списка" />

| Модул | Шта је |
| --- | --- |
| **Апликација** | Главни прозор, подешавања, иконе и тако даље. |
| **Локална база података** | База података која се користи као локално складиште. |
| **Сучеље у прегледачу** | Неке функције у локалном прегледачу: странице [REST API-ја](/integration/rest-api). |
| **Дугмад** | [Дугмад](/sip-accounts/buttons) поред поља за бирање и лампице на њима. |
| **Хватање** | [Снимање разговора](/capture/) који тече у другој апликацији. |
| **Дијагностика** | SIP траг, статистика медија и бројачи: [Дијагностика](/troubleshooting/diagnostics). |
| **Речници** | Категорије, ознаке и упозорења — кодови на које показује све остало: [Речници](/ai-processing/dictionaries). |
| **Именик** | Адресар: [Контакти](/interface/contacts-history). |
| **Повезивање** | Локални API и веб-куке: [Повезивање](/integration/rest-api). |
| **Складиште записа** | Библиотека разговора и колико се дуго чувају: [Снимци](/interface/recordings). |
| **Обрада** | Упутства и правила која их окидају: [Обрада](/ai-processing/processing). |
| **Снимање** | Снимање позива и обавештавање друге стране о томе: [Снимање позива](/recordings/call-recording). |
| **Телефонија** | SIP, налози, позиви, поље за бирање и историја позива. |
| **Преписивање** | Препознавачи, ред који их покреће и преписи које праве: [Преписивање](/ai-processing/transcription). |

Искључите модул и нема га: нема подешавања за њега, нема ставке менија, ништа од њега не ради. Искључите модул који вам не треба — на пример **Повезивање** на рачунару где ништа друго не разговара са телефоном — или задржите телефон који је само телефон, ако је то све што радном месту треба. Пакет је у оба случаја исти: нема шта да се купи ни откључа.
