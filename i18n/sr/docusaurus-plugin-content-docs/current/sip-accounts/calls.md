**Подешавања → Позиви** садржи подешавања која важе за сваки позив, без обзира на налог.

## Звучни формати {#audio-formats}

<Shot name="07_settings_calls" alt="Подешавања → Позиви: звучни формати" />

Списак кодека које телефон нуди другој страни. Кодеци се *нуде овим редом*, а друга страна бира из онога што понудите: што је кодек више, то је вероватније да ће се користити.

- **Поље за потврду** укључује или искључује кодек. Искључен кодек се не нуди.
- **▲** и **▼** га померају горе или доле по списку.
- *широкопојасни* десно означава кодек са ширим опсегом звука него што га има телефонска линија: глас је јаснији.

| Кодек | Фреквенција узорковања | Подразумевано укључен |
| --- | --- | --- |
| **opus** | 48 kHz, стерео, широкопојасни | да |
| **G722** | 16 kHz, широкопојасни | да |
| **PCMU** | 8 kHz | да |
| **PCMA** | 8 kHz | да |
| **speex** | 16 kHz, широкопојасни | не |
| **speex** | 8 kHz | не |
| **speex** | 32 kHz, широкопојасни | не |
| **iLBC** | 8 kHz | не |
| **GSM** | 8 kHz | не |
| **L16** | 44 kHz, стерео, широкопојасни | не |
| **L16** | 44 kHz, широкопојасни | не |

Табела је у редоследу у ком долази са програмом.

Кодеци се договарају на почетку позива, па измена важи од следећег позива. Ако позив звучи лоше, оставите укључене само кодеке које користи ваша централа.

## Позив на чекању {#call-waiting}

<Shot name="07b_settings_calls_scrolled" alt="Подешавања → Позиви: позив на чекању, аутоматско бирање и историја" />

*Шта се дешава када вас неко позове док сте већ у разговору.* Бира се у падајућем менију; подразумевано је **Нека други позив звони**. Интерфонски позив са сопствене централе увек пролази, шта год да изаберете — тако до овог телефона стиже позив упућен са CTI табле.

## Аутоматско бирање {#autodial}

Када позив не може да прође, његова картица нуди да настави да бира док не успе. Два клизача одређују како:

- **Чекање између покушаја** — подразумевано 15 секунди;
- **Одустани после** — подразумевано 30 минута.

## Историја {#history}

Дневник позива је доказ, па се из њега ништа не уклања док то овде не кажете.

- **Раздобље чувања** бира колико дуго [дневник позива](/interface/contacts-history#history) чува позив. Подразумевано је **Увек**.
- **Испразни историју позива** брише све позиве одједном, без обзира на раздобље. То не може да се поништи.
