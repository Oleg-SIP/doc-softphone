**Setări → Înregistrare** hotărăște ce apeluri devin înregistrări și cât timp rămân fișierele. Un apel înregistrat apare în [fereastra Înregistrări](/interface/recordings).

<Shot name="09_settings_recording" alt="Setări → Înregistrare" />

## Înregistrare {#recording}

Lista derulantă alege ce apeluri se înregistrează:

| Opțiune | Înregistrează |
| --- | --- |
| **Manual** | Doar când apăsați butonul de înregistrare de pe cardul apelului. Implicit. |
| **Întreabă la fiecare apel** | Telefonul întreabă la fiecare apel dacă să-l înregistreze. |
| **Fiecare apel** | Fiecare apel la care s-a răspuns, de la sine. Ales în imagine. |
| **Linii alese** | Apelurile de pe conturile pe care le bifați în lista care apare. |

Înregistrarea începe când se răspunde la apel și niciodată înainte, așa că sunetul de apel și numerele pe care le formați nu ajung în fișier. Un apel este un singur fișier stereo: dumneavoastră pe un canal și toți ceilalți pe celălalt.

## Consimțământ {#consent}

Lista derulantă alege cum este informată cealaltă parte despre înregistrare:

| Opțiune | Ce aude cealaltă parte |
| --- | --- |
| **Un anunț** | Un mesaj scurt când începe înregistrarea. Implicit. **Alege…** selectează propriul fișier de sunet; *Dacă nu este ales nimic, telefonul redă un semnal scurt.* |
| **Un ton la câteva secunde** | Un bip la un interval pe care îl stabiliți cu glisorul. |
| **Absolut nimic** | Nimic. Ales în imagine. |

**Păstrează anunțul în înregistrare** — anunțul și tonul sunt redate persoanelor din apel; porniți această opțiune și ele vor ajunge și în fișier.

:::caution
În multe locuri — cea mai mare parte a Europei și mai multe state americane — înregistrarea unei conversații fără a o anunța celeilalte părți este ilegală. Decizia vă aparține, iar programul spune acest lucru sub lista derulantă.
:::

## Conferințe {#conferences}

**Un fișier de persoană**, pornit implicit. Într-o conferință, al doilea canal este un amestec al tuturor, așa că un fișier suplimentar pentru fiecare persoană este ceea ce permite unei transcrieri să spună cine ce a spus.

## Păstrare {#retention}

<Shot name="09b_settings_recording_scrolled" alt="Setări → Înregistrare: păstrare" />

| Setare | Implicit | Ce limitează |
| --- | --- | --- |
| **Perioada de păstrare** | Întotdeauna | Cât timp se păstrează o înregistrare. |
| **Limita de stocare** | Fără limită | Cât spațiu pot ocupa toate înregistrările împreună. |
| **Fișiere de persoană** | Întotdeauna | Cât timp se păstrează fișierele suplimentare ale unei conferințe. |
| **Pragul de spațiu pe disc** | 500 MB | Un minim pentru spațiul liber de pe disc. Înregistrările pe care nu le-ați fixat pot fi eliminate ca să rămână deasupra lui. |

O înregistrare pe care ați fixat-o nu este ștearsă niciodată de vreuna dintre aceste setări, dar se socotește în continuare în limită. O oră de conversație ocupă aproximativ 30 MB.

Partea programului care înregistrează apelurile și o anunță celeilalte părți poate fi oprită în [Module](/application/modules).

Pentru a înregistra o ședință ținută în altă aplicație, consultați [Captare](/capture/).
