**Setări** se deschide ca o filă în dreapta telefonului, cu o listă de file de setări pe marginea din stânga. Lista este împărțită în grupuri separate prin linii: **Prezentare generală** separat, apoi telefonia, inteligența artificială, programul însuși și, la final, **Module** și **Despre**.

## Prezentare generală {#overview}

<Shot name="04_settings_overview" alt="Setări → Prezentare generală: lista de verificare a ceea ce a fost configurat" />

**Prezentare generală** este o listă de verificare a ceea ce este necesar ca să obțineți maximum din program. În partea de sus numără pașii — în imagine *10 pași făcuți* cu un punct verde și *au rămas 8 pași* cu unul roșu — iar o bară arată partea realizată. Fiecare pas este un rând cu un punct: verde pentru un pas făcut, roșu pentru unul care a rămas.

*Apăsați pe o linie pentru a citi la ce folosește și a deschide locul unde se configurează.* Săgeata din capătul din dreapta al rândului îl extinde.

| Grup | Pași |
| --- | --- |
| **Apeluri** | Adăugați un cont; Dați un apel; Răspunde la un apel; Înregistrați un apel |
| **Captură din alte aplicații** | Activați captura; Capturați o conversație; Dați-i un nume |
| **Transcriere** | Adăugați un recunoscător; Transcrieți o conversație |
| **Prelucrare** | Adăugați un model; Prelucrați o transcriere |
| **Înregistrări** | Căutați în ce s-a spus; Exportați o înregistrare; Exportați un rezumat |
| **Aplicație** | Pornire odată cu calculatorul; Țineți-l la zi |
| **Reacții** | Trimiteți raportul extins; Spuneți-ne ce credeți |

<Shot name="04b_settings_overview_scrolled" alt="Restul listei de verificare Prezentare generală" />

Pașii sunt un ghid, nu o obligație: un pas de care nu aveți nevoie poate rămâne roșu.
