**Setări → Module** listează părțile programului. *Tot ce face acest telefon este unul dintre acestea.* Oprirea unuia are efect imediat și lasă pe loc ce a salvat deja.

<Shot name="19_settings_modules" alt="Setări → Module" />

Fiecare modul are o casetă de bifat, un nume, un rând care spune ce face și, în dreapta, starea lui — **Rulează** pentru un modul pornit. Casetele de bifat ale celor două module de care depind toate celelalte, **Aplicație** și **Bază de date locală**, sunt gri: nu pot fi oprite.

<Shot name="19b_settings_modules_scrolled" alt="Setări → Module: restul listei" />

| Modul | Ce este |
| --- | --- |
| **Aplicație** | Fereastra principală, setările, pictogramele și așa mai departe. |
| **Bază de date locală** | Baza de date folosită ca stocare locală. |
| **Interfață în navigator** | Unele funcții într-un navigator local: paginile [API-ului REST](/integration/rest-api). |
| **Butoane** | [Butoanele](/sip-accounts/buttons) de lângă tastatura de apelare și indicatoarele luminoase de pe ele. |
| **Captare** | [Înregistrarea unei conversații](/capture/) care se desfășoară în altă aplicație. |
| **Diagnostic** | Urmărirea SIP, statisticile media și contoarele: [Diagnostic](/troubleshooting/diagnostics). |
| **Dicționare** | Categorii, etichete și semnale de alarmă — codurile la care trimite tot restul: [Dicționare](/ai-processing/dictionaries). |
| **Agendă** | Agenda de adrese: [Contacte](/interface/contacts-history). |
| **Integrare** | API-ul local și webhookurile: [Integrare](/integration/rest-api). |
| **Depozit media** | Biblioteca de conversații și cât timp sunt păstrate: [Înregistrări](/interface/recordings). |
| **Prelucrare** | Instrucțiunile și regulile care le declanșează: [Prelucrare](/ai-processing/processing). |
| **Înregistrare** | Înregistrarea apelurilor și anunțarea celeilalte părți despre aceasta: [Înregistrări](/recordings). |
| **Telefonie** | SIP, conturile, apelurile, tastatura de apelare și istoricul apelurilor. |
| **Transcriere** | Recunoscătoarele, coada care le alimentează și transcrierile pe care le produc: [Transcriere](/ai-processing/transcription). |

Opriți un modul și acesta dispare: nicio setare pentru el, nicio intrare de meniu, nimic din el nu mai rulează. Opriți un modul de care nu aveți nevoie — de exemplu **Integrare** pe un calculator unde niciun alt program nu comunică cu telefonul — sau păstrați un telefon care este doar telefon, acolo unde de atât are nevoie un birou. Pachetul este același în ambele cazuri: nu este nimic de cumpărat și nimic de deblocat.
