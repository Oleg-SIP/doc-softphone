**Setări → Aspect** schimbă felul în care arată programul și locul în care stau ferestrele lui.

<Shot name="14_settings_appearance" alt="Setări → Aspect" />

## Dispunere {#layout}

Șase aranjamente, fiecare desenat ca o imagine mică; cel selectat are un chenar.

| Dispunere | |
| --- | --- |
| **Două ferestre** | Telefonul într-o fereastră, tot restul în alta. |
| **Mai multe ferestre** | Telefonul și câte o fereastră proprie pentru fiecare dintre celelalte secțiuni. |
| **Compact** | Un telefon mic și o fereastră alături. |
| **O fereastră** | Telefonul și tot restul într-o singură fereastră. Aceasta este dispunerea folosită în capturile de ecran din această documentație. |
| **Bară pe margine** | Telefonul ca o bară de-a lungul marginii ecranului, cu o fereastră sub ea. |
| **Doar bara de sistem** | Nicio fereastră până când nu o chemați din bara de sistem sau cu [scurtătura](/program/shortcuts). |

Fiecare aranjament conține aceleași ferestre; diferă doar locul în care stau. **Telefonul se închide și se deschide din nou pentru a schimba dispunerea** — cu butonul **Aplică și repornește telefonul**.

## Limbă {#language}

Lista derulantă alege limba interfeței; implicit este **Ca acest calculator**. Este vorba doar de interfață. Limba vorbită într-un apel este o setare separată și vine odată cu transcrierile — consultați [Transcriere](/ai-processing/transcription#language).

Instrucțiunile, regulile și dicționarele venite cu programul rămân în limba lor atunci când o schimbați. **Restabilește valorile implicite** din [Prelucrare](/ai-processing/processing#defaults) și din [Dicționare](/ai-processing/dictionaries#defaults) le aduce în limba nouă.

## Temă {#theme}

Lista derulantă alege tema luminoasă sau întunecată; implicit este **Ca acest calculator**. Atât limba, cât și tema au efect imediat, atât în timpul unui apel, cât și în afara lui.

## Pictograme {#icons}

Două liste derulante stabilesc imaginile de pe butoanele de apel: prima stilul (**Plin** în imagine), a doua dimensiunea (**Normal**). Este o chestiune de gust: ambele stiluri sunt aceleași desene, iar dimensiunea schimbă cât de mari sunt desenate, nu ce desen se folosește.
