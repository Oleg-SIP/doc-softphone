**Einstellungen → Aufnahme** legt fest, welche Anrufe zu Aufnahmen werden und wie lange die Dateien bleiben. Ein aufgenommener Anruf erscheint im [Aufnahmefenster](/interface/recordings).

<Shot name="09_settings_recording" alt="Einstellungen → Aufnahme" />

## Aufnahme {#recording}

Die Auswahlliste legt fest, welche Anrufe aufgenommen werden:

| Auswahl | Nimmt auf |
| --- | --- |
| **Von Hand** | Nur, wenn Sie auf der Gesprächskarte die Aufnahme drücken. Der Standard. |
| **Bei jedem Anruf fragen** | Das Telefon fragt bei jedem Anruf, ob er aufgenommen werden soll. |
| **Jeder Anruf** | Jeden angenommenen Anruf, von selbst. Im Bild gewählt. |
| **Ausgewählte Leitungen** | Die Anrufe auf den Konten, die Sie in der erscheinenden Liste ankreuzen. |

Die Aufnahme beginnt, wenn das Gespräch angenommen wird, und nie davor, das Klingeln und die von Ihnen gewählten Nummern stehen also nicht in der Datei. Ein Anruf ist eine Stereodatei: Sie auf einem Kanal und alle anderen auf dem anderen.

## Zustimmung {#consent}

Die Auswahlliste legt fest, wie die Gegenseite von der Aufnahme erfährt:

| Auswahl | Was die Gegenseite hört |
| --- | --- |
| **Eine Ansage** | Eine kurze Nachricht, wenn die Aufnahme beginnt. Der Standard. **Wählen…** nimmt eine eigene Tondatei; *ist nichts gewählt, spielt das Telefon einen kurzen Ton*. |
| **Alle paar Sekunden ein Ton** | Einen Piepton im Abstand, den Sie mit dem Schieberegler einstellen. |
| **Überhaupt nichts** | Nichts. Im Bild gewählt. |

**Den Hinweis in der Aufnahme behalten** — Ansage und Ton werden den Menschen im Gespräch vorgespielt; schalten Sie dies ein, und sie stehen auch in der Datei.

:::caution
Vielerorts — in weiten Teilen Europas und in mehreren US-Bundesstaaten — ist es rechtswidrig, ein Gespräch aufzunehmen, ohne es der Gegenseite zu sagen. Das ist Ihre Entscheidung, und das Programm sagt es auch unter der Auswahlliste.
:::

## Konferenzen {#conferences}

**Eine Datei je Person**, standardmäßig an. In einer Konferenz ist der zweite Kanal eine Mischung aus allen, deshalb ist eine zusätzliche Datei je Person das, was ein Transkript sagen lässt, wer was gesagt hat.

## Aufbewahrung {#retention}

<Shot name="09b_settings_recording_scrolled" alt="Einstellungen → Aufnahme: Aufbewahrung" />

| Einstellung | Standard | Was sie begrenzt |
| --- | --- | --- |
| **Aufbewahrungsdauer** | Immer | Wie lange eine Aufnahme aufbewahrt wird. |
| **Speichergrenze** | Keine Grenze | Wie viel Platz alle Aufnahmen zusammen einnehmen dürfen. |
| **Dateien je Person** | Immer | Wie lange die zusätzlichen Dateien einer Konferenz aufbewahrt werden. |
| **Schwelle für freien Speicher** | 500 MB | Eine Untergrenze für den freien Platz auf der Festplatte. Aufnahmen, die Sie nicht angeheftet haben, können entfernt werden, um darüber zu bleiben. |

Eine von Ihnen angeheftete Aufnahme wird von keiner dieser Regeln gelöscht und zählt weiterhin zur Grenze. Eine Stunde Gespräch belegt etwa 30 MB.

Der Teil des Programms, der Anrufe aufnimmt und es der Gegenseite mitteilt, lässt sich unter [Module](/application/modules) abschalten.

Wie Sie eine Besprechung in einer anderen Anwendung aufnehmen, beschreibt [Mitschnitt](/capture/).
