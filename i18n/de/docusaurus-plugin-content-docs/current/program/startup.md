**Einstellungen → Start** legt fest, wie das Programm startet, was das Schließen seines Fensters bewirkt und was passiert, wenn Sie in einem anderen Programm auf eine Telefonnummer klicken.

<Shot name="15_settings_startup" alt="Einstellungen → Start" />

## Autostart {#autostart}

| Einstellung | Standard | Was sie bewirkt |
| --- | --- | --- |
| **Das Telefon beim Anmelden starten** | aus | Startet das Programm mit Ihrer Sitzung, sodass es Anrufe annimmt, sobald Sie sich hinsetzen. |
| **Minimiert starten, ohne Fenster** | aus | Startet es, ohne ein Fenster zu zeigen. Nur zusammen mit der Einstellung darüber verfügbar. |

## Schließung {#close}

**Das Telefon weiterlaufen lassen, wenn das Fenster geschlossen wird**, standardmäßig an. Ein geschlossenes Fenster ist kein aufgelegtes Telefon: Anrufe kommen weiter an, und das Symbol im Infobereich (auf macOS in der Menüleiste) holt das Fenster zurück. Schalten Sie das aus, beendet das Schließen des Fensters das Programm.

## Anruf-Links {#call-links}

Ein Link, der mit `tel:`, `callto:` oder `sip:` beginnt — eine Telefonnummer auf einer Webseite, in einer E-Mail oder in einem CRM —, kann von diesem Programm geöffnet werden.

- **Anruf-Links mit diesem Telefon öffnen** macht das Programm zu dem, das sie öffnet. Die Taste ist grau, wenn es das bereits ist.
- **Sofort anrufen, ohne Anrufen zu drücken** — standardmäßig aus. Eine angeklickte Nummer landet in der Wählhilfe und wartet dort; schalten Sie dies ein, um sie sofort zu wählen, wenn sie ankommt.
