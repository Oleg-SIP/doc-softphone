**Einstellungen → Tastenkürzel** listet die Tastenkürzel des Telefons auf.

<Shot name="16_settings_shortcuts" alt="Einstellungen → Tastenkürzel" />

| Aktion | Tastenkürzel unter macOS | **Überall** |
| --- | --- | --- |
| **Einen Anruf annehmen** | ⌃⌥A | aus |
| **Auflegen** | ⌃⌥E | aus |
| **Halten oder fortsetzen** | ⌃⌥H | aus |
| **Das Mikrofon stummschalten** | ⌃⌥M | aus |
| **Das Telefon zeigen oder ausblenden** | ⌃⌥S | an |

(⌃ ist Control und ⌥ ist Option.)

## Ein Tastenkürzel ändern {#changing-a-shortcut}

Klicken Sie auf das Kürzel und drücken Sie die neue Kombination. Ein weiterer Klick oder Escape löscht es.

**Überall** ist ein Kontrollkästchen neben jedem Kürzel. Aus — das Kürzel funktioniert, wenn das Telefon das Programm ist, das Sie gerade verwenden. An — es funktioniert aus jedem Programm: *Es nimmt die Kombination dem übrigen Desktop weg*, andere Programme bekommen sie also nicht mehr. Nur **Das Telefon zeigen oder ausblenden** ist standardmäßig global, weil es das Telefon von überall hervorholen muss.

**Voreinstellungen wiederherstellen** setzt alle fünf zurück.
