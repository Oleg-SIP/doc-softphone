title: Module

description: Die Teile, aus denen das Programm besteht, und wie sich jeder abschalten lässt.
---

**Einstellungen → Module** listet die Teile des Programms auf. *Alles, was dieses Telefon tut, ist eines davon.* Eines auszuschalten wirkt sofort und lässt liegen, was es bereits gespeichert hat.

<Shot name="19_settings_modules" alt="Einstellungen → Module" />

Jedes Modul hat ein Kontrollkästchen, einen Namen, eine Zeile, was es tut, und rechts seinen Zustand — **Läuft** für ein eingeschaltetes Modul. Die Kästchen der zwei Module, von denen der Rest abhängt, **Anwendung** und **Lokale Datenbank**, sind grau: Sie lassen sich nicht abschalten.

<Shot name="19b_settings_modules_scrolled" alt="Einstellungen → Module: der Rest der Liste" />

| Modul | Was es ist |
| --- | --- |
| **Anwendung** | Das Hauptfenster, die Einstellungen, die Symbole und so weiter. |
| **Lokale Datenbank** | Die als lokaler Speicher verwendete Datenbank. |
| **Browser-Oberfläche** | Einige Funktionen in einem lokalen Browser: die Seiten der [REST-API](/integration/rest-api). |
| **Tasten** | Die [Tasten](/sip-accounts/buttons) neben der Wählhilfe und die Lampen darauf. |
| **Mitschnitt** | [Ein Gespräch aufnehmen](/capture/), das in einer anderen Anwendung stattfindet. |
| **Diagnose** | SIP-Trace, Medienstatistik und Zähler: [Diagnose](/troubleshooting/diagnostics). |
| **Verzeichnisse** | Kategorien, Label und Auffälligkeiten — die Codes, auf die alles andere verweist: [Verzeichnisse](/ai-processing/dictionaries). |
| **Verzeichnis** | Das Adressbuch: [Kontakte](/interface/contacts-history). |
| **Integration** | Die lokale API und Webhooks: [Integration](/integration/rest-api). |
| **Medienspeicher** | Die Bibliothek der Gespräche und wie lange sie aufbewahrt werden: [Aufnahmen](/interface/recordings). |
| **Verarbeitung** | Prompts und die Regeln, die sie ausführen: [Verarbeitung](/ai-processing/processing). |
| **Aufnahme** | Anrufe aufnehmen und es der Gegenseite mitteilen: [Aufnahmen](/recordings). |
| **Telefon** | SIP, Konten, Anrufe, die Wählhilfe und die Anrufliste. |
| **Transkription** | Spracherkenner, die Warteschlange, die sie antreibt, und die Transkripte, die sie erzeugen: [Transkription](/ai-processing/transcription). |

Achten Sie auf die zwei ähnlichen Namen: **Verzeichnis** (Singular) ist das Adressbuch, **Verzeichnisse** (Plural) sind Kategorien, Label und Auffälligkeiten.

Schalten Sie ein Modul aus, ist es weg: keine Einstellungen dafür, kein Menüeintrag, nichts davon läuft. Schalten Sie ein Modul ab, das Sie nicht brauchen — zum Beispiel **Integration** auf einem Rechner, auf dem nichts anderes mit dem Telefon spricht —, oder behalten Sie ein Telefon, das nur ein Telefon ist, wenn ein Arbeitsplatz nicht mehr braucht. Das Paket ist in jedem Fall dasselbe: Es gibt nichts zu kaufen und nichts freizuschalten.
