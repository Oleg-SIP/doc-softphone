**Nastavitve → Moduli** navaja dele programa. *Vse, kar ta telefon počne, je eden od njih.* Izklop enega učinkuje takoj in pusti na mestu to, kar je že shranil.

<Shot name="19_settings_modules" alt="Nastavitve → Moduli" />

Vsak modul ima potrditveno polje, ime, vrstico o tem, kaj počne, na desni pa svoje stanje — **Teče** za vklopljen modul. Potrditveni polji dveh modulov, od katerih so odvisni drugi, **Aplikacija** in **Krajevna zbirka podatkov**, sta sivi: ni ju mogoče izklopiti.

<Shot name="19b_settings_modules_scrolled" alt="Nastavitve → Moduli: preostanek seznama" />

| Modul | Kaj je |
| --- | --- |
| **Aplikacija** | Glavno okno, nastavitve, ikone in tako naprej. |
| **Krajevna zbirka podatkov** | Zbirka podatkov, ki se uporablja kot krajevna shramba. |
| **Vmesnik v brskalniku** | Nekatere funkcije v krajevnem brskalniku: strani [REST API-ja](/integration/rest-api). |
| **Gumbi** | [Gumbi](/sip-accounts/buttons) poleg polja za klicanje in lučke na njih. |
| **Zajemanje** | [Snemanje pogovora](/capture/), ki teče v drugem programu. |
| **Diagnostika** | Sled SIP, statistika medijev in števci: [Diagnostika](/troubleshooting/diagnostics). |
| **Slovarji** | Kategorije, oznake in opozorilni znaki — kode, na katere kaže vse drugo: [Slovarji](/ai-processing/dictionaries). |
| **Imenik** | Imenik stikov: [Stiki](/interface/contacts-history). |
| **Integracija** | Krajevni API in webhooki: [Integracija](/integration/rest-api). |
| **Medijska shramba** | Knjižnica pogovorov in kako dolgo se hranijo: [Posnetki](/interface/recordings). |
| **Obdelava** | Navodila in pravila, ki jih sprožijo: [Obdelava](/ai-processing/processing). |
| **Snemanje** | Snemanje klicev in obveščanje druge strani o tem: [Snemanje klicev](/recordings/call-recording). |
| **Telefonija** | SIP, računi, klici, polje za klicanje in zgodovina klicev. |
| **Prepis** | Razpoznavalniki, vrsta, ki jih poganja, in prepisi, ki jih ustvarijo: [Prepis](/ai-processing/transcription). |

Izklopite modul in ga ni več: nobenih nastavitev zanj, nobenega vnosa v meniju, nič od njega ne teče. Izklopite modul, ki ga ne potrebujete — na primer **Integracija** na računalniku, kjer s telefonom nič drugega ne govori —, ali obdržite telefon, ki je samo telefon, če je to vse, kar delovno mesto potrebuje. Paket je v obeh primerih enak: ničesar ni treba kupiti ali odkleniti.
