**Nastavení → Moduly** uvádí části programu. *Vše, co tento telefon dělá, je jeden z nich.* Vypnutí modulu platí okamžitě a to, co už uložil, nechá na místě.

<Shot name="19_settings_modules" alt="Nastavení → Moduly" />

Každý modul má zaškrtávací políčko, název, řádek o tom, co dělá, a vpravo svůj stav — **Běží** u zapnutého modulu. Políčka dvou modulů, na kterých závisí ostatní, **Aplikace** a **Místní databáze**, jsou šedá: vypnout je nelze.

<Shot name="19b_settings_modules_scrolled" alt="Nastavení → Moduly: zbytek seznamu" />

| Modul | Co to je |
| --- | --- |
| **Aplikace** | Hlavní okno, nastavení, ikony a tak dále. |
| **Místní databáze** | Databáze používaná jako místní úložiště. |
| **Rozhraní prohlížeče** | Některé funkce v místním prohlížeči: stránky [REST API](/integration/rest-api). |
| **Tlačítka** | [Tlačítka](/sip-accounts/buttons) vedle vytáčení a kontrolky na nich. |
| **Zachytávání** | [Nahrávání hovoru](/capture/) probíhajícího v jiné aplikaci. |
| **Diagnostika** | SIP trasa, statistiky médií a čítače: [Diagnostika](/troubleshooting/diagnostics). |
| **Slovníky** | Kategorie, štítky a varovné signály — kódy, na které ukazuje vše ostatní: [Slovníky](/ai-processing/dictionaries). |
| **Adresář** | Kniha adres: [Kontakty](/interface/contacts-history). |
| **Integrace** | Místní API a webhooky: [Integrace](/integration/rest-api). |
| **Úložiště médií** | Knihovna rozhovorů a jak dlouho se uchovávají: [Nahrávky](/interface/recordings). |
| **Zpracování** | Pokyny a pravidla, která je spouštějí: [Zpracování](/ai-processing/processing). |
| **Nahrávání** | Nahrávání hovorů a oznámení druhé straně: [Nahrávání hovorů](/recordings/call-recording). |
| **Telefon** | SIP, účty, hovory, klávesnice a historie hovorů. |
| **Přepis** | Rozpoznávače, fronta, která je pohání, a přepisy, které vytvářejí: [Přepis](/ai-processing/transcription). |

Vypněte modul a je pryč: žádná jeho nastavení, žádná položka v nabídce, nic z něj neběží. Vypněte modul, který nepotřebujete — například **Integraci** na počítači, kde s telefonem nic jiného nemluví — nebo si nechte telefon, který je jen telefonem, pokud stůl nic víc nepotřebuje. Balíček je tak jako tak stejný: nic se nekupuje a nic se neodemyká.
