**Nastavenia → Moduly** uvádza časti programu. *Všetko, čo tento telefón robí, je jeden z nich.* Vypnutie jedného platí okamžite a to, čo už uložil, nechá na mieste.

<Shot name="19_settings_modules" alt="Nastavenia → Moduly" />

Každý modul má začiarkavacie políčko, názov, riadok o tom, čo robí, a vpravo svoj stav — **Beží** pre zapnutý modul. Začiarkavacie políčka dvoch modulov, od ktorých závisia ostatné, **Aplikácia** a **Miestna databáza**, sú sivé: nedajú sa vypnúť.

<Shot name="19b_settings_modules_scrolled" alt="Nastavenia → Moduly: zvyšok zoznamu" />

| Modul | Čo to je |
| --- | --- |
| **Aplikácia** | Hlavné okno, nastavenia, ikony a tak ďalej. |
| **Miestna databáza** | Databáza používaná ako miestne úložisko. |
| **Rozhranie prehliadača** | Niektoré funkcie v miestnom prehliadači: stránky [REST API](/integration/rest-api). |
| **Tlačidlá** | [Tlačidlá](/sip-accounts/buttons) vedľa poľa na vytáčanie a kontrolky na nich. |
| **Zachytávanie** | [Nahrávanie rozhovoru](/capture/) prebiehajúceho v inej aplikácii. |
| **Diagnostika** | Sledovanie SIP, štatistiky médií a počítadlá: [Diagnostika](/troubleshooting/diagnostics). |
| **Slovníky** | Kategórie, štítky a varovné signály — kódy, na ktoré ukazuje všetko ostatné: [Slovníky](/ai-processing/dictionaries). |
| **Adresár** | Adresár kontaktov: [Kontakty](/interface/contacts-history). |
| **Integrácia** | Miestne API a webhooky: [Integrácia](/integration/rest-api). |
| **Úložisko médií** | Knižnica rozhovorov a ako dlho sa uchovávajú: [Nahrávky](/recordings/recordings-window). |
| **Spracovanie** | Pokyny a pravidlá, ktoré ich spúšťajú: [Spracovanie](/ai-processing/processing). |
| **Nahrávanie** | Nahrávanie hovorov a upozornenie druhej strany: [Nahrávanie hovorov](/recordings/call-recording). |
| **Telefónia** | SIP, účty, hovory, pole na vytáčanie a história hovorov. |
| **Prepis** | Rozpoznávače, front, ktorý ich poháňa, a prepisy, ktoré vytvárajú: [Prepis](/ai-processing/transcription). |

Vypnite modul a je preč: žiadne jeho nastavenia, žiadna položka v ponuke, nič z neho nebeží. Vypnite modul, ktorý nepotrebujete — napríklad **Integrácia** na počítači, kde s telefónom nič iné nekomunikuje — alebo si nechajte telefón, ktorý je len telefónom, ak je to všetko, čo pracovné miesto potrebuje. Balík je v oboch prípadoch rovnaký: nie je čo kupovať ani odomykať.
