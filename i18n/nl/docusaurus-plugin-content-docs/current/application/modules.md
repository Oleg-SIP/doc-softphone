**Instellingen → Modules** toont de onderdelen van het programma. *Alles wat deze telefoon doet is een van deze.* Er een uitzetten werkt meteen en laat staan wat hij al heeft opgeslagen.

<Shot name="19_settings_modules" alt="Instellingen → Modules" />

Elke module heeft een vakje, een naam, een regel die zegt wat ze doet, en rechts haar toestand — **Draait** voor een module die aan staat. De vakjes van de twee modules waar de rest van afhangt, **Toepassing** en **Lokale database**, zijn grijs: die kunnen niet worden uitgezet.

<Shot name="19b_settings_modules_scrolled" alt="Instellingen → Modules: de rest van de lijst" />

| Module | Wat het is |
| --- | --- |
| **Toepassing** | Het hoofdvenster, de instellingen, de pictogrammen enzovoort. |
| **Lokale database** | De database die als lokale opslag wordt gebruikt. |
| **Browserinterface** | Enkele functies in een lokale browser: de pagina's van de [REST-API](/integration/rest-api). |
| **Knoppen** | De [knoppen](/sip-accounts/buttons) naast de kiezer, en de lampjes erop. |
| **Vastleggen** | [Een gesprek opnemen](/capture/) dat in een andere toepassing plaatsvindt. |
| **Diagnose** | Het SIP-spoor, de mediastatistieken en de tellers: [Diagnose](/troubleshooting/diagnostics). |
| **Woordenlijsten** | Categorieën, labels en signalen — de codes waar al het andere naar verwijst: [Woordenlijsten](/ai-processing/dictionaries). |
| **Adresboek** | Het adresboek: [Contacten](/interface/contacts-history). |
| **Integratie** | De lokale API en webhooks: [Integratie](/integration/rest-api). |
| **Media-opslag** | De bibliotheek met gesprekken en hoelang ze bewaard blijven: [Opnames](/recordings/recordings-window). |
| **Verwerking** | Prompts en de regels die ze laten vuren: [Verwerking](/ai-processing/processing). |
| **Opname** | Gesprekken opnemen, en de andere partij daarover inlichten: [Gesprekken opnemen](/recordings/call-recording). |
| **Telefonie** | SIP, accounts, gesprekken, de kiezer en de gesprekgeschiedenis. |
| **Transcriptie** | Herkenners, de wachtrij die ze aanstuurt, en de transcripten die ze maken: [Transcriptie](/ai-processing/transcription). |

Zet een module uit en ze is weg: geen instellingen meer, geen menu-item, niets ervan draait nog. Zet een module uit waar u niets aan hebt — bijvoorbeeld **Integratie** op een computer waar niets anders met de telefoon praat — of houd een telefoon die alleen een telefoon is, als dat alles is wat een werkplek nodig heeft. Het pakket is in beide gevallen hetzelfde: er valt niets te kopen en niets te ontgrendelen.
