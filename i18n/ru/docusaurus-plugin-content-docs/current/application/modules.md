**Настройки → Модули** перечисляют части программы. *Всё, что умеет этот телефон, — одна из них.* Выключение действует сразу и оставляет всё, что модуль уже сохранил, на месте.

<Shot name="19_settings_modules" alt="Настройки → Модули" />

У каждого модуля есть флажок, название, строка о том, что он делает, и справа состояние — **Работает** у включённого модуля. Флажки двух модулей, от которых зависят остальные, — **Приложение** и **Локальная база** — серые: их выключить нельзя.

<Shot name="19b_settings_modules_scrolled" alt="Настройки → Модули: остальная часть списка" />

| Модуль | Что это |
| --- | --- |
| **Приложение** | Главное окно, настройки, значки и прочее. |
| **Локальная база** | База данных, используемая как локальное хранилище. |
| **Адресная книга** | Адресная книга: [Контакты](/interface/contacts-history). |
| **Диагностика** | Трассировка SIP, статистика медиа и счётчики: [Диагностика](/troubleshooting/diagnostics). |
| **Запись** | Запись звонков и предупреждение собеседника об этом: [Запись звонков](/recordings/call-recording). |
| **Интеграция** | Локальный API и вебхуки: [Интеграция](/integration/rest-api). |
| **Интерфейс в браузере** | Часть возможностей в локальном браузере: страницы [REST API](/integration/rest-api). |
| **Кнопки** | [Кнопки](/sip-accounts/buttons) рядом с номеронабирателем и лампы на них. |
| **Обработка** | Промпты и правила, которые их запускают: [Обработка](/ai-processing/processing). |
| **Перехват** | [Запись разговора](/capture/), который идёт в другом приложении. |
| **Расшифровка** | Распознаватели (в том числе Yandex SpeechKit), очередь, которая их запускает, и стенограммы, которые они формируют: [Расшифровка](/ai-processing/transcription). |
| **Справочники** | Категории, метки и красные флаги — коды, на которые указывает всё остальное: [Справочники](/ai-processing/dictionaries). |
| **Телефон** | SIP, учётные записи, звонки, наборная панель и журнал звонков. |
| **Хранилище записей** | Библиотека разговоров и то, сколько они хранятся: [Записи](/recordings/recordings-window). |

Выключенного модуля нет: ни настроек, ни пункта меню, ничего из него не работает. Выключите модуль, который вам не нужен, — например, **Интеграцию** на компьютере, где с телефоном больше ничто не общается, — или оставьте телефон просто телефоном, если столу больше ничего не нужно. Пакет при этом один и тот же: ничего не нужно покупать и ничего не нужно разблокировать.
