**Контакты** и **История** открываются в одном окне, **Контакты и звонки**, в виде двух вкладок. Окно стоит рядом с телефоном, поэтому номер можно найти прямо во время разговора.

![Контакты](https://ai-softphone.com/screenshots/macos/ru/light/directory.png)

## Контакты

- **Поиск** отбирает записи по мере ввода.
- **Добавить** создаёт контакт.
- У каждого контакта есть имя и номер. Входящий звонок с известного номера показывается с именем контакта — так работает определение звонящего.

## История

Журнал звонков, новые сверху. В нём входящие, исходящие, пропущенные и отклонённые звонки. Пропущенные и отклонённые можно получить и через [локальный REST API](../integration/rest-api.md) (`/history?missed=true`, `/history?declined=true`).
