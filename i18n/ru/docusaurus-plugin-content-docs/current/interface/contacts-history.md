**Контакты** и **История** открываются двумя вкладками справа от телефона, так что номер можно найти прямо во время разговора.

## Контакты {#contacts}

<Shot name="03_contacts" alt="Вкладка «Контакты»" />

- **Поиск** фильтрует список по мере ввода.
- **Добавить** создаёт контакт.
- Каждый контакт показан с именем, а под ним — номер и учётная запись, через которую ему звонят, например *231 · 201 Офис*.

Входящий звонок с известного номера показывает имя контакта, так же как списки последних звонков и журнал, — так работает определение звонящего.

### Изменение контакта {#editing-a-contact}

<Shot name="03b_contact_edit" alt="Контакт открыт для изменения" />

Выберите контакт — справа в его строке появятся карандаш и трубка. Трубка звонит контакту; карандаш открывает форму под строкой:

| Поле | Что вводить |
| --- | --- |
| **Имя** | Как показывать контакт. |
| **Номер** | Номер для набора. |
| Список под **Номером** | Учётная запись, через которую звонят контакту. |

**Сохранить** сохраняет изменения, **Отмена** отбрасывает их, **Удалить** удаляет контакт.

## История {#history}

<Shot name="21_history" alt="Вкладка «История»" />

Журнал звонков, новые сверху. Вверху:

- список, по умолчанию **Все звонки**, сужает журнал до одного вида звонков;
- **Поиск** фильтрует по введённому тексту.

У каждой записи есть значок вида звонка — исходящая трубка или красная трубка для пропущенного, — имя собеседника (или номер), а под ним дата, итог звонка, длительность, номер и учётная запись. Недавние звонки показываются как *Вчера, 22:33* или днём недели, более старые — датой.

| Итог звонка | Как показан |
| --- | --- |
| Вы поговорили | **Исходящий** или входящий и длительность, например *48 с* |
| На входящий звонок не ответили | **Пропущенный** |
| Ваш звонок не соединился | **Занято или отклонено** |

Выберите запись — справа появятся кнопки:

| Кнопка | Что делает |
| --- | --- |
| Человек с плюсом | Добавляет номер в [Контакты](#contacts). |
| ▶ | Проигрывает запись звонка, если он записывался. |
| Корзина | Удаляет запись журнала. |
| Трубка | Перезванивает по номеру. |

### Сколько хранится журнал {#how-long-the-log-is-kept}

Журнал звонков — это доказательство, поэтому из него ничего не удаляется, пока вы сами не скажете: по умолчанию хранятся все звонки. Срок хранения и кнопка **Очистить журнал звонков** находятся в [Настройках звонков](../sip-accounts/calls.md#history).

Пропущенные и отклонённые звонки можно читать и через [локальный REST API](../integration/rest-api.md) (`/history?missed=true`, `/history?declined=true`).
