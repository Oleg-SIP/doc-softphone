**Настройки** открывают окно со списком вкладок слева. Вкладки собраны в группы, отделённые линиями.

| Группа | Вкладка | Что в ней |
| --- | --- | --- |
| Телефония | **Учётные записи** | SIP-аккаунты: [Настройка SIP-аккаунта](../sip-accounts/setup.md) |
| | **Устройства** | [Микрофон, динамики, мелодия звонка и прочие звуки](../sip-accounts/devices.md) |
| | **Звонки** | Поведение при звонках и приоритет кодеков |
| | **Кнопки** | Кнопки, следящие за другими внутренними номерами (BLF) |
| | **Запись** | Запись звонков |
| | **Перехват** | [Внешняя запись](../capture/capture.md) встреч в других приложениях |
| ИИ | **Обработка** | [Автоматическая обработка, лимиты расходов, языковые модели и промпты](../ai-processing/processing.md) |
| | **Расшифровка** | [Распознаватели](../ai-processing/transcription.md) |
| | **Справочники** | [Категории, метки и красные флаги](../ai-processing/dictionaries.md) |
| Программа | **Оформление** | Язык интерфейса и тема (светлая или тёмная); меняются без перезапуска |
| | **Запуск** | Как запускается программа |
| | **Горячие клавиши** | Сочетания клавиш |
| | **Интеграция** | [Локальный REST API и вебхуки](../integration/rest-api.md) |
| | **Диагностика** | Уровень диагностики; см. [Диагностика](../troubleshooting/diagnostics.md) |
| | **Модули** | Необязательные части программы |

:::note
Вкладки **Звонки**, **Кнопки**, **Запись**, **Перехват**, **Оформление**, **Запуск**, **Горячие клавиши** и **Модули** пока не описаны подробно.
:::
