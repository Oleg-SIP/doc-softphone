**Настройки** открываются вкладкой справа от телефона, со списком вкладок настроек у левого края. Список разбит на группы линиями: **Сводка** отдельно, затем телефония, ИИ, сама программа и в конце **Модули** и **О программе**.

## Сводка {#overview}

<Shot name="04_settings_overview" alt="Настройки → Сводка: чек-лист того, что уже настроено" />

**Сводка** — чек-лист того, что нужно, чтобы получить от программы всё. Вверху посчитаны шаги — на картинке *10 шагов сделано* с зелёной точкой и *8 шагов осталось* с красной, — а полоса показывает долю сделанного. Каждый шаг — строка с точкой: зелёной для сделанного шага, красной для ещё не сделанного.

*Нажмите на строку, чтобы прочитать, зачем она нужна, и открыть, где это настраивается.* Стрелка в правом конце строки раскрывает её.

| Группа | Шаги |
| --- | --- |
| **Звонки** | Добавить учётную запись; Позвонить; Ответить на звонок; Записать звонок |
| **Перехват из других приложений** | Включить перехват; Перехватить разговор; Дать записи имя |
| **Расшифровка** | Добавить распознаватель; Расшифровать разговор |
| **Обработка** | Добавить модель; Обработать стенограмму |
| **Записи** | Поиск по сказанному; Выгрузить запись; Выгрузить содержание |
| **Приложение** | Запускать вместе с компьютером; Держать в актуальном состоянии |
| **Обратная связь** | Отправлять расширенный отчёт; Рассказать нам впечатление |

<Shot name="04b_settings_overview_scrolled" alt="Остальная часть чек-листа «Сводка»" />

Шаги — подсказка, а не обязанность: шаг, который вам не нужен, может оставаться красным.
