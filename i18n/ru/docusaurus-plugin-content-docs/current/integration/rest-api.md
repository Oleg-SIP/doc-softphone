У AI Softphone есть REST API для CTI-интеграции: программа на том же компьютере может управлять телефоном, читать контакты и историю звонков, управлять учётными записями и следить за активными звонками. Облачный посредник и SDK не нужны.

API **по умолчанию выключен**: пока вы его не включите, ничего не слушает. Когда он включён, он слушает только интерфейс loopback, поэтому из сети недоступен.

## Как включить

Откройте **Настройки → Интеграция** и в разделе **Локальное управление (REST API)**:

1. Включите **Разрешить другим программам на этом компьютере управлять телефоном**.
2. Оставьте порт по умолчанию, `8377`, если он не занят.
3. При желании задайте **токен API**.
4. Выберите группы доступа, которые нужно открыть: **Контакты**, **История**, **Звонки**, **Учётные записи**, **Настройки**, **Метрики**.

Отдельную службу устанавливать не нужно, перезапуск не требуется.

Базовый адрес — `http://127.0.0.1:8377`. Любой запрос к группе, которая не включена, получает ответ `404 {"error":"no such endpoint"}`.

## Аутентификация

- Токен хранится в хранилище ключей операционной системы, а не в файле настроек.
- Запросы на запись должны передавать его в заголовке `Authorization`.
- Без токена любая программа на компьютере может читать включённые группы и управлять активными звонками (отвечать, завершать, ставить на удержание, переводить, посылать DTMF). Задайте токен, чтобы другие программы этого не делали.

## Методы

| Метод | Путь | Что делает |
| --- | --- | --- |
| GET | `/accounts` | SIP-аккаунты и состояние их регистрации. Пароли никогда не возвращаются. |
| GET | `/calls` | Активные звонки и их состояние. |
| POST | `/calls` | Начинает звонок: `{"number": "...", "account_id": "..."}` (`account_id` необязателен). |
| POST | `/calls/{id}/answer` | Отвечает на входящий звонок. |
| POST | `/calls/{id}/hangup` | Завершает звонок. |
| POST | `/calls/{id}/hold` | Ставит звонок на удержание. |
| POST | `/calls/{id}/resume` | Снимает звонок с удержания. |
| POST | `/calls/{id}/dtmf` | Посылает тоны: `{"digits": "..."}`. |
| POST | `/calls/{id}/transfer` | Переводит звонок: `{"target": "..."}`. |
| GET | `/contacts` | Контакты. |
| GET | `/contacts/{id}` | Один контакт. |
| GET | `/history` | Журнал звонков, новые сверху. Принимает `?limit=`, `?missed=true` и `?declined=true`. |
| GET | `/settings` | Вся конфигурация, без секретов. |
| GET | `/metrics` | Счётчики в формате Prometheus. |
| GET | `/taxonomy` | Категории, метки и красные флаги с их кодами. |
| GET | `/ui` | Список записей в виде HTML-страницы. |
| GET | `/ui/recordings/{id}` | Запись с расшифровкой в виде HTML-страницы. |
| GET | `/ui/recordings/{id}/audio` | Звук для страницы выше. |

Каждый идентификатор — UUID, выданный телефоном: `id` звонка берётся из `/calls` или из ответа на `POST /calls`, `id` учётной записи — из `/accounts`.

Имена полей записываются в snake_case, а окончание указывает тип: `_id` — ссылка на UUID, `_ts` — момент времени в миллисекундах Unix (UTC), `_s` — длительность в секундах.

Записи отдаются HTML-страницами, а не JSON: вместо передачи звука давайте в CRM ссылки на эти страницы.

## Ошибки

Любая ошибка — JSON с единственным ключом `error`: `{"error": "что пошло не так"}`; сообщение предназначено для человека, а не для разбора программой. Статус — `400` для неверного запроса и `404` для пути, которого нет или группа доступа которого выключена (ответ в обоих случаях одинаков намеренно), а также для контакта или звонка, которых нет (звонок мог уже завершиться). Отклонённые запросы учитываются в `api_requests_refused_total`.

## Классификатор и настройки

У каждого элемента `/taxonomy` есть постоянный `code`, `title` и `description` на языке интерфейса, `kind` и, у красных флагов, `severity`. **Сопоставляйте по `code`, а не по `title`**: названия возвращаются на языке, выбранном в телефоне. `retired: true` отмечает элемент, сохранённый для корректного отображения старых звонков; новым звонкам он больше не присваивается.

`/settings` возвращает конфигурацию без секретов: звуковые устройства и громкость, приоритет кодеков, оформление и язык, запуск, горячие клавиши, уровень диагностики и состояние обеих интеграций. `api.disabled` содержит выключенные группы доступа, `webhooks.silenced` — выключенные события; пустые списки означают, что всё включено. Пароль SIP, токен API и значение заголовка вебхука в ответ не входят никогда.

## Метрики

`calls_incoming_total`, `calls_outgoing_total`, `calls_answered_total`, `calls_missed_total`, `calls_declined_total`, `webhooks_delivered_total`, `webhooks_failed_total`, `webhooks_dropped_total`, `api_requests_total`, `api_requests_refused_total`.

## Пример: звонок по клику

```javascript
async function dial(number) {
  const r = await fetch("http://127.0.0.1:8377/calls", {
    method: "POST",
    headers: { "Content-Type": "application/json" },
    body: JSON.stringify({ number }),
  });
  if (!r.ok) console.warn("softphone:", (await r.json()).error);
}
```
