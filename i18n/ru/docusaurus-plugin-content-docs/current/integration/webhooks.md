Вебхуки сообщают другой системе о звонках по мере их появления — например, чтобы CRM открыла карточку клиента до второго гудка. Входящие правила межсетевого экрана не нужны, и по умолчанию они **выключены**.

## Как включить

В **Настройки → Интеграция**, в разделе **Вебхуки**:

1. Укажите **адрес**, на который нужно отправлять события.
2. Выберите метод, **POST** или **GET**.
3. Выберите, какие события отправлять.
4. При желании задайте собственный заголовок — имя и значение, — который проверит ваш приёмник. Значение хранится в хранилище ключей операционной системы.
5. Нажмите **Отправить тестовое событие**, чтобы убедиться, что оно доходит.

## События

| Событие | Когда отправляется |
| --- | --- |
| `call-started` | Входящий звонок начал звонить или совершён исходящий. |
| `call-state-changed` | Изменилось состояние звонка (`state`): на него ответили, поставили на удержание или сняли с удержания. |
| `call-ended` | Звонок завершён. |

## Что отправляется

```json
{
  "event": "call-started",
  "id": "5b1c0a6e-0c7e-4c53-9f57-2c4f1f0d6a11",
  "direction": "in",
  "state": "ringing-in",
  "number": "+15551234567",
  "name": "Jane Miller",
  "uri": "sip:+15551234567@pbx.example.com",
  "account": "1001@pbx.example.com",
  "account_id": "0d7a4c52-6f2e-4a51-8f46-7d9a3e1b2c90",
  "event_ts": "1788788890412",
  "callstart_ts": "1788788890398",
  "callstate_ts": "1788788890398",
  "duration_s": "0",
  "seance_id": "e3f0b9f4-1a2c-4d8b-9c35-6a7b8c9d0e1f"
}
```

**Все значения — строки**, включая числа и время.

| Поле | Значение |
| --- | --- |
| `event` | `call-started`, `call-state-changed` или `call-ended`. |
| `id` | Звонок. |
| `direction` | `in` или `out`. |
| `state` | `dialing`, `ringing-out`, `ringing-in`, `active`, `hold`, `onhold`, `conference` или `ended`. |
| `number`, `name`, `uri` | Собеседник. |
| `account`, `account_id` | Учётная запись, на которой идёт звонок. |
| `event_ts`, `callstart_ts`, `callstate_ts` | Время Unix в миллисекундах (UTC). |
| `duration_s` | Длительность звонка в секундах. |
| `reason` | Почему звонок завершён: `local-hangup`, `remote-hangup`, `busy`, `no-answer` или `cancelled`. |
| `answered_by` | `no`, если на звонок не ответили, иначе — кто ответил. |
| `seance_id` | Идентификатор разговора. |

Имена подчиняются одному правилу: `_id` — идентификатор, `_ts` — время Unix в миллисекундах, `_s` — длительность в секундах.

Счётчики `webhooks_delivered_total`, `webhooks_failed_total` и `webhooks_dropped_total` [REST API](rest-api.md) показывают, как идёт доставка.
