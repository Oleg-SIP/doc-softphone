**Настройки → Звонки** содержат настройки, которые относятся к каждому звонку, на какой бы учётной записи он ни шёл.

## Аудиоформаты {#audio-formats}

<Shot name="07_settings_calls" alt="Настройки → Звонки: аудиоформаты" />

Список кодеков, которые телефон предлагает другой стороне. Кодеки *предлагаются в этом порядке*, а другая сторона выбирает из предложенного: чем выше кодек, тем вероятнее, что он будет использован.

- **Флажок** включает или выключает кодек. Выключенный кодек не предлагается.
- **▲** и **▼** двигают его вверх и вниз по списку.
- *широкополосный* справа отмечает кодек с более широким диапазоном звука, чем у телефонной линии: голос звучит чище.

| Кодек | Частота дискретизации | Включён по умолчанию |
| --- | --- | --- |
| **opus** | 48 кГц, стерео, широкополосный | да |
| **G722** | 16 кГц, широкополосный | да |
| **PCMU** | 8 кГц | да |
| **PCMA** | 8 кГц | да |
| **speex** | 16 кГц, широкополосный | нет |
| **speex** | 8 кГц | нет |
| **speex** | 32 кГц, широкополосный | нет |
| **iLBC** | 8 кГц | нет |
| **GSM** | 8 кГц | нет |
| **L16** | 44 кГц, стерео, широкополосный | нет |
| **L16** | 44 кГц, широкополосный | нет |

Таблица — в том порядке, в каком программа поставляется.

Кодеки согласуются при установлении звонка, поэтому изменение действует со следующего звонка. Если звонок звучит плохо, оставьте включёнными только кодеки, которые использует ваша АТС.

## Ожидание вызова {#call-waiting}

<Shot name="07b_settings_calls_scrolled" alt="Настройки → Звонки: ожидание вызова, автодозвон и история" />

*Что происходит, когда вам звонят, пока вы уже разговариваете.* Выбирается в выпадающем списке; по умолчанию — **Звонить вторым вызовом**. Интерком с собственной станции проходит всегда, что бы вы ни выбрали, — именно так до этого телефона доходит звонок, поставленный с CTI-панели.

## Автодозвон {#autodial}

Если звонок не проходит, на его карточке появляется кнопка дозвона — телефон будет набирать номер, пока не дозвонится. Два ползунка задают, как именно:

- **Пауза между попытками** — по умолчанию 15 секунд;
- **Прекращать через** — по умолчанию 30 минут.

## История {#history}

Журнал звонков — это доказательство, поэтому из него ничего не удаляется, пока вы не укажете это здесь.

- **Срок хранения** выбирает, сколько [журнал звонков](/interface/contacts-history#history) хранит звонок. По умолчанию — **Всегда**.
- **Очистить журнал звонков** удаляет все звонки сразу, независимо от срока выше. Отменить это нельзя.
