Кнопки — это клавиши **BLF** (Busy Lamp Field) софтфона, та же функция, что у настольного телефона на IP-АТС. Кнопка набирает внутренний номер одним нажатием. Кнопка, которая следит за своей линией, ещё и показывает лампу: телефон спрашивает АТС об этом номере и показывает, свободен ли он, звонит или занят, — как это делают консоль секретаря или программируемые клавиши настольного телефона.

BLF требует поддержки со стороны АТС: станция должна сообщать телефону состояние номера. Большинство IP-АТС это умеют. Если ваша не умеет, лампа остаётся серой, а кнопка всё равно набирает номер.

Кнопки стоят под плашками учётных записей в [главном окне](/interface/main-window), а создаются в разделе **Настройки → Кнопки**.

<Shot name="08_settings_buttons" alt="Настройки → Кнопки: две кнопки" />

Каждая строка — кнопка: лампа, подпись, а справа номер и учётная запись, к которой она относится, например *212 · 201 Офис*. **▲** и **▼** двигают кнопку вверх и вниз; кнопки в главном окне идут в этом же порядке. **Добавить** создаёт новую.

## Лампа {#the-lamp}

Кнопка, которая следит за своей линией, показывает лампу:

| Лампа | Линия |
| --- | --- |
| Зелёная | свободна |
| Жёлтая | звонит |
| Красная | идёт разговор |
| Серая | неизвестно: станция не отвечает |

## Добавление кнопки {#adding-a-button}

<Shot name="08b_button_add" alt="Форма новой кнопки" />

Нажмите **Добавить** — под списком откроется форма.

| Поле | Что вводить |
| --- | --- |
| **Номер** | Номер для набора. |
| **Линия** | Учётная запись, с которой идёт звонок. Выберите её первой: чтобы показать лампу, телефон спрашивает о номере станцию именно этой линии, поэтому ему нужно знать, какую. |
| **Подпись** | Текст на кнопке, например имя человека. Места на кнопке хватает только для короткой подписи; длинная обрезается. |
| **Показывать занятость линии** | Переключатель. Включён — у кнопки есть лампа. Выключен — она только набирает номер. |

**Сохранить** остаётся серой, пока форма не заполнена. **Отмена** закрывает форму.

Часть программы, которая показывает кнопки, можно отключить в [Модулях](/application/modules).
