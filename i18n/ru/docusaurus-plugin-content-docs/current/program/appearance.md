**Настройки → Оформление** меняют внешний вид программы и расположение её окон.

<Shot name="14_settings_appearance" alt="Настройки → Оформление" />

## Раскладка {#layout}

Шесть вариантов, каждый нарисован маленькой картинкой; выбранный обведён рамкой.

| Раскладка | |
| --- | --- |
| **Два окна** | Телефон в одном окне, всё остальное — в другом. |
| **Несколько окон** | Телефон и отдельное окно для каждого из остальных разделов. |
| **Компактный** | Маленький телефон и окно рядом с ним. |
| **Одно окно** | Телефон и всё остальное в одном окне. В этой раскладке сделаны скриншоты документации. |
| **Полоса** | Телефон полосой вдоль края экрана, а окно под ней. |
| **Только трей** | Окна нет, пока вы не вызовете его из трея или [горячей клавишей](/program/shortcuts). |

*Во всех раскладках одни и те же окна; различается только то, где они стоят. Чтобы её сменить, телефон закроется и откроется снова* — кнопкой **Применить и перезапустить телефон**.

## Язык {#language}

Выпадающий список выбирает язык интерфейса; по умолчанию — **Как на этом компьютере**. Это только интерфейс. *Язык, на котором говорят в разговоре, — отдельная настройка, она появляется вместе со стенограммами*, — см. [Расшифровка](/ai-processing/transcription#the-recognisers-card).

Промпты, правила и справочники, пришедшие с программой, при смене языка остаются на прежнем. **Восстановить по умолчанию** в [Обработке](/ai-processing/processing#defaults) и в [Справочниках](/ai-processing/dictionaries#defaults) переводит их на новый.

:::tip
Русский язык интерфейса и страна — разные настройки. Чтобы в списках распознавателей и моделей появились Yandex SpeechKit и YandexGPT, выберите страну **Россия** в разделе [О программе](/application/about#version-and-country).
:::

## Тема {#theme}

Выпадающий список выбирает светлую или тёмную тему; по умолчанию — **Как на этом компьютере**. *Обе настройки действуют сразу — и во время звонка, и вне его.*

## Значки {#icons}

Два выпадающих списка задают картинки на кнопках звонка: первый — стиль (**Заливка** на картинке), второй — размер (**Обычные**). Это дело вкуса: оба варианта — одни и те же рисунки, а размер меняет, насколько крупно они нарисованы, а не какой рисунок используется.
