**Настройки → Горячие клавиши** перечисляют сочетания клавиш телефона.

<Shot name="16_settings_shortcuts" alt="Настройки → Горячие клавиши" />

| Действие | Сочетание в macOS | **Везде** |
| --- | --- | --- |
| **Ответить на звонок** | ⌃⌥A | выкл. |
| **Положить трубку** | ⌃⌥E | выкл. |
| **Удержать или снять с удержания** | ⌃⌥H | выкл. |
| **Выключить микрофон** | ⌃⌥M | выкл. |
| **Показать или скрыть телефон** | ⌃⌥S | вкл. |

(⌃ — Control, ⌥ — Option.)

## Изменение сочетания {#changing-a-shortcut}

*Щёлкните по сочетанию и нажмите клавиши; щелчок ещё раз — или Escape — очищает его.*

**Везде** — флажок рядом с каждым сочетанием. Выключен — сочетание работает, пока телефон — программа, с которой вы работаете. Включён — оно работает из любой программы: *«Везде» забирает сочетание у остального рабочего стола*, и другие программы его больше не получают. Глобальным по умолчанию сделано только **Показать или скрыть телефон**, потому что оно должно вызывать телефон откуда угодно.

**Восстановить по умолчанию** возвращает все пять.
