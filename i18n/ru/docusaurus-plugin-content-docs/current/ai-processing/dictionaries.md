**Настройки → Справочники** хранят слова, к которым разговор можно отнести, которыми его можно пометить или из-за которых поднять флаг. *Эти списки показываются моделям, и модели выбирают только из них* — поэтому ответ всегда можно потом найти.

<Shot name="13_settings_dictionaries" alt="Настройки → Справочники" />

**Показывать удалённые** показывает записи, которые вы удалили.

Каждая запись — название, короткий код мелким шрифтом и описание, которое подсказывает модели, когда её выбирать. Хранится и возвращается [REST API](../integration/rest-api.md#taxonomy-and-settings) именно код, поэтому он не меняется, когда вы переименовываете запись.

## Категории {#categories}

О чём был разговор; **выбирается одна на разговор**. В программе четыре категории:

| Название | Код | Для чего |
| --- | --- | --- |
| **Продажи** | `sales` | Продажа, расчёт стоимости, переговоры или продолжение сделки — включая вопрос клиента о том, сколько что-то стоит. |
| **Поддержка** | `support` | Помощь с продуктом или услугой, которые у человека уже есть: неисправность, вопрос по использованию, жалоба на то, как оно работает. |
| **Личное** | `personal` | Совсем не по делу — частный разговор, случившийся на этой линии. |
| **Прочее** | `other` | По делу, но не продажа и не поддержка: поставщик, коллега, доставка, ошиблись номером. Выбирайте это, а не гадайте между остальными. |

Нажмите **Добавить**, чтобы добавить свою категорию.

## Метки {#tags}

Ярлыки, *которые могут быть верны для одного разговора все сразу*. Нажмите **Добавить**, чтобы добавить метку. Список начинается с таких записей:

| Название | Код | Для чего |
| --- | --- | --- |
| **Обещан звонок** | `callback` | Кто-то на этом разговоре пообещал перезвонить или попросил, чтобы перезвонили ему. |
| **Жалоба** | `complaint` | Другая сторона выразила недовольство, независимо от того, решилось оно или нет. |
| **Передан дальше** | `escalation` | Разговор передали кому-то другому, или другая сторона об этом попросила. |
| **Важный клиент** | `vip` | С другой стороной обращались как с важным клиентом, или она сама так себя назвала. |

## Красные флаги {#red-flags}

То, что требует внимания, найденное в разговоре вместе с доказательством и временем. Красные флаги выделены красным в [окне записей](../interface/recordings.md), и у каждого есть важность: низкая, средняя или высокая.

| Название | Код | Важность | Когда поднимается |
| --- | --- | --- | --- |
| **Клиент рассержен** | `angry-customer` | высокая | Другая сторона была слышимо рассержена, переходила на оскорбления или угрожала уйти. |
| **Риск ухода** | `churn-risk` | высокая | Прозвучал отказ, непродление или переход к кому-то другому — сколь угодно спокойно. |
| **Дано обещание** | `promise-made` | средняя | Наша сторона пообещала что-то определённое — дату, цену, исправление, возврат. |
| **Чувствительные данные** | `sensitive-data` | высокая | Вслух назвали номер карты, пароль, номер документа или что-то ещё, чему не место в записи. |
| **Конкурент** | `competitor` | низкая | Другая сторона назвала кого-то ещё, кто предлагает то же самое, или сравнила нас с ним. |

## Указания {#instructions}

<Shot name="13b_settings_dictionaries_scrolled" alt="Настройки → Справочники: формы ответа и указания о языке" />

*Что добавляется к каждому промпту о форме ответа и языке, на котором его писать.* Они хранятся здесь, чтобы каждый промпт пользовался одной и той же формулировкой, и их можно менять, как любую другую запись, — или написать свои, например *отвечай кратко* или *никогда не называй цену*, и отметить их в **Отправлять ещё** у любого промпта.

| Название | Код | Что сообщает модели |
| --- | --- | --- |
| **Проза** | `shape-plain` | Отвечать связным текстом, без JSON, списков и заголовков. |
| **Пункты** | `shape-list` | Отвечать JSON со списком пунктов: что сделать, кто и когда. |
| **Метки** | `shape-labels` | Отвечать JSON со списком кодов и уверенностью в каждом, беря коды только из данного списка. |
| **Оценка** | `shape-score` | Отвечать оценкой от 1 до 5, её обоснованием и словами, на которых она основана. |
| **Критерии** | `shape-rubric` | Отвечать общей оценкой и вердиктом по каждому критерию. |
| **Флаги** | `shape-flags` | Отвечать кодами из списка, каждый с важностью. |
| **Ответ** | `shape-qa` | Отвечать на вопрос или прямо сказать, что разговор об этом не говорит, — со словами, на которых держится ответ. |
| **JSON** | `shape-json` | Отвечать только JSON, в той форме, о которой просят выше. |
| **Как говорили** | `language-as-spoken` | Писать на том языке, на котором шёл разговор. |
| **Как говорили, с названием** | `language-as-spoken-named` | То же, с названием языка. |
| **Названный язык** | `language-named` | Писать на указанном языке. |

**Добавить** в начале списка добавляет запись.

## Форматы ответов {#response-formats}

Ниже — примеры формы, которую стандартные указания требуют от модели. Значения в примерах условные. Это ответы языковой модели, а не описание точек REST API. Для JSON-форм модель просят не добавлять текст вне JSON.

### Пункты (`shape-list`) {#shape-list}

Каждый пункт содержит `text` — что сделать, `owner` — кто это взял на себя, и `due` — срок. Если исполнитель или срок не прозвучали, соответствующая строка остаётся пустой. Если договорённостей нет, список задач должен быть пустым.

```json
{
  "items": [
    {
      "text": "Перезвонить клиенту",
      "owner": "Оператор",
      "due": "Завтра"
    }
  ]
}
```

### Метки (`shape-labels`) {#shape-labels}

`code` берётся только из переданного справочника; `confidence` передаёт уверенность модели. Промпт категории просит выбрать одну категорию, промпт меток — все подходящие метки, которых может не быть вовсе.

```json
{
  "labels": [
    {
      "code": "callback",
      "confidence": 0.9
    }
  ]
}
```

### Оценка (`shape-score`) {#shape-score}

`score` — целое число от 1 до 5, `rationale` — обоснование. В `evidence` приводятся цитаты и время их появления в миллисекундах от начала разговора.

```json
{
  "score": 3,
  "rationale": "Назван следующий шаг, но не уточнён срок",
  "evidence": [
    {
      "at_ms": 15000,
      "quote": "Мы вам перезвоним"
    }
  ]
}
```

### Критерии (`shape-rubric`) {#shape-rubric}

`overall` — общая оценка, целое число от 1 до 5; `rationale` — причина. В `criteria` перечисляются только заданные промптом критерии, с исходными названиями и заметкой `note` в одно предложение. Возможные значения `verdict`: `pass` — выполнено, `weak` — слабо, `fail` — не выполнено, `n/a` — не применимо.

```json
{
  "overall": 3,
  "rationale": "Вопрос клиента понят, но следующий шаг не определён",
  "criteria": [
    {
      "name": "следующий шаг",
      "verdict": "fail",
      "note": "Оператор не договорился о дальнейших действиях."
    }
  ]
}
```

В примере показан один элемент массива; в полном ответе нужны все критерии выбранного промпта. [Критерии продаж и поддержки](prompt-studio.md#quality-criteria) различаются.

### Флаги (`shape-flags`) {#shape-flags}

`code` выбирается из справочника, каждый код — не более одного раза в ответе. `severity` принимает `low`, `medium` или `high`. `evidence` содержит слова, подтверждающие флаг, а `at_ms` — время в миллисекундах от начала разговора. Без подтверждающей цитаты стандартный промпт просит не поднимать флаг. Если ни один флаг не подходит, список остаётся пустым.

```json
{
  "flags": [
    {
      "code": "promise-made",
      "severity": "medium",
      "evidence": "Я перезвоню вам завтра",
      "at_ms": 30000
    }
  ]
}
```

### Ответ (`shape-qa`) {#shape-qa}

`answer` — ответ только по этому разговору или прямое сообщение, что в разговоре нет нужных сведений. `citations` — цитаты с временем в миллисекундах, на которых держится ответ.

```json
{
  "answer": "Оператор обещал перезвонить завтра.",
  "citations": [
    {
      "at_ms": 30000,
      "quote": "Я перезвоню вам завтра"
    }
  ]
}
```

### Проза, произвольный JSON и язык {#plain-json-and-language}

**Проза** (`shape-plain`) просит связный текст без JSON, списков и заголовков. **JSON** (`shape-json`) требует только JSON в форме, указанной в самом задании; отдельная фиксированная структура для промпта «Имена и числа» в стандартном тексте не задана.

Указания `language-as-spoken`, `language-as-spoken-named` и `language-named` выбирают язык разговора либо явно названный язык. В текстах двух последних указаний место для названия языка обозначено `{language}`. Это отличается от подстановки `{{language}}` в задании промпта; примеры заданий находятся в [Студии промптов](prompt-studio.md#placeholders) и [Настройках суфлёра](prompter.md#assistant-templates).

## По умолчанию {#defaults}

**Восстановить по умолчанию** возвращает все справочники такими, какими они пришли с программой, на текущем языке интерфейса. *Разметка ваших разговоров остаётся нетронутой.*
