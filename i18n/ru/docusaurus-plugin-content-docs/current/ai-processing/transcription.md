**Настройки → Расшифровка** — это список распознавателей: сервисов, которые превращают звук в текст, — для законченных разговоров и, для [суфлёра](../interface/prompter.md), прямо во время разговора.

<Shot name="25_transcription" alt="Настройки → Расшифровка: пять распознавателей" />

Разговор расшифровывается, когда вы просите об этом в [окне записей](/interface/recordings), или сам, если в [Обработке](/ai-processing/processing) включено **Обрабатывать разговоры автоматически**. Распознаватель на своей машине не стоит ничего; облачный берёт плату за минуту звука.

## Распознаватели {#recognisers}
Распознаватель — это сервис распознавания речи, которому телефон отправляет звук. Кнопка **Добавить** добавляет новый; кнопка **Проверить** в его карточке проверяет, что сервис действительно отвечает. В списке у каждого показано название, а под ним — модель и адрес сервиса. На картинке их пять:

| Название | Модель | Адрес |
| --- | --- | --- |
| **X.ai** | *(пусто: модель сервиса по умолчанию)* | `https://api.x.ai/v1` |
| **ElevenLabs** | `scribe_v2` | `https://api.elevenlabs.io/v1` |
| **Deepgram** | `nova-2` | `https://api.deepgram.com/v1` |
| **OpenAI** | `gpt-4o-transcribe` | `https://api.openai.com/v1/` |
| **Vosk** | *(нет)* | `ws://localhost:2700`, сервер на этом компьютере |

Два значка справа в строке показывают, для чего распознаватель выбран по умолчанию. Часы горят у основного **для расшифровок** — на картинке это **X.ai**: он используется, когда вы не выбрали другой. Молния горит у основного **для суфлёра** — на картинке это **Vosk**. Распознавателей можно держать несколько; выпадающий список над расшифровкой в [окне записей](/interface/recordings#transcript-or-write-up-the-drop-down) показывает расшифровки, сделанные каждым из них.

## Карточка распознавателя {#the-recognisers-card}
Нажатие на распознаватель открывает его карточку.

<Shot name="43_recogniser_card" alt="Карточка распознавателя X.ai: вид, два адреса, ключ, «Проверить» и выбор по умолчанию" />

| Поле | Что это |
| --- | --- |
| **Название** | Имя в списках. |
| **Вид** | Вид сервиса — от него зависит, как телефон с ним разговаривает: **Совместимый с OpenAI (Whisper, OpenAI)**, **Deepgram**, **ElevenLabs (Scribe)**, **xAI (Grok)**, **AssemblyAI**, **Soniox**, **Speechmatics** и три вида, которые работают на вашей машине, — **Vosk**, **WhisperLive** и **NVIDIA Riva**. **Yandex SpeechKit** предлагается, когда в [О программе](../application/about.md) выбрана Россия или одна из соседних стран. |
| **Адрес для стенограмм** | Куда отправляются законченные разговоры. |
| **Адрес для суфлёра** | Куда идёт живой звук, пока разговор идёт. *Пусто — берётся из адреса рядом*, как `wss://api.x.ai` на картинке. |
| **Ключ** | Ключ сервиса. *Хранится в хранилище ключей этого компьютера, а не в файле настроек.* |
| **Проверить** | Спрашивает сервис и сообщает, что он ответил, например *Ответил и предлагает 3 модели*. |
| **Модель для стенограмм** и **Модель для суфлёра** | Модель — ровно так, как её называет сервис. *Пусто — имя модели не передаётся*, и сервис берёт свою модель по умолчанию; если поставщик её публикует, карточка её называет. Для вида, у которого выбора нет, поле не показывается. |
| **По умолчанию для расшифровок** | Делает этот распознаватель тем, который используется, когда вы не выбрали другой. |
| **По умолчанию для суфлёра** | Делает этот распознаватель тем, которым слушает новый помощник суфлёра. |
| **Включён** | Выключенный распознаватель остаётся в списке, но не используется. |

**Дополнительные настройки** раскрывают остальную часть карточки. Самое важное в них:

<Shot name="43b_recogniser_advanced" alt="Дополнительные настройки распознавателя: пределы, как нарезаются реплики, язык" />

| Поле | Что делает |
| --- | --- |
| **Регион** | Регион сервиса, если у него их несколько. |
| **Отправлять стороны раздельно** | Звонок записывается так, что два собеседника лежат в двух каналах, — именно по этому распознаватель понимает, кто что сказал. Выключите для сервера, который заявляет, что умеет это, а на деле не умеет. |
| **Спрашивать, кто говорит** | Различает людей внутри одного канала, если в нём говорят несколько человек. |
| **Писать числа цифрами** | Суммы, даты и номера телефонов приходят записанными цифрами, а не прописанными словами. |
| **Предел отправки**, **Предел длины** | Самый большой файл в байтах и самая длинная запись в секундах, которые отправит телефон. |
| **Запросов сразу** | Сколько запросов может выполняться одновременно. |
| **Завершать реплику через**, **Склеивать короткие реплики в пределах**, **Пауза между репликами** | Для суфлёра: сколько времени без новых слов завершает реплику, сколько короткая реплика ждёт следующую, чтобы склеиться с ней, и какая тишина завершает очередь говорящего, если распознаватель сам её не отмечает. В миллисекундах. |
| **Язык** | Двухбуквенный код языка по ISO 639-1 (`en`, `de`, `es`, `fr`, `sr`…). Оставьте пустым — распознаватель решит сам; это правильно, если только ваши разговоры не идут на языке, который он постоянно путает. |
| **Дополнительно** | Параметры вида `имя = значение`, по одному в строке, — передаются сервису как есть. Оставьте пустым, если сервер ничего такого не описывает. |
| **Ожидание, минуты** | Сколько ждать расшифровку. Пусто — ожидание считается по длительности записи. |
| **Цена за минуту** | Сколько стоит минута живого звука — из прайс-листа сервиса. Суфлёр показывает, во сколько обошёлся сеанс, и останавливается на своём [месячном лимите](prompter.md#spending). |

## Живое распознавание для суфлёра {#live-recognition-for-the-prompter}
[Суфлёру](../interface/prompter.md) нужен распознаватель, который слушает, пока человек говорит, — потоком, а не готовым файлом. Это умеют такие виды: **Deepgram**, **ElevenLabs (Scribe)**, **xAI (Grok)**, **Совместимый с OpenAI** (с живой расшифровкой OpenAI), **AssemblyAI**, **Soniox** и **Speechmatics** в облаке, **Yandex SpeechKit** там, где он предлагается, и **Vosk**, **WhisperLive** и **NVIDIA Riva** на вашей машине. Распознаватель на своей машине оставляет голос собеседника внутри и ничего не стоит.

Чтобы им воспользоваться, откройте его карточку, проверьте **Адрес для суфлёра** (или оставьте его вычисляться), выберите **Модель для суфлёра**, если сервис предлагает несколько, — живые модели часто отличаются от моделей для файлов, например `scribe_v2_realtime` у ElevenLabs, — и нажмите **Проверить**. Отметьте **По умолчанию для суфлёра**, чтобы новые помощники слушали именно им.

## Yandex SpeechKit {#yandex-speechkit}

**Yandex SpeechKit** — распознавание речи Яндекс Облака. Он хорошо понимает русскую речь, в том числе телефонную, звук и текст обрабатываются в Яндекс Облаке, а платить можно в рублях. Для компании в России это обычно самый простой распознаватель: не нужен ни зарубежный счёт, ни собственный сервер с видеокартой.

SpeechKit появляется в списке **Вид**, когда в [**Настройки → О программе → Страна**](/application/about#version-and-country) выбрана **Россия** (а также Беларусь, Казахстан, Узбекистан, Кыргызстан, Таджикистан, Туркменистан, Армения или Азербайджан). При другой стране этого вида в списке нет; уже добавленный распознаватель продолжает работать.

<Shot name="11b_transcription_yandex" alt="Карточка распознавателя Yandex SpeechKit: название, вид, адрес https://stt.api.cloud.yandex.net, модель general и ключ" />

### Что нужно в Яндекс Облаке {#what-yandex-cloud-needs}

1. Платёжный аккаунт и каталог в [консоли Яндекс Облака](https://console.yandex.cloud/).
2. Сервисный аккаунт в этом каталоге с ролью `ai.speechkit-stt.user`. Если тот же аккаунт будет работать и с [YandexGPT](processing.md#yandexgpt), добавьте ему роль `ai.languageModels.user` — тогда хватит одного ключа на обоих.
3. API-ключ этого сервисного аккаунта. Он показывается один раз — сразу вставьте его в поле **Ключ**.

Подробности — в документации Яндекс Облака: [аутентификация в SpeechKit](https://yandex.cloud/ru/docs/speechkit/concepts/auth) и [асинхронное распознавание](https://yandex.cloud/ru/docs/speechkit/stt/transcribation).

### Добавление SpeechKit {#adding-speechkit}

1. Убедитесь, что в **О программе** выбрана страна **Россия**.
2. **Настройки → Расшифровка → Добавить**.
3. В поле **Вид** выберите **Yandex SpeechKit**. Адрес `https://stt.api.cloud.yandex.net` и модель `general` подставятся сами.
4. Вставьте API-ключ в поле **Ключ**.
5. Нажмите **Проверить**, затем **Сохранить**. Отметьте **По умолчанию для расшифровок**, если SpeechKit должен расшифровывать все разговоры.

Сделайте пробную запись и откройте её в [окне записей](/interface/recordings): в выпадающем списке над расшифровкой появится **Yandex SpeechKit**.

### Как SpeechKit расшифровывает {#how-speechkit-transcribes}

Телефон пользуется асинхронным распознаванием SpeechKit (API v3): отправляет запись целиком, получает номер операции и спрашивает **Адрес операций**, пока распознавание не закончится. Поэтому длинный разговор расшифровывается минуты, а не секунды, — полоска над списком записей показывает, что сейчас в работе. Звонок записан в два канала, так что в расшифровке видно, где говорили вы, а где собеседник.

### Модели SpeechKit {#speechkit-models}

| Модель | Что это |
| --- | --- |
| **`general`** | Основная модель распознавания. Подходит для звонков и встреч. Подставляется по умолчанию. |
| `general:rc` | Следующая версия модели до её выпуска (release candidate): иногда точнее, но может меняться. |
| `general:deprecated` | Предыдущая версия модели — на случай, если новая распознаёт ваши разговоры хуже. |
| `deferred-general` | Отложенное распознавание: результат приходит позже, зато дешевле. Подходит, если расшифровка не нужна срочно. |

Актуальный список моделей и языков — в [документации SpeechKit](https://yandex.cloud/ru/docs/speechkit/stt/models).

### Дополнительные настройки SpeechKit {#yandex-speechkit-settings}

**Дополнительные настройки** внизу карточки раскрывают редкие поля. Обычно их не трогают.

<Shot name="11c_transcription_yandex_advanced" alt="Дополнительные настройки Yandex SpeechKit: регион, каталог, писать числа цифрами, предел отправки и длины" />

<Shot name="11d_transcription_yandex_operations" alt="Дополнительные настройки Yandex SpeechKit: запросов сразу, адрес операций и дополнительные параметры" />

| Поле | По умолчанию | Что это |
| --- | --- | --- |
| **Регион** | пусто | Регион облака, если ваша установка Яндекс Облака его требует. |
| **Каталог** | пусто | *Нужен только для IAM-токена личного аккаунта: такой аккаунт не принадлежит каталогу. API-ключ сервисного аккаунта уже знает свой каталог, так что поле можно оставить пустым.* |
| **Писать числа цифрами** | вкл. | *Суммы, даты и номера телефонов приходят записанными цифрами, а не прописанными словами, как их произнесли.* Выключите, чтобы каждое слово осталось таким, каким его сказали. |
| **Предел отправки** | 45000000 | Самый большой файл, который телефон отправит, в байтах (около 45 МБ). Запись больше этого отклоняется до отправки, а не после неё. |
| **Предел длины** | 14400 | Самая длинная запись, которую телефон отправит, в секундах (4 часа). Ноль — нашего предела нет, действует предел провайдера. |
| **Запросов сразу** | 2 | Сколько распознаваний телефон держит выполняющимися одновременно. |
| **Адрес операций** | `https://operation.api.cloud.yandex.net` | *Адрес, где спрашивают о переданном распознавании, пока оно не закончится.* Адрес самого Яндекса, если у вашей установки нет другого. |
| **Дополнительно** | пусто | Параметры вида `имя = значение`, по одному в строке, — передаются распознавателю как есть. Оставьте пустым, если сервис ничего такого не требует. |
| **Ожидание, минуты** | пусто | Сколько минут ждать результата. Пусто — ожидание считается по длительности каждой записи, и почти всем стоит оставить так. |

:::tip
Если поле **Ключ** заполнено API-ключом сервисного аккаунта, **Каталог** и **Регион** можно не заполнять — SpeechKit сам знает, к какому каталогу относится ключ.
:::

## Какую модель выбрать {#which-model-to-choose}
В таблице — модели распознавания речи всех видов из списка **Вид**. **Жирным** выделены модели, настроенные на картинке; у распознавателя X.ai модель пустая, поэтому используется модель сервиса по умолчанию — **`grok-voice-transcribe-2.0`**. Столбец **Для чего** говорит, для чего сделана модель: для законченных записей (*расшифровки*), для живой речи [суфлёра](#live-recognition-for-the-prompter) (*суфлёр*) или для *обоих*.

| Вид и адрес | Модель | Для чего | Что это |
| --- | --- | --- | --- |
| **Совместимый с OpenAI (Whisper, OpenAI)**<br />`https://api.openai.com/v1` | `gpt-transcribe` | расшифровки | Модель, которую OpenAI рекомендует для записанной речи на языке оригинала. |
| | **`gpt-4o-transcribe`** | оба | Расшифровка общего назначения. Её получает новый распознаватель этого вида. |
| | `gpt-4o-mini-transcribe` | оба | Облегчённый и более дешёвый вариант предыдущей. |
| | `gpt-4o-transcribe-diarize` | расшифровки | Размечает, кто когда говорит. Берите, только если это нужно. |
| | `whisper-1` | расшифровки | Старая модель Whisper — для особых задач вроде меток времени по словам и субтитров. |
| | `gpt-live-transcribe` | суфлёр | Живая модель OpenAI: слова приходят по мере того, как их произносят. Телефон предлагает её для суфлёра. |
| **Deepgram**<br />`https://api.deepgram.com/v1` | `nova-3` | оба | Лучшая модель Deepgram общего назначения — для встреч, шумной и многоязычной речи. Её получает новый распознаватель этого вида. |
| | **`nova-2`** | оба | Предыдущее поколение; оставьте её для языков, которых `nova-3` ещё не знает. |
| | `nova-2-phonecall` | оба | `nova-2`, настроенная на узкий звук телефонной линии. Английский. |
| | `flux-general-en` | суфлёр | Сделана для разговора: слышит, когда человек договорил. Английский. |
| | `flux-general-multi` | суфлёр | То же на десяти языках, и разговор может переходить с одного на другой. |
| | `enhanced`, `base` | расшифровки | Старые уровни; `base` — для больших объёмов. |
| | `whisper` | расшифровки | Whisper, запущенный у Deepgram. |
| **ElevenLabs (Scribe)**<br />`https://api.elevenlabs.io/v1` | **`scribe_v2`** | расшифровки | Расшифровка общего назначения на 90+ языках, с разделением говорящих. |
| | `scribe_v2_realtime` | суфлёр | Живая версия `scribe_v2`. Телефон предлагает её для суфлёра. |
| | `scribe_v2_medical` | расшифровки | `scribe_v2`, настроенная на медицинскую речь. |
| | `scribe_v1` | расшифровки | Первое поколение; устарело, используйте `scribe_v2`. |
| **Speechmatics**<br />`https://asr.api.speechmatics.com/v2` | `enhanced` | оба | Самая точная — для разговора на одном языке. Её получает новый распознаватель этого вида. |
| | `standard` | оба | Быстрее и дешевле, чуть менее точная. |
| | `melia-1` | расшифровки | Разговор на нескольких языках, с переходами посреди фразы, приходит одной расшифровкой. Только для записей, в регионах ЕС и США; своего словаря и разметки говорящих пока нет. |
| **xAI (Grok)**<br />`https://api.x.ai/v1` | **`grok-voice-transcribe-2.0`** | оба | Модель по умолчанию; 25 языков. |
| | `grok-voice-transcribe-1.0` | расшифровки | Устарела: сервис переадресует её на `2.0`. |
| **Soniox**<br />`https://api.soniox.com` | `stt-async-v5` | расшифровки | 60+ языков, с разделением говорящих. |
| | `stt-rt-v5` | суфлёр | Живое распознавание на тех же 60+ языках; слышит, где кончается реплика. Телефон предлагает её для суфлёра. |
| **AssemblyAI**<br />`https://api.assemblyai.com` | `universal-3-5-pro` | оба | Самая точная модель для записей; 18 языков, и разговор может переходить с одного на другой. |
| | `universal-2` | расшифровки | 99 языков, дешевле; AssemblyAI переключается на неё для языка, которого `universal-3-5-pro` не знает. |
| | `universal-3-6-pro` | суфлёр | Новейшая живая модель AssemblyAI, 32 языка; сервис берёт её, когда модель не указана. |
| | `universal-streaming-multilingual` | суфлёр | Более дешёвое живое распознавание на английском, испанском, немецком, французском, португальском и итальянском. |
| | `universal-streaming-english` | суфлёр | Более дешёвое живое распознавание, только английский. |
| **Yandex SpeechKit**<br />`https://stt.api.cloud.yandex.net` | `general` | оба | Основная модель; хорошо знает русскую речь, в том числе телефонную. Предлагается, когда страна — Россия или одна из соседних. |
| | `general:rc` | оба | Следующая версия модели до выпуска. |
| | `deferred-general` | расшифровки | Отложенное распознавание: расшифровка приходит позже, зато дешевле. |
| **Vosk (на вашей машине)**<br />`ws://localhost:2700` | *(задаётся на сервере)* | оба | Бесплатный и лёгкий, работает без видеокарты. Модель — та, с которой запущен сервер, своя для каждого языка, например `vosk-model-ru-0.42` или маленькая `vosk-model-small-ru-0.22`. |
| **WhisperLive (на вашей машине)**<br />`ws://localhost:9090` | `small` | оба | Whisper в живом потоке. Размер выбирается в карточке: `tiny`, `base`, `small` (его предлагает телефон), `medium`, `large-v3`; чем больше, тем точнее и тем нужнее видеокарта. |
| **NVIDIA Riva (на вашей машине)**<br />`localhost:50051` | *(задаётся на сервере)* | оба | Речевой сервер NVIDIA для компьютера с видеокартой NVIDIA. Обслуживает модели вроде Parakeet и Canary. |

Что стоит знать до выбора:

- **Расшифровки или суфлёр.** Модель для живой речи не принимает готовый файл, а большинство моделей для файлов не умеет слушать вживую. Поэтому в карточке два поля — **Модель для стенограмм** и **Модель для суфлёра**.
- **Где обрабатываются данные.** Yandex SpeechKit работает в Яндекс Облаке; остальные облачные сервисы — за рубежом. Если звук не должен покидать страну или вашу сеть, берите SpeechKit или распознаватель на своей машине.
- **Размер файла.** OpenAI принимает файлы до 25 МБ, X.ai — до 500 МБ. Длинный разговор может оказаться больше, чем принимает облачный сервис.
- **Цена.** Облачные сервисы берут плату за минуту звука, тарифы зависят от модели и меняются; смотрите их на странице сервиса, прежде чем переключаться. Распознаватель на своей машине ничего не стоит.
- **Языки.** У каждого сервиса свой список; проверьте свой и укажите код **Язык** в дополнительных настройках распознавателя, если он угадывает неверно.

Список моделей сервисов меняется часто. Если нужной модели здесь нет, актуальный список — в документации сервиса: [OpenAI](https://developers.openai.com/api/docs/guides/speech-to-text), [Deepgram](https://developers.deepgram.com/docs/models-languages-overview), [ElevenLabs](https://elevenlabs.io/docs/capabilities/speech-to-text), [Speechmatics](https://docs.speechmatics.com/speech-to-text/models), [X.ai](https://docs.x.ai/developers/model-capabilities/audio/speech-to-text), [Soniox](https://soniox.com/docs/stt/models), [AssemblyAI](https://www.assemblyai.com/docs/getting-started/models), [Yandex SpeechKit](https://yandex.cloud/en/docs/speechkit/stt/models), [Vosk](https://alphacephei.com/vosk/models), [WhisperLive](https://github.com/collabora/WhisperLive), [NVIDIA Riva](https://docs.nvidia.com/deeplearning/riva/user-guide/docs/asr/asr-overview.html); **Модель** — это название ровно так, как его даёт сервис.

## Собственные модели {#your-own-models}
Распознаватель не обязан быть облачным сервисом. Телефон может использовать **любую модель, которая отдаётся через API, совместимый с OpenAI**, — интерфейс `POST /v1/audio/transcriptions`, — работает ли она на вашем компьютере или на вашем собственном сервере. Звук не покидает ваших помещений, поминутной платы нет, ограничений по объёму тоже.

Чтобы добавить такую модель, нажмите **Добавить** и укажите:

- **адрес** сервера вплоть до `/v1` включительно, например `http://localhost:8000/v1` для самого компьютера или `http://asr.local:8080/v1` для сервера в вашей сети;
- название **модели** ровно так, как его показывает сервер, например `openai/whisper-large-v3-turbo`.

### Что можно использовать {#what-can-be-used}
Обычно выбирают **Whisper** — открытую модель распознавания речи от OpenAI. Она бесплатна, понимает около сотни языков и бывает нескольких размеров: маленькая модель работает на обычном компьютере, большие заметно точнее, и им лучше дать видеокарту.

| Модель | Примечания |
| --- | --- |
| `whisper-large-v3` | Самый точный Whisper. Для сервера с видеокартой. |
| `openai/whisper-large-v3-turbo` | Более быстрая версия `large-v3` с небольшой потерей точности. |
| `Systran/faster-whisper-large-v3` | `large-v3`, переведённая на движок faster-whisper: быстрее и легче для памяти. |
| `medium`, `small`, `base` | Меньшие модели Whisper — для компьютера без видеокарты. |

Именно вокруг Whisper построены эти серверы. Некоторые из них умеют отдавать и другие модели распознавания речи, например NVIDIA Parakeet.

### Серверы с API, совместимым с OpenAI {#servers-that-offer-the-openai-compatible-api}
Модель должен запускать сервер, который предоставляет совместимую с OpenAI точку `/v1/audio/transcriptions`. Такие серверы:

| Сервер | Что это |
| --- | --- |
| [vLLM](https://docs.vllm.ai/en/latest/serving/online_serving/speech_to_text/) | Высокопроизводительный сервер моделей. После запуска отдаёт Whisper по адресу `http://localhost:8000/v1`. |
| [Speaches](https://github.com/speaches-ai/speaches) | Сервер речевых моделей, «Ollama для речи», на основе faster-whisper. Загружает модель при первом запросе к ней. |
| [whisper.cpp](https://github.com/ggml-org/whisper.cpp) | Эффективно запускает Whisper на процессоре, в том числе на Apple silicon. Его `whisper-server` запускается с `--inference-path /v1/audio/transcriptions`. |
| [LocalAI](https://localai.io/) | Замена OpenAI, которая запускает модели локально. |

Любой другой сервер с той же точкой работает так же. Если сервер требует ключ, введите его, как для облачного сервиса.

Прежде чем полагаться на сервер, сделайте пробную запись и посмотрите расшифровку в [окне записей](/interface/recordings): разговор на языке, который модель знает плохо, сразу это покажет.
