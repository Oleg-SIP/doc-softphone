Сводку разговора пишут промпты. В программе их одиннадцать, и вы можете менять их обычным языком, дублировать и добавлять свои. Они перечислены под заголовком **Промпты** в [Настройки → Обработка](processing.md).

## Промпты, которые идут с программой

| Промпт | Что пишет |
| --- | --- |
| **Содержание** | Главные тезисы, решения и следующие шаги — в одном коротком абзаце. |
| **Краткое содержание** | Короткий заголовок, по которому разговор легко узнать с первого взгляда. |
| **Задачи** | Кто что обязался сделать и к какому сроку — если об этом говорили. |
| **Темы** | Какие темы затрагивались в разговоре — по несколько слов на каждую. |
| **Имена и числа** | Людей, компании, даты, суммы и номера документов. |
| **Категория** | Относит разговор к одной из ваших [категорий](dictionaries.md). |
| **Метки** | Проставляет ваши [метки](dictionaries.md), по которым нужные разговоры проще найти. |
| **Красные флаги** | Отмечает проблемы, требующие внимания, с цитатами и ссылками на моменты разговора. |
| **Вопрос об этом разговоре** | Отвечает на ваш вопрос об одном разговоре на основе его расшифровки. |
| **Качество продажи** | Оценивает разговор по понятным критериям продаж, которые можно изменить. |
| **Качество поддержки** | Оценивает, насколько верно поняли проблему клиента и как её решали. |

## Настройте под себя

- Измените обычным языком, что просит промпт.
- Продублируйте промпт, чтобы попробовать вариант.
- Выберите модель для каждого промпта — на вашей машине или в облаке.
- Задайте порядок запуска промптов, включайте и выключайте их и делайте условными: например, оценка продажи запускается только для звонков с категорией **Продажи**.
- Ведите собственные категории, метки и красные флаги в [Справочниках](dictionaries.md).
- Ограничивайте расходы [месячными лимитами](processing.md#лимиты).

Исходные промпты можно восстановить в **Настройках**.
