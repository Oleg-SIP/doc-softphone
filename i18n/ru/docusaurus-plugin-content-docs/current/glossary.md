title: Глоссарий

description: Термины IP-телефонии и AI Softphone, которые встречаются в этой документации, в одном месте.
---

| Термин | Значение |
| --- | --- |
| **API-ключ** | Секрет, с которым программа обращается к облачному сервису. Для Yandex SpeechKit и YandexGPT это API-ключ сервисного аккаунта Яндекс Облака. Хранится в хранилище ключей компьютера. См. [Расшифровка](/ai-processing/transcription#yandex-speechkit). |
| **BLF** (Busy Lamp Field) | Кнопка, которая набирает внутренний номер и лампой показывает, свободен ли он, звонит или занят. См. [Кнопки](/sip-accounts/buttons). |
| **CTI** | Компьютерно-телефонная интеграция: программа на компьютере совершает звонки и следит за ними. См. [Локальный REST API](/integration/rest-api). |
| **DTMF** | Тоны клавиатуры, передаваемые во время звонка. |
| **IAM-токен** | Короткоживущий токен Яндекс Облака, которым можно войти вместо API-ключа. Для IAM-токена личного аккаунта нужно указать **Каталог**. |
| **IP-АТС** | Офисная телефонная станция, работающая по сети; её ещё называют софтсвитчем. |
| **SIP** | Протокол, которым телефоны и АТС устанавливают звонки. |
| **Внутренний номер** | Номер человека или устройства внутри АТС. |
| **Вебхук** | Запрос, который телефон отправляет в другую систему, когда звонок начинается, меняется или заканчивается. См. [Вебхуки](/integration/webhooks). |
| **Каталог** (folder) | Папка ресурсов в Яндекс Облаке; её идентификатор входит в адрес модели YandexGPT. См. [Обработка](/ai-processing/processing#yandexgpt). |
| **Категория** | О чём был разговор; одна на разговор. См. [Справочники](/ai-processing/dictionaries). |
| **Кодек** | Способ кодирования голоса для линии. Телефон предлагает список, другая сторона выбирает. См. [Настройки звонков](/sip-accounts/calls#audio-formats). |
| **Конференция** | Звонки, объединённые в один. |
| **Красный флаг** | То, что в разговоре требует внимания, — с доказательством и временем. См. [Справочники](/ai-processing/dictionaries#red-flags). |
| **Метка** | Ярлык; к одному разговору может подходить несколько. См. [Справочники](/ai-processing/dictionaries#tags). |
| **Ожидание вызова** | Что делает телефон, когда кто-то звонит, пока вы уже разговариваете. См. [Настройки звонков](/sip-accounts/calls#call-waiting). |
| **Перехват** | Запись разговора, идущего в другом приложении — Zoom, Teams, Meet, Телемосте. См. [Перехват](/capture/). |
| **Правило** | Шаг, который выполняется сам, по порядку, для каждого разговора. См. [Обработка](/ai-processing/processing#rules). |
| **Промпт** | То, о чём просят языковую модель. См. [Персональная студия промптов](/ai-processing/prompt-studio). |
| **Распознаватель** | Сервис, превращающий звук в текст (распознавание речи), например Yandex SpeechKit. См. [Расшифровка](/ai-processing/transcription). |
| **Расшифровка** (стенограмма) | Разговор в виде текста, реплика за репликой, синхронно со звуком. |
| **Регистрация** | Телефон сообщает АТС, где он находится, чтобы до него доходили звонки. Зелёная точка у учётной записи означает, что она зарегистрирована. |
| **Токен** | Две разные вещи: **Токен** локального API — пароль для других программ; и токены, которые считает языковая модель, — единица месячного **Лимита токенов**. |
| **Учётная запись** | Линия: SIP-логин на АТС или у провайдера. Можно быть подключённым сразу к нескольким. См. [Настройка SIP-учётной записи](/sip-accounts/setup). |
| **Широкополосный** | Кодек с более широким диапазоном звука, чем у телефонной линии, — голос звучит чище. |
| **Языковая модель** | ИИ, который читает расшифровку и пишет о ней, например YandexGPT. См. [Обработка](/ai-processing/processing). |
