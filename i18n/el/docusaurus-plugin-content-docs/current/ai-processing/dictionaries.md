Οι **Ρυθμίσεις → Λεξικά** περιέχουν τις λέξεις στις οποίες μπορεί να καταταχθεί μια συνομιλία, με τις οποίες μπορεί να πάρει ετικέτα ή να επισημανθεί. Αυτές οι λίστες είναι αυτό που βλέπουν τα μοντέλα και από αυτές πρέπει να διαλέξουν, οπότε μια απάντηση είναι πάντα κάτι που μπορείτε να αναζητήσετε αργότερα.

<Shot name="13_settings_dictionaries" alt="Ρυθμίσεις → Λεξικά" />

Η **Εμφάνιση διαγραμμένων** δείχνει τις καταχωρίσεις που έχετε διαγράψει.

Κάθε καταχώριση είναι ένα όνομα, ένας σύντομος κωδικός με μικρά γράμματα και μια περιγραφή που λέει στο μοντέλο πότε να την επιλέξει. Ο κωδικός είναι αυτό που αποθηκεύεται και αυτό που επιστρέφει το [REST API](../integration/rest-api.md#taxonomy-and-settings), οπότε μένει ίδιος όταν μετονομάζετε την καταχώριση.

## Κατηγορίες {#categories}

Το θέμα της συνομιλίας· **επιλέγεται μία ανά συνομιλία**. Το πρόγραμμα ξεκινά με τέσσερις:

| Όνομα | Κωδικός | Χρησιμοποιείται για |
| --- | --- | --- |
| **Πωλήσεις** | `sales` | Πώληση, προσφορά, διαπραγμάτευση ή παρακολούθηση μιας αγοράς — μαζί και ο πελάτης που ρωτά πόσο κοστίζει κάτι. |
| **Υποστήριξη** | `support` | Βοήθεια σε κάποιον για προϊόν ή υπηρεσία που ήδη έχει: μια βλάβη, μια ερώτηση για τη χρήση, ένα παράπονο για τον τρόπο που λειτουργεί. |
| **Προσωπική** | `personal` | Καθόλου επαγγελματική — ιδιωτική συνομιλία που έτυχε να γίνει σε αυτή τη γραμμή. |
| **Άλλο** | `other` | Επαγγελματική, αλλά ούτε πώληση ούτε υποστήριξη: προμηθευτής, συνάδελφος, παράδοση, λάθος αριθμός. Διαλέξτε αυτό αντί να μαντεύετε ανάμεσα στα υπόλοιπα. |

Πατήστε **Προσθήκη** για να προσθέσετε μια δική σας κατηγορία.

## Ετικέτες {#tags}

Σήματα που *μπορεί να ισχύουν όλα για την ίδια συνομιλία*. Πατήστε **Προσθήκη** για να προσθέσετε μία. Η λίστα ξεκινά με καταχωρίσεις όπως:

| Όνομα | Κωδικός | Χρησιμοποιείται για |
| --- | --- | --- |
| **Υποσχέθηκε επιστροφή κλήσης** | `callback` | Κάποιος σε αυτή την κλήση υποσχέθηκε να τηλεφωνήσει ξανά ή ζήτησε να τον καλέσουν. |
| **Παράπονο** | `complaint` | Η άλλη πλευρά εξέφρασε δυσαρέσκεια, είτε λύθηκε το θέμα είτε όχι. |
| **Κλιμακώθηκε** | `escalation` | Η κλήση δόθηκε σε κάποιον άλλον, ή η άλλη πλευρά το ζήτησε. |
| **Πελάτης VIP** | `vip` | Η άλλη πλευρά αντιμετωπίστηκε ως σημαντικός πελάτης, ή το είπε η ίδια για τον εαυτό της. |

## Ενδείξεις προσοχής {#red-flags}

Πράγματα που χρειάζονται προσοχή, που βρέθηκαν στη συνομιλία με την απόδειξη και τη χρονική στιγμή — για παράδειγμα *Θυμωμένος πελάτης* ή *Κίνδυνος αποχώρησης*. Οι ενδείξεις προσοχής εμφανίζονται με κόκκινο χρώμα στο [παράθυρο Εγγραφές](../interface/recordings.md), και η καθεμία φέρει έναν βαθμό σοβαρότητας: χαμηλό, μέτριο ή υψηλό.

| Όνομα | Κωδικός | `severity` | Χρησιμοποιείται για |
| --- | --- | --- | --- |
| **Θυμωμένος πελάτης** | `angry-customer` | `high` | Ακουγόταν ότι η άλλη πλευρά ήταν θυμωμένη, έβριζε ή απείλησε να φύγει. |
| **Κίνδυνος αποχώρησης** | `churn-risk` | `high` | Τέθηκε θέμα ακύρωσης, μη ανανέωσης ή μετάβασης σε κάποιον άλλον, όσο ήρεμα κι αν ειπώθηκε. |
| **Δόθηκε υπόσχεση** | `promise-made` | `medium` | Η πλευρά μας δεσμεύτηκε για κάτι συγκεκριμένο — ημερομηνία, τιμή, επισκευή, επιστροφή χρημάτων. |
| **Ευαίσθητα δεδομένα** | `sensitive-data` | `high` | Ειπώθηκε φωναχτά αριθμός κάρτας, κωδικός, αριθμός εγγράφου ή οτιδήποτε άλλο δεν πρέπει να βρίσκεται σε ηχογράφηση. |
| **Ανταγωνιστής** | `competitor` | `low` | Η άλλη πλευρά κατονόμασε κάποιον άλλον που προσφέρει το ίδιο ή μας σύγκρινε μαζί του. |

## Οδηγίες {#instructions}

<Shot name="13b_settings_dictionaries_scrolled" alt="Ρυθμίσεις → Λεξικά: σχήματα απάντησης και οδηγίες γλώσσας" />

*Αυτά που προστίθενται σε κάθε οδηγία για τη μορφή της απάντησης και τη γλώσσα στην οποία γράφεται.* Φυλάσσονται εδώ ώστε κάθε οδηγία να μπορεί να χρησιμοποιεί την ίδια διατύπωση, και μπορείτε να τις αλλάξετε όπως κάθε άλλη καταχώριση — ή να γράψετε δικές σας, όπως *απάντησε σύντομα* ή *μην αναφέρεις ποτέ τιμή*, και να τις σημειώσετε στο **Στείλε επίσης** σε οποιαδήποτε οδηγία.

| Όνομα | Κωδικός | Τι λέει στο μοντέλο |
| --- | --- | --- |
| **Πεζός λόγος** | `shape-plain` | Απάντηση σε απλό πεζό λόγο, χωρίς JSON, λίστες ή επικεφαλίδες. |
| **Στοιχεία** | `shape-list` | Απάντηση με λίστα πραγμάτων που πρέπει να γίνουν, το καθένα με το ποιος και πότε. |
| **Ετικέτες** | `shape-labels` | Να απαντήσει σε JSON με μια λίστα κωδικών και πόσο σίγουρο είναι για τον καθένα, χρησιμοποιώντας μόνο κωδικούς από τη λίστα που του δόθηκε. |
| **Βαθμολογία** | `shape-score` | Να απαντήσει με μια βαθμολογία, την αιτιολόγησή της και τα λόγια στα οποία βασίζεται. |
| **Κριτήρια** | `shape-rubric` | Να απαντήσει με μια συνολική βαθμολογία και μια βαθμολογία για κάθε κριτήριο. |
| **Ενδείξεις** | `shape-flags` | Να απαντήσει με κωδικούς από τη λίστα, τον καθένα με έναν βαθμό σοβαρότητας. |
| **Απάντηση** | `shape-qa` | Να απαντήσει με την απόκριση, ή να πει καθαρά ότι η συνομιλία δεν το αναφέρει, και με τα λόγια στα οποία στηρίζεται η απόκριση. |
| **JSON** | `shape-json` | Να απαντήσει μόνο με JSON, στο σχήμα που ζητήθηκε παραπάνω. |
| **Όπως μιλήθηκε** | `language-as-spoken` | Να γράψει στη γλώσσα στην οποία έγινε η συνομιλία. |
| **Όπως μιλήθηκε, με όνομα** | `language-as-spoken-named` | Το ίδιο, κατονομάζοντας τη γλώσσα. |
| **Ορισμένη γλώσσα** | `language-named` | Να γράψει στη γλώσσα που ορίζετε. |

Η **Προσθήκη** στην αρχή της λίστας προσθέτει μια καταχώριση.

## Προεπιλογές {#defaults}

Η **Επαναφορά προεπιλογών** επαναφέρει κάθε λεξικό όπως ήρθε με το πρόγραμμα, στην τρέχουσα γλώσσα της διεπαφής. Οι κατατάξεις που έχουν ήδη γίνει στις συνομιλίες σας δεν αγγίζονται.

## Μορφές απάντησης {#response-formats}

Τα μπλοκ αναπαράγουν τις ενσωματωμένες οδηγίες. Περιγράφουν μορφές απάντησης· οι εναλλακτικές είναι τρόπος γραφής, όχι εκτελέσιμα παραδείγματα JSON.

### Πεζός λόγος (`shape-plain`) {#shape-plain}

```text
Απαντήστε σε απλό πεζό λόγο. Μη χρησιμοποιείτε JSON, λίστες ή επικεφαλίδες.
```

### Στοιχεία (`shape-list`) {#shape-list}

```text
Απαντήστε μόνο με JSON, ακριβώς αυτής της μορφής:
{"items": [{"text": "τι πρέπει να γίνει", "owner": "ποιος, ή κενό", "due": "πότε, ή κενό"}]}
Όταν δεν υπάρχει τίποτα να απαριθμηθεί, χρησιμοποιήστε κενό πίνακα. Μη γράφετε τίποτα εκτός του JSON.
```

### Ετικέτες (`shape-labels`) {#shape-labels}

```text
Απαντήστε μόνο με JSON, ακριβώς αυτής της μορφής:
{"labels": [{"code": "κωδικός από τη λίστα που σας δόθηκε", "confidence": 0.0}]}
Χρησιμοποιήστε μόνο κωδικούς από τη λίστα. Όταν δεν ταιριάζει κανένας,
χρησιμοποιήστε κενό πίνακα. Μην επινοείτε κωδικό και μη γράφετε τίποτα εκτός του JSON.
```

### Βαθμολογία (`shape-score`) {#shape-score}

```text
Απαντήστε μόνο με JSON, ακριβώς αυτής της μορφής:
{"score": 3, "rationale": "γιατί αυτός ο αριθμός και όχι ένας παραπάνω",
 "evidence": [{"at_ms": 0, "quote": "τα λόγια στα οποία στηριχτήκατε"}]}
Η βαθμολογία είναι ακέραιος από 1 έως 5. Μη γράφετε τίποτα εκτός του JSON.
```

### Κριτήρια (`shape-rubric`) {#shape-rubric}

```text
Απαντήστε μόνο με JSON, ακριβώς αυτής της μορφής:
{"overall": 3, "rationale": "γιατί αυτός ο αριθμός και όχι ένας παραπάνω",
 "criteria": [{"name": "το κριτήριο όπως σας δόθηκε",
               "verdict": "pass" ή "weak" ή "fail" ή "n/a",
               "note": "μία πρόταση"}]}
Κρίνετε κάθε κριτήριο που σας δόθηκε και κανένα άλλο. Η συνολική βαθμολογία
είναι ακέραιος από 1 έως 5. Μη γράφετε τίποτα εκτός του JSON.
```

### Ενδείξεις (`shape-flags`) {#shape-flags}

```text
Απαντήστε μόνο με JSON, ακριβώς αυτής της μορφής:
{"flags": [{"code": "κωδικός από τη λίστα που σας δόθηκε",
            "severity": "low" ή "medium" ή "high",
            "evidence": "τα λόγια στα οποία στηριχτήκατε",
            "at_ms": 0}]}
Χρησιμοποιήστε μόνο κωδικούς από τη λίστα και σηκώστε καθέναν το πολύ μία φορά.
Όταν δεν ταιριάζει τίποτα, χρησιμοποιήστε κενό πίνακα. Μη γράφετε τίποτα εκτός του JSON.
```

### Απάντηση (`shape-qa`) {#shape-qa}

```text
Απαντήστε μόνο με JSON, ακριβώς αυτής της μορφής:
{"answer": "η απάντησή σας, ή ξεκάθαρα ότι η συνομιλία δεν το λέει",
 "citations": [{"at_ms": 0, "quote": "τα λόγια στα οποία στηρίζεται η απάντηση"}]}
Μην απαντάτε από τίποτα άλλο εκτός από τη συνομιλία. Μη γράφετε τίποτα εκτός του JSON.
```

### JSON (`shape-json`) {#shape-json}

```text
Απαντήστε μόνο με JSON, στη μορφή που ζητήθηκε παραπάνω. Μη γράφετε τίποτα εκτός του JSON.
```

### Όπως μιλήθηκε (`language-as-spoken`) {#language-as-spoken}

```text
Γράψτε την απάντησή σας στην ίδια γλώσσα που είχε η συνομιλία.
```

### Όπως μιλήθηκε, με όνομα (`language-as-spoken-named`) {#language-as-spoken-named}

```text
Γράψτε την απάντησή σας στην ίδια γλώσσα που είχε η συνομιλία, δηλαδή: {language}.
```

### Ορισμένη γλώσσα (`language-named`) {#language-named}

```text
Γράψτε την απάντησή σας σε αυτή τη γλώσσα: {language}.
```
