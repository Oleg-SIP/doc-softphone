Οι **Ρυθμίσεις → Λεξικά** περιέχουν τις λέξεις στις οποίες μπορεί να καταταχθεί μια συνομιλία, με τις οποίες μπορεί να πάρει ετικέτα ή να επισημανθεί. Αυτές οι λίστες είναι αυτό που βλέπουν τα μοντέλα και από αυτές πρέπει να διαλέξουν, οπότε μια απάντηση είναι πάντα κάτι που μπορείτε να αναζητήσετε αργότερα.

<Shot name="13_settings_dictionaries" alt="Ρυθμίσεις → Λεξικά" />

Η **Εμφάνιση διαγραμμένων** δείχνει τις καταχωρίσεις που έχετε διαγράψει.

Κάθε καταχώριση είναι ένα όνομα, ένας σύντομος κωδικός με μικρά γράμματα και μια περιγραφή που λέει στο μοντέλο πότε να την επιλέξει. Ο κωδικός είναι αυτό που αποθηκεύεται και αυτό που επιστρέφει το [REST API](../integration/rest-api.md#taxonomy-and-settings), οπότε μένει ίδιος όταν μετονομάζετε την καταχώριση.

## Κατηγορίες {#categories}

Το θέμα της συνομιλίας· **επιλέγεται μία ανά συνομιλία**. Το πρόγραμμα ξεκινά με τέσσερις:

| Όνομα | Κωδικός | Χρησιμοποιείται για |
| --- | --- | --- |
| **Πωλήσεις** | `sales` | Πώληση, προσφορά τιμής, διαπραγμάτευση ή συνέχεια μιας αγοράς — όπως και όταν ένας πελάτης ρωτά πόσο κοστίζει κάτι. |
| **Υποστήριξη** | `support` | Βοήθεια σε κάποιον με ένα προϊόν ή μια υπηρεσία που ήδη έχει: μια βλάβη, μια ερώτηση για τη χρήση του, ένα παράπονο για τον τρόπο που λειτουργεί. |
| **Προσωπική** | `personal` | Καθόλου επαγγελματική — μια ιδιωτική συνομιλία που έτυχε να γίνει σε αυτή τη γραμμή. |
| **Άλλο** | `other` | Επαγγελματική, αλλά ούτε πώληση ούτε υποστήριξη: ένας προμηθευτής, ένας συνάδελφος, μια παράδοση, λάθος αριθμός. Επιλέξτε αυτό αντί να μαντεύετε ανάμεσα στις άλλες. |

Πατήστε **Προσθήκη** για να προσθέσετε μια δική σας κατηγορία.

## Ετικέτες {#tags}

Σήματα που *μπορεί να ισχύουν όλα για την ίδια συνομιλία*. Πατήστε **Προσθήκη** για να προσθέσετε μία. Η λίστα ξεκινά με καταχωρίσεις όπως:

| Όνομα | Κωδικός | Χρησιμοποιείται για |
| --- | --- | --- |
| **Υποσχέθηκε επιστροφή κλήσης** | `callback` | Κάποιος σε αυτή την κλήση υποσχέθηκε να καλέσει πίσω ή ζήτησε να τον καλέσουν πίσω. |
| **Παράπονο** | `complaint` | Ο συνομιλητής εξέφρασε δυσαρέσκεια, είτε λύθηκε είτε όχι. |
| **Κλιμακώθηκε** | `escalation` | Η κλήση μεταβιβάστηκε σε κάποιον άλλον ή ο συνομιλητής ζήτησε να μεταβιβαστεί. |
| **Πελάτης VIP** | `vip` | Ο συνομιλητής αντιμετωπίστηκε ως σημαντικός πελάτης ή δήλωσε ότι είναι. |

## Ενδείξεις προσοχής {#red-flags}

Πράγματα που χρειάζονται προσοχή, που βρέθηκαν στη συνομιλία με την απόδειξη και τη χρονική στιγμή — για παράδειγμα *Θυμωμένος πελάτης* ή *Κίνδυνος αποχώρησης*. Οι ενδείξεις προσοχής εμφανίζονται με κόκκινο χρώμα στο [παράθυρο Εγγραφές](../interface/recordings.md), και η καθεμία φέρει έναν βαθμό σοβαρότητας: χαμηλό, μέτριο ή υψηλό.

## Σχήματα απάντησης και γλώσσα {#answer-shapes-and-language}

<Shot name="13b_settings_dictionaries_scrolled" alt="Ρυθμίσεις → Λεξικά: σχήματα απάντησης και οδηγίες γλώσσας" />

Πιο κάτω στην καρτέλα βρίσκονται οι οδηγίες από τις οποίες συντίθενται οι οδηγίες προς τα μοντέλα. Φυλάσσονται εδώ ώστε κάθε οδηγία να μπορεί να χρησιμοποιεί την ίδια διατύπωση, και μπορείτε να τις αλλάξετε όπως κάθε άλλη καταχώριση.

| Όνομα | Κωδικός | Τι λέει στο μοντέλο |
| --- | --- | --- |
| **Ετικέτες** | `shape-labels` | Να απαντήσει σε JSON με μια λίστα κωδικών και πόσο σίγουρο είναι για τον καθένα, χρησιμοποιώντας μόνο κωδικούς από τη λίστα που του δόθηκε. |
| **Βαθμολογία** | `shape-score` | Να απαντήσει με μια βαθμολογία, την αιτιολόγησή της και τα λόγια στα οποία βασίζεται. |
| **Κριτήρια** | `shape-rubric` | Να απαντήσει με μια συνολική βαθμολογία και μια βαθμολογία για κάθε κριτήριο. |
| **Ενδείξεις** | `shape-flags` | Να απαντήσει με κωδικούς από τη λίστα, τον καθένα με έναν βαθμό σοβαρότητας. |
| **Απάντηση** | `shape-qa` | Να απαντήσει με την απόκριση, ή να πει καθαρά ότι η συνομιλία δεν το αναφέρει, και με τα λόγια στα οποία στηρίζεται η απόκριση. |
| **JSON** | `shape-json` | Να απαντήσει μόνο με JSON, στο σχήμα που ζητήθηκε παραπάνω. |
| **Όπως μιλήθηκε** | `language-as-spoken` | Να γράψει στη γλώσσα στην οποία έγινε η συνομιλία. |
| **Όπως μιλήθηκε, με όνομα** | `language-as-spoken-named` | Το ίδιο, κατονομάζοντας τη γλώσσα. |
| **Ορισμένη γλώσσα** | `language-named` | Να γράψει στη γλώσσα που ορίζετε. |

Η **Προσθήκη** στο τέλος της λίστας προσθέτει μια καταχώριση.

## Προεπιλογές {#defaults}

Η **Επαναφορά προεπιλογών** επαναφέρει κάθε λεξικό όπως ήρθε με το πρόγραμμα, στην τρέχουσα γλώσσα της διεπαφής. Οι κατατάξεις που έχουν ήδη γίνει στις συνομιλίες σας δεν αγγίζονται.
