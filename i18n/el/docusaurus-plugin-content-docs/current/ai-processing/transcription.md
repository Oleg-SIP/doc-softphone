Οι **Ρυθμίσεις → Απομαγνητοφώνηση** ορίζουν πώς ο ήχος γίνεται κείμενο: σε ποια γλώσσα και από ποιον αναγνωριστή.

<Shot name="25_transcription" alt="Ρυθμίσεις → Απομαγνητοφώνηση: η γλώσσα και τέσσερις αναγνωριστές" />

Μια συνομιλία απομαγνητοφωνείται όταν το ζητήσετε στο [παράθυρο Εγγραφές](/interface/recordings), ή αυτόματα αν η **Αυτόματη επεξεργασία συνομιλιών** είναι ενεργή στην [Επεξεργασία](/ai-processing/processing). Ένας αναγνωριστής στον δικό σας υπολογιστή δεν κοστίζει τίποτα· ένας στο cloud χρεώνει ανά λεπτό ήχου.

## Γλώσσα {#language}

Η **Γλώσσα** είναι ένας κωδικός γλώσσας δύο γραμμάτων κατά ISO 639-1 (`en`, `de`, `es`, `fr`, `sr`…). Αφήστε την κενή και αποφασίζει ο αναγνωριστής — αυτό είναι το σωστό, εκτός αν οι κλήσεις σας είναι σε μια γλώσσα που ο αναγνωριστής συνεχώς παρακούει.

## Αναγνωριστές {#recognisers}

Ένας αναγνωριστής είναι μια υπηρεσία μετατροπής ομιλίας σε κείμενο στην οποία το τηλέφωνο στέλνει τον ήχο. Πατήστε **Προσθήκη** για να προσθέσετε έναν· το κουμπί **Δοκιμή** της φόρμας ελέγχει ότι η υπηρεσία πράγματι απαντά. Ο καθένας εμφανίζεται με το όνομά του και, από κάτω, το μοντέλο και τη διεύθυνση της υπηρεσίας του. Στην εικόνα υπάρχουν τέσσερις:

| Όνομα | Μοντέλο | Διεύθυνση |
| --- | --- | --- |
| **X.ai** | *(κενό: η προεπιλογή της υπηρεσίας)* | `https://api.x.ai/v1` |
| **ElevenLabs** | `scribe_v2` | `https://api.elevenlabs.io/v1` |
| **Deepgram** | `nova-2` | `https://api.deepgram.com/v1` |
| **OpenAI** | `gpt-4o-transcribe` | `https://api.openai.com/v1/` |

Αυτός που φέρει την ένδειξη **Προεπιλογή** στα δεξιά της γραμμής του (στην εικόνα το **X.ai**) είναι αυτός που χρησιμοποιείται όταν δεν επιλέγετε άλλον. Μπορείτε να κρατάτε αρκετούς. Η αναπτυσσόμενη λίστα πάνω από μια απομαγνητοφώνηση στο [παράθυρο Εγγραφές](/interface/recordings#transcript-or-write-up-the-drop-down) δείχνει τις απομαγνητοφωνήσεις που έκανε κάθε αναγνωριστής.

Το μοντέλο μπορεί να μείνει κενό. Η υπηρεσία χρησιμοποιεί τότε τη δική της προεπιλογή.

## Ποιο μοντέλο να επιλέξετε {#which-model-to-choose}

Ο πίνακας παραθέτει τα μοντέλα μετατροπής ομιλίας σε κείμενο των τεσσάρων υπηρεσιών της εικόνας. Τα μοντέλα σε **έντονη γραφή** είναι αυτά που έχουν ρυθμιστεί στην εικόνα. Για τον αναγνωριστή X.ai το μοντέλο είναι κενό, οπότε χρησιμοποιείται η προεπιλογή της υπηρεσίας, **`grok-voice-transcribe-2.0`**.

| Υπηρεσία και διεύθυνση | Μοντέλο | Σε τι χρησιμεύει |
| --- | --- | --- |
| **OpenAI**<br />`https://api.openai.com/v1` | `gpt-transcribe` | Το μοντέλο που προτείνει η OpenAI για ηχογραφημένη ομιλία στην αρχική της γλώσσα. |
| | **`gpt-4o-transcribe`** | Απομαγνητοφώνηση γενικής χρήσης. |
| | `gpt-4o-mini-transcribe` | Μια ελαφρύτερη, φθηνότερη παραλλαγή του παραπάνω. |
| | `gpt-4o-transcribe-diarize` | Σημειώνει ποιος μιλά πότε. Χρησιμοποιήστε το μόνο αν το χρειάζεστε. |
| | `whisper-1` | Το παλαιότερο μοντέλο Whisper, που διατηρείται για ειδικές χρήσεις, όπως χρονοσημάνσεις λέξεων και υπότιτλους. |
| **ElevenLabs**<br />`https://api.elevenlabs.io/v1` | **`scribe_v2`** | Απομαγνητοφώνηση γενικής χρήσης σε 90+ γλώσσες, με διάκριση ομιλητών. |
| | `scribe_v2_medical` | Το ίδιο, προσαρμοσμένο για κλινικό ήχο. |
| | `scribe_v1` | Η πρώτη γενιά· έχει καταργηθεί, χρησιμοποιήστε το `scribe_v2`. |
| **Deepgram**<br />`https://api.deepgram.com/v1` | `nova-3` | Το καλύτερο μοντέλο γενικής χρήσης της Deepgram, για συναντήσεις, θορυβώδη και πολύγλωσσο ήχο. |
| | **`nova-2`** | Η προηγούμενη γενιά· κρατήστε το για γλώσσες που το `nova-3` δεν υποστηρίζει ακόμη. |
| | `enhanced` | Μια παλαιότερη βαθμίδα με χαμηλότερα ποσοστά σφαλμάτων από το `base`. |
| | `base` | Η παλαιότερη βαθμίδα, για μεγάλους όγκους. |
| | `whisper` | Το Whisper, που εκτελείται από την Deepgram. |
| **X.ai**<br />`https://api.x.ai/v1` | **`grok-voice-transcribe-2.0`** | Η προεπιλογή· 25 γλώσσες. |
| | `grok-voice-transcribe-1.0` | Έχει καταργηθεί: η υπηρεσία το ανακατευθύνει στο `2.0`. |

Τι αξίζει να ξέρετε πριν επιλέξετε:

- **Μέγεθος αρχείου.** Η OpenAI δέχεται αρχεία έως 25 MB· η X.ai έως 500 MB. Μια μεγάλη συνομιλία μπορεί να είναι μεγαλύτερη από όσο δέχεται μια υπηρεσία cloud.
- **Τιμή.** Οι υπηρεσίες cloud χρεώνουν ανά λεπτό ήχου, και οι τιμές διαφέρουν ανά μοντέλο και αλλάζουν· διαβάστε τις στη σελίδα της ίδιας της υπηρεσίας πριν αλλάξετε.
- **Γλώσσες.** Κάθε υπηρεσία έχει τη δική της λίστα· ελέγξτε τη δική σας και ορίστε τον κωδικό [Γλώσσας](#language) αν ο αναγνωριστής μαντεύει λάθος.
- **Μοντέλα πραγματικού χρόνου**, όπως το `scribe_v2_realtime` ή το `flux` της Deepgram, είναι φτιαγμένα για ζωντανές ροές και δεν περιλαμβάνονται στον πίνακα: το τηλέφωνο απομαγνητοφωνεί ολοκληρωμένες εγγραφές.

Η λίστα των μοντέλων μιας υπηρεσίας αλλάζει συχνά. Αν λείπει από εδώ ένα μοντέλο που θέλετε, η τεκμηρίωση της ίδιας της υπηρεσίας έχει την τρέχουσα λίστα — [OpenAI](https://developers.openai.com/api/docs/guides/speech-to-text), [ElevenLabs](https://elevenlabs.io/docs/capabilities/speech-to-text), [Deepgram](https://developers.deepgram.com/docs/models-languages-overview), [X.ai](https://docs.x.ai/developers/model-capabilities/audio/speech-to-text) — και το **Μοντέλο** είναι το όνομα ακριβώς όπως το δίνει η υπηρεσία.

## Τα δικά σας μοντέλα {#your-own-models}

Ένας αναγνωριστής δεν χρειάζεται να είναι υπηρεσία cloud. Το τηλέφωνο μπορεί να χρησιμοποιήσει **οποιοδήποτε μοντέλο διατίθεται μέσω του API που είναι συμβατό με το OpenAI** — τη διεπαφή `POST /v1/audio/transcriptions` — είτε εκτελείται τοπικά στον υπολογιστή σας είτε σε δικό σας διακομιστή. Ο ήχος δεν βγαίνει ποτέ από τους χώρους σας, δεν υπάρχει χρέωση ανά λεπτό και δεν υπάρχει όριο στον όγκο.

Για να προσθέσετε ένα, πατήστε **Προσθήκη** και δώστε:

- τη **διεύθυνση** του διακομιστή, έως και το `/v1`, για παράδειγμα `http://localhost:8000/v1` για τον ίδιο τον υπολογιστή ή `http://asr.local:8080/v1` για έναν διακομιστή στο δίκτυό σας·
- το όνομα του **μοντέλου** ακριβώς όπως το αναφέρει ο διακομιστής, για παράδειγμα `openai/whisper-large-v3-turbo`.

### Τι μπορεί να χρησιμοποιηθεί {#what-can-be-used}

Η συνηθισμένη επιλογή είναι το **Whisper**, το ανοιχτό μοντέλο αναγνώρισης ομιλίας της OpenAI. Η χρήση του είναι δωρεάν, καταλαβαίνει περίπου εκατό γλώσσες και διατίθεται σε διάφορα μεγέθη: ένα μικρό μοντέλο τρέχει σε έναν συνηθισμένο υπολογιστή, ενώ τα μεγάλα είναι αισθητά πιο ακριβή και καλό είναι να έχουν κάρτα γραφικών.

| Μοντέλο | Σημειώσεις |
| --- | --- |
| `whisper-large-v3` | Το πιο ακριβές Whisper. Για διακομιστή με GPU. |
| `openai/whisper-large-v3-turbo` | Μια ταχύτερη έκδοση του `large-v3` με μικρή απώλεια ακρίβειας. |
| `Systran/faster-whisper-large-v3` | Το `large-v3` μετατρεμμένο για τη μηχανή faster-whisper· ταχύτερο και ελαφρύτερο στη μνήμη. |
| `medium`, `small`, `base` | Μικρότερα μοντέλα Whisper, για υπολογιστή χωρίς κάρτα γραφικών. |

Το Whisper είναι το μοντέλο γύρω από το οποίο έχουν χτιστεί αυτοί οι διακομιστές. Μερικοί από αυτούς μπορούν να εξυπηρετήσουν και άλλα μοντέλα αναγνώρισης ομιλίας, όπως το NVIDIA Parakeet.

### Διακομιστές που προσφέρουν το API που είναι συμβατό με το OpenAI {#servers-that-offer-the-openai-compatible-api}

Το μοντέλο πρέπει να εκτελείται από έναν διακομιστή που προσφέρει το σημείο πρόσβασης `/v1/audio/transcriptions`, συμβατό με το OpenAI. Το προσφέρουν οι εξής:

| Διακομιστής | Τι είναι |
| --- | --- |
| [vLLM](https://docs.vllm.ai/en/latest/serving/online_serving/speech_to_text/) | Ένας διακομιστής μοντέλων υψηλών επιδόσεων. Εξυπηρετεί το Whisper στο `http://localhost:8000/v1` μόλις ξεκινήσει. |
| [Speaches](https://github.com/speaches-ai/speaches) | Ένας διακομιστής για μοντέλα ομιλίας, «το Ollama για την ομιλία», χτισμένος πάνω στο faster-whisper. Φορτώνει ένα μοντέλο την πρώτη φορά που του ζητείται. |
| [whisper.cpp](https://github.com/ggml-org/whisper.cpp) | Εκτελεί το Whisper αποδοτικά σε CPU, και σε Apple silicon. Ο `whisper-server` του ξεκινά με `--inference-path /v1/audio/transcriptions`. |
| [LocalAI](https://localai.io/) | Ένα άμεσο υποκατάστατο του OpenAI που εκτελεί τα μοντέλα τοπικά. |

Οποιοσδήποτε άλλος διακομιστής προσφέρει το ίδιο σημείο πρόσβασης λειτουργεί με τον ίδιο τρόπο. Αν ένας διακομιστής χρειάζεται κλειδί, εισαγάγετέ το όπως για μια υπηρεσία cloud.

Πριν βασιστείτε σε έναν διακομιστή, κάντε μια δοκιμαστική εγγραφή και δείτε την απομαγνητοφώνηση στο [παράθυρο Εγγραφές](/interface/recordings): μια συνομιλία σε γλώσσα που το μοντέλο γνωρίζει ελάχιστα το δείχνει αμέσως.
