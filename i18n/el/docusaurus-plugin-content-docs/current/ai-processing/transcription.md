Οι **Ρυθμίσεις → Απομαγνητοφώνηση** παραθέτουν τους αναγνωριστές: τις υπηρεσίες που μετατρέπουν τον ήχο σε κείμενο, για ολοκληρωμένες συνομιλίες και, για τον [υποβολέα](../interface/prompter.md), όσο διαρκεί μια συνομιλία.

<Shot name="25_transcription" alt="Ρυθμίσεις → Απομαγνητοφώνηση: πέντε αναγνωριστές" />

Μια συνομιλία απομαγνητοφωνείται όταν το ζητήσετε στο [παράθυρο Εγγραφές](/interface/recordings), ή μόνη της αν στην [Επεξεργασία](/ai-processing/processing) είναι ενεργή η **Αυτόματη επεξεργασία συνομιλιών**. Ένας αναγνωριστής στο δικό σας μηχάνημα δεν κοστίζει τίποτα· ένας στο νέφος χρεώνει ανά λεπτό ήχου.

## Αναγνωριστές {#recognisers}
Αναγνωριστής είναι μια υπηρεσία αναγνώρισης ομιλίας στην οποία το τηλέφωνο στέλνει τον ήχο. Η **Προσθήκη** προσθέτει έναν· το κουμπί **Δοκιμή** στην καρτέλα του ελέγχει ότι η υπηρεσία όντως απαντά. Καθένας εμφανίζεται στη λίστα με το όνομά του και από κάτω το μοντέλο και τη διεύθυνση της υπηρεσίας του. Στην εικόνα είναι πέντε:

| Όνομα | Μοντέλο | Διεύθυνση |
| --- | --- | --- |
| **X.ai** | *(κενό: το προεπιλεγμένο μοντέλο της υπηρεσίας)* | `https://api.x.ai/v1` |
| **ElevenLabs** | `scribe_v2` | `https://api.elevenlabs.io/v1` |
| **Deepgram** | `nova-2` | `https://api.deepgram.com/v1` |
| **OpenAI** | `gpt-4o-transcribe` | `https://api.openai.com/v1/` |
| **Vosk** | *(κανένα)* | `ws://localhost:2700`, ένας διακομιστής σε αυτόν τον υπολογιστή |

Τα δύο σημάδια στα δεξιά μιας γραμμής λένε για τι είναι προεπιλογή ο αναγνωριστής. Το ρολόι ανάβει στην προεπιλογή **για τις απομαγνητοφωνήσεις** — στην εικόνα ο **X.ai** —, που χρησιμοποιείται όταν δεν επιλέγετε άλλον. Ο κεραυνός ανάβει στην προεπιλογή **για τον υποβολέα** — στην εικόνα ο **Vosk**. Μπορείτε να κρατάτε πολλούς αναγνωριστές· η αναπτυσσόμενη λίστα πάνω από μια απομαγνητοφώνηση στο [παράθυρο Εγγραφές](/interface/recordings#transcript-or-write-up-the-drop-down) δείχνει τις απομαγνητοφωνήσεις που έκανε ο καθένας.

## Η καρτέλα του αναγνωριστή {#the-recognisers-card}
Πατώντας έναν αναγνωριστή ανοίγει η καρτέλα του.

<Shot name="43_recogniser_card" alt="Η καρτέλα του αναγνωριστή X.ai: είδος, οι δύο διευθύνσεις, κλειδί, Δοκιμή και οι προεπιλογές" />

| Πεδίο | Τι είναι |
| --- | --- |
| **Όνομα** | Το όνομα στις λίστες. |
| **Είδος** | Το είδος της υπηρεσίας, που καθορίζει πώς μιλά το τηλέφωνο μαζί της: **Συμβατό με OpenAI (Whisper, OpenAI)**, **Deepgram**, **ElevenLabs (Scribe)**, **xAI (Grok)**, **AssemblyAI**, **Soniox**, **Speechmatics** και τρία που τρέχουν στο δικό σας μηχάνημα — **Vosk**, **WhisperLive** και **NVIDIA Riva**. Το **Yandex SpeechKit** προσφέρεται όταν η χώρα στα [Σχετικά](../application/about.md) είναι η Ρωσία ή κάποια από τις γειτονικές της. |
| **Διεύθυνση για τις απομαγνητοφωνήσεις** | Πού στέλνονται οι ολοκληρωμένες συνομιλίες. |
| **Διεύθυνση για τον υποβολέα** | Πού πηγαίνει ο ζωντανός ήχος όσο διαρκεί μια συνομιλία. *Το κενό προκύπτει από τη διεύθυνση δίπλα*, όπως το `wss://api.x.ai` στην εικόνα. |
| **Κλειδί** | Το κλειδί της υπηρεσίας. *Φυλάσσεται στην κλειδοθήκη αυτού του υπολογιστή, ποτέ σε αρχείο ρυθμίσεων.* |
| **Δοκιμή** | Ρωτά την υπηρεσία και λέει τι απάντησε, για παράδειγμα *Απάντησε, και προσφέρει 3 μοντέλα*. |
| **Μοντέλο για τις απομαγνητοφωνήσεις** και **Μοντέλο για τον υποβολέα** | Το μοντέλο, ακριβώς όπως το ονομάζει η υπηρεσία. *Κενό δεν στέλνει όνομα μοντέλου*, και η υπηρεσία χρησιμοποιεί τη δική της προεπιλογή· όπου ο πάροχος δημοσιεύει μία, η καρτέλα την αναφέρει. Για είδος χωρίς επιλογή το πεδίο δεν εμφανίζεται. |
| **Προεπιλογή για τις απομαγνητοφωνήσεις** | Κάνει αυτόν τον αναγνωριστή εκείνον που χρησιμοποιείται όταν δεν επιλέγετε άλλον. |
| **Προεπιλογή για τον υποβολέα** | Κάνει αυτόν τον αναγνωριστή εκείνον με τον οποίο ακούει ένας νέος βοηθός του υποβολέα. |
| **Ενεργό** | Ανενεργός, ο αναγνωριστής μένει στη λίστα και δεν χρησιμοποιείται. |

Οι **Προχωρημένες ρυθμίσεις** ανοίγουν το υπόλοιπο της καρτέλας. Οι τιμές που μετρούν περισσότερο:

<Shot name="43b_recogniser_advanced" alt="Οι προχωρημένες ρυθμίσεις ενός αναγνωριστή: όρια, πώς κόβονται οι απαντήσεις, η γλώσσα" />

| Πεδίο | Τι κάνει |
| --- | --- |
| **Περιοχή** | Η περιοχή της υπηρεσίας, για μία που έχει πολλές. |
| **Στείλε τις δύο πλευρές χωριστά** | Μια κλήση καταγράφεται με τα δύο πρόσωπα σε δύο κανάλια, και αυτό λέει στον αναγνωριστή ποιος είπε τι. Απενεργοποιήστε το για διακομιστή που λέει ότι μπορεί να το κάνει και δεν μπορεί. |
| **Ζήτησε ποιος μιλάει** | Ξεχωρίζει τα πρόσωπα μέσα σε ένα κανάλι, όταν μιλούν σε αυτό πολλά. |
| **Αριθμοί με ψηφία** | Ποσά, ημερομηνίες και αριθμοί τηλεφώνου επιστρέφουν όπως γράφονται, όχι ολογράφως. |
| **Όριο αποστολής**, **Όριο διάρκειας** | Το μεγαλύτερο αρχείο σε byte και η μεγαλύτερη εγγραφή σε δευτερόλεπτα που θα στείλει αυτό το τηλέφωνο. |
| **Ταυτόχρονα αιτήματα** | Πόσα αιτήματα μπορούν να εκτελούνται ταυτόχρονα. |
| **Τερματισμός απάντησης μετά από**, **Συνένωση σύντομων απαντήσεων εντός**, **Κενό μεταξύ σειρών** | Για τον υποβολέα: πόσος χρόνος χωρίς νέες λέξεις τερματίζει μια απάντηση, πόσο περιμένει μια σύντομη απάντηση την επόμενη για να ενωθεί μαζί της, και πόση σιωπή τερματίζει μια σειρά ομιλίας όπου ο αναγνωριστής δεν σημειώνει καμία. Σε χιλιοστά του δευτερολέπτου. |
| **Γλώσσα** | Ένας δίγραμμος κωδικός γλώσσας κατά ISO 639-1 (`en`, `de`, `es`, `fr`, `sr`…). Αφήστε τον κενό και αποφασίζει ο αναγνωριστής — αυτό είναι σωστό, εκτός αν οι κλήσεις σας γίνονται σε γλώσσα που συνεχώς παρακούει. |
| **Πρόσθετα** | Ένα `name = value` ανά γραμμή, που περνά στην υπηρεσία όπως είναι. Αφήστε το κενό, εκτός αν ο διακομιστής τεκμηριώνει κάτι. |
| **Αναμονή, λεπτά** | Πόση ώρα να περιμένει μια απομαγνητοφώνηση. Το κενό το υπολογίζει από τη διάρκεια της εγγραφής. |
| **Τιμή ανά λεπτό** | Πόσο κοστίζει ένα λεπτό ζωντανού ήχου, από τον τιμοκατάλογο της υπηρεσίας. Ο υποβολέας δείχνει πόσο κόστισε μια συνεδρία και σταματά στο [μηνιαίο όριό](prompter.md#spending) του. |

## Ζωντανή αναγνώριση για τον υποβολέα {#live-recognition-for-the-prompter}
Ο [υποβολέας](../interface/prompter.md) χρειάζεται έναν αναγνωριστή που ακούει όσο κάποιος μιλά, μέσω ροής και όχι με ολοκληρωμένο αρχείο. Αυτά τα είδη μπορούν: **Deepgram**, **ElevenLabs (Scribe)**, **xAI (Grok)**, **Συμβατό με OpenAI** (με τη ζωντανή απομαγνητοφώνηση της OpenAI), **AssemblyAI**, **Soniox** και **Speechmatics** στο νέφος, **Yandex SpeechKit** όπου προσφέρεται, και **Vosk**, **WhisperLive** και **NVIDIA Riva** στο δικό σας μηχάνημα. Ένας αναγνωριστής στο δικό σας μηχάνημα κρατά τη φωνή του συνομιλητή μέσα στο κτίριο και δεν χρεώνει τίποτα.

Για να χρησιμοποιήσετε έναν: ανοίξτε την καρτέλα του, ελέγξτε τη **Διεύθυνση για τον υποβολέα** (ή αφήστε την να προκύψει), επιλέξτε το **Μοντέλο για τον υποβολέα** όπου η υπηρεσία προσφέρει πολλά — τα ζωντανά μοντέλα συχνά διαφέρουν από αυτά για αρχεία, όπως το `scribe_v2_realtime` της ElevenLabs — και πατήστε **Δοκιμή**. Τσεκάρετε την **Προεπιλογή για τον υποβολέα** ώστε οι νέοι βοηθοί να ακούν με αυτόν.

## Ποιο μοντέλο να επιλέξετε {#which-model-to-choose}
Ο πίνακας παραθέτει τα μοντέλα αναγνώρισης ομιλίας κάθε είδους της λίστας **Είδος**. Τα μοντέλα με **έντονα** είναι αυτά που έχουν ρυθμιστεί στην εικόνα· για τον αναγνωριστή X.ai το μοντέλο είναι κενό, οπότε χρησιμοποιείται η προεπιλογή της υπηρεσίας, **`grok-voice-transcribe-2.0`**. Η στήλη **Για** λέει για τι είναι φτιαγμένο ένα μοντέλο: για ολοκληρωμένες εγγραφές (*απομαγνητοφωνήσεις*), για ζωντανή ομιλία για τον [υποβολέα](#live-recognition-for-the-prompter) (*υποβολέας*) ή για *και τα δύο*.

| Είδος και διεύθυνση | Μοντέλο | Για | Σε τι χρησιμεύει |
| --- | --- | --- | --- |
| **Συμβατό με OpenAI (Whisper, OpenAI)**<br />`https://api.openai.com/v1` | `gpt-transcribe` | απομαγνητοφωνήσεις | Το μοντέλο που προτείνει η OpenAI για ηχογραφημένη ομιλία στην αρχική της γλώσσα. |
| | **`gpt-4o-transcribe`** | και τα δύο | Απομαγνητοφώνηση γενικής χρήσης. Το παίρνει ένας νέος αναγνωριστής αυτού του είδους. |
| | `gpt-4o-mini-transcribe` | και τα δύο | Μια ελαφρύτερη, φθηνότερη παραλλαγή του παραπάνω. |
| | `gpt-4o-transcribe-diarize` | απομαγνητοφωνήσεις | Σημειώνει ποιος μιλά πότε. Χρησιμοποιήστε το μόνο αν το χρειάζεστε. |
| | `whisper-1` | απομαγνητοφωνήσεις | Το παλαιότερο μοντέλο Whisper, που κρατήθηκε για ειδικές χρήσεις όπως χρονοσημάνσεις λέξεων και υπότιτλους. |
| | `gpt-live-transcribe` | υποβολέας | Το ζωντανό μοντέλο της OpenAI: οι λέξεις έρχονται καθώς λέγονται. Το τηλέφωνο το προτείνει για τον υποβολέα. |
| **Deepgram**<br />`https://api.deepgram.com/v1` | `nova-3` | και τα δύο | Το καλύτερο μοντέλο γενικής χρήσης της Deepgram, για συσκέψεις, θορυβώδη και πολύγλωσσο ήχο. Το παίρνει ένας νέος αναγνωριστής αυτού του είδους. |
| | **`nova-2`** | και τα δύο | Η προηγούμενη γενιά· κρατήστε την για γλώσσες που το `nova-3` δεν υποστηρίζει ακόμη. |
| | `nova-2-phonecall` | και τα δύο | Το `nova-2` ρυθμισμένο για τον στενό ήχο μιας τηλεφωνικής γραμμής. Αγγλικά. |
| | `flux-general-en` | υποβολέας | Φτιαγμένο για συνομιλία: ακούει πότε κάποιος τελείωσε να μιλά. Αγγλικά. |
| | `flux-general-multi` | υποβολέας | Το ίδιο σε δέκα γλώσσες, και μια συνομιλία μπορεί να περνά από τη μία στην άλλη. |
| | `enhanced`, `base` | απομαγνητοφωνήσεις | Παλαιότερα επίπεδα· το `base` είναι για μεγάλους όγκους. |
| | `whisper` | απομαγνητοφωνήσεις | Το Whisper, που το τρέχει η Deepgram. |
| **ElevenLabs (Scribe)**<br />`https://api.elevenlabs.io/v1` | **`scribe_v2`** | απομαγνητοφωνήσεις | Απομαγνητοφώνηση γενικής χρήσης σε περισσότερες από 90 γλώσσες, με διαχωρισμό ομιλητών. |
| | `scribe_v2_realtime` | υποβολέας | Η ζωντανή έκδοση του `scribe_v2`. Το τηλέφωνο την προτείνει για τον υποβολέα. |
| | `scribe_v2_medical` | απομαγνητοφωνήσεις | Το `scribe_v2` ρυθμισμένο για κλινικό ήχο. |

| **Speechmatics**<br />`https://asr.api.speechmatics.com/v2` | `enhanced` | και τα δύο | Το πιο ακριβές, για συνομιλία σε μία γλώσσα. Το παίρνει ένας νέος αναγνωριστής αυτού του είδους. |
| | `standard` | και τα δύο | Πιο γρήγορο και φθηνότερο, λίγο λιγότερο ακριβές. |

| **Soniox**<br />`https://api.soniox.com` | `stt-async-v5` | απομαγνητοφωνήσεις | Περισσότερες από 60 γλώσσες, με διαχωρισμό ομιλητών. |
| | `stt-rt-v5` | υποβολέας | Ζωντανά, στις ίδιες 60+ γλώσσες, και ακούει πού τελειώνει μια σειρά ομιλίας. Το τηλέφωνο το προτείνει για τον υποβολέα. |
| **AssemblyAI**<br />`https://api.assemblyai.com` | `universal-3-5-pro` | και τα δύο | Το πιο ακριβές μοντέλο για εγγραφές· 18 γλώσσες, και μια συνομιλία μπορεί να περνά από τη μία στην άλλη. |
| | `universal-2` | απομαγνητοφωνήσεις | 99 γλώσσες, φθηνότερο· η AssemblyAI καταφεύγει σε αυτό για γλώσσα που το `universal-3-5-pro` δεν γνωρίζει. |
| | `universal-3-6-pro` | υποβολέας | Το νεότερο ζωντανό μοντέλο της AssemblyAI, 32 γλώσσες· η υπηρεσία το χρησιμοποιεί όταν το μοντέλο είναι κενό. |
| | `universal-streaming-multilingual` | υποβολέας | Φθηνότερη ζωντανή αναγνώριση σε αγγλικά, ισπανικά, γερμανικά, γαλλικά, πορτογαλικά και ιταλικά. |
| | `universal-streaming-english` | υποβολέας | Φθηνότερη ζωντανή αναγνώριση, μόνο στα αγγλικά. |
| **Yandex SpeechKit**<br />`https://stt.api.cloud.yandex.net` | `general` | και τα δύο | Το κύριο μοντέλο, δυνατό στα ρωσικά, και στο τηλέφωνο. Προσφέρεται όταν η χώρα είναι η Ρωσία ή κάποια από τις γειτονικές της. |
| | `general:rc` | και τα δύο | Η επόμενη έκδοση του μοντέλου πριν από την κυκλοφορία της. |
| | `deferred-general` | απομαγνητοφωνήσεις | Αναβαλλόμενη αναγνώριση: η απομαγνητοφώνηση έρχεται αργότερα, με λιγότερα χρήματα. |
| **Vosk (στο δικό σας μηχάνημα)**<br />`ws://localhost:2700` | *(ορίζεται στον διακομιστή)* | και τα δύο | Δωρεάν και ελαφρύ· τρέχει χωρίς κάρτα γραφικών. Το μοντέλο είναι αυτό με το οποίο ξεκίνησε ο διακομιστής, ένα ανά γλώσσα, για παράδειγμα `vosk-model-el-gr-0.7` ή `vosk-model-en-us-0.22`. |
| **WhisperLive (στο δικό σας μηχάνημα)**<br />`ws://localhost:9090` | `small` | και τα δύο | Το Whisper σε ζωντανή ροή. Το μέγεθος επιλέγεται στην καρτέλα: `tiny`, `base`, `small` (αυτό προτείνει το τηλέφωνο), `medium`, `large-v3`· όσο μεγαλύτερο, τόσο πιο ακριβές και τόσο περισσότερο θέλει κάρτα γραφικών. |
| **NVIDIA Riva (στο δικό σας μηχάνημα)**<br />`localhost:50051` | *(ορίζεται στον διακομιστή)* | και τα δύο | Ο διακομιστής ομιλίας της NVIDIA, για υπολογιστή με κάρτα γραφικών NVIDIA. Εξυπηρετεί μοντέλα όπως τα Parakeet και Canary. |

Τι αξίζει να ξέρετε πριν επιλέξετε:

- **Απομαγνητοφωνήσεις ή υποβολέας.** Ένα μοντέλο για ζωντανή ομιλία δεν δέχεται ολοκληρωμένο αρχείο, και τα περισσότερα μοντέλα για αρχεία δεν μπορούν να ακούν ζωντανά. Γι' αυτό μια καρτέλα έχει δύο πεδία, **Μοντέλο για τις απομαγνητοφωνήσεις** και **Μοντέλο για τον υποβολέα**.
- **Μέγεθος αρχείου.** Η OpenAI δέχεται αρχεία έως 25 MB· η X.ai έως 500 MB. Μια μεγάλη συνομιλία μπορεί να είναι μεγαλύτερη από όσο δέχεται μια υπηρεσία νέφους.
- **Τιμή.** Οι υπηρεσίες νέφους χρεώνουν ανά λεπτό ήχου, και οι τιμές διαφέρουν ανά μοντέλο και αλλάζουν· διαβάστε τες στη σελίδα της ίδιας της υπηρεσίας πριν αλλάξετε. Ένας αναγνωριστής στο δικό σας μηχάνημα δεν κοστίζει τίποτα.
- **Γλώσσες.** Κάθε υπηρεσία έχει τη δική της λίστα· ελέγξτε τη δική σας και ορίστε τον κωδικό στη **Γλώσσα** στις προχωρημένες ρυθμίσεις του αναγνωριστή, αν μαντεύει λάθος.

Η λίστα μοντέλων μιας υπηρεσίας αλλάζει συχνά. Αν λείπει εδώ ένα μοντέλο που θέλετε, η τεκμηρίωση της ίδιας της υπηρεσίας έχει την τρέχουσα λίστα — [OpenAI](https://developers.openai.com/api/docs/guides/speech-to-text), [Deepgram](https://developers.deepgram.com/docs/models-languages-overview), [ElevenLabs](https://elevenlabs.io/docs/capabilities/speech-to-text), [Speechmatics](https://docs.speechmatics.com/speech-to-text/models), [X.ai](https://docs.x.ai/developers/model-capabilities/audio/speech-to-text), [Soniox](https://soniox.com/docs/stt/models), [AssemblyAI](https://www.assemblyai.com/docs/getting-started/models), [Yandex SpeechKit](https://yandex.cloud/en/docs/speechkit/stt/models), [Vosk](https://alphacephei.com/vosk/models), [WhisperLive](https://github.com/collabora/WhisperLive), [NVIDIA Riva](https://docs.nvidia.com/deeplearning/riva/user-guide/docs/asr/asr-overview.html) — και το **Μοντέλο** είναι το όνομα ακριβώς όπως το δίνει η υπηρεσία.

## Τα δικά σας μοντέλα {#your-own-models}

Ένας αναγνωριστής δεν χρειάζεται να είναι υπηρεσία cloud. Το τηλέφωνο μπορεί να χρησιμοποιήσει **οποιοδήποτε μοντέλο διατίθεται μέσω του API που είναι συμβατό με το OpenAI** — τη διεπαφή `POST /v1/audio/transcriptions` — είτε εκτελείται τοπικά στον υπολογιστή σας είτε σε δικό σας διακομιστή. Ο ήχος δεν βγαίνει ποτέ από τους χώρους σας, δεν υπάρχει χρέωση ανά λεπτό και δεν υπάρχει όριο στον όγκο.

Για να προσθέσετε ένα, πατήστε **Προσθήκη** και δώστε:

- τη **διεύθυνση** του διακομιστή, έως και το `/v1`, για παράδειγμα `http://localhost:8000/v1` για τον ίδιο τον υπολογιστή ή `http://asr.local:8080/v1` για έναν διακομιστή στο δίκτυό σας·
- το όνομα του **μοντέλου** ακριβώς όπως το αναφέρει ο διακομιστής, για παράδειγμα `openai/whisper-large-v3-turbo`.

### Τι μπορεί να χρησιμοποιηθεί {#what-can-be-used}

Η συνηθισμένη επιλογή είναι το **Whisper**, το ανοιχτό μοντέλο αναγνώρισης ομιλίας της OpenAI. Η χρήση του είναι δωρεάν, καταλαβαίνει περίπου εκατό γλώσσες και διατίθεται σε διάφορα μεγέθη: ένα μικρό μοντέλο τρέχει σε έναν συνηθισμένο υπολογιστή, ενώ τα μεγάλα είναι αισθητά πιο ακριβή και καλό είναι να έχουν κάρτα γραφικών.

| Μοντέλο | Σημειώσεις |
| --- | --- |
| `whisper-large-v3` | Το πιο ακριβές Whisper. Για διακομιστή με GPU. |
| `openai/whisper-large-v3-turbo` | Μια ταχύτερη έκδοση του `large-v3` με μικρή απώλεια ακρίβειας. |
| `Systran/faster-whisper-large-v3` | Το `large-v3` μετατρεμμένο για τη μηχανή faster-whisper· ταχύτερο και ελαφρύτερο στη μνήμη. |
| `medium`, `small`, `base` | Μικρότερα μοντέλα Whisper, για υπολογιστή χωρίς κάρτα γραφικών. |

Το Whisper είναι το μοντέλο γύρω από το οποίο έχουν χτιστεί αυτοί οι διακομιστές. Μερικοί από αυτούς μπορούν να εξυπηρετήσουν και άλλα μοντέλα αναγνώρισης ομιλίας, όπως το NVIDIA Parakeet.

### Διακομιστές που προσφέρουν το API που είναι συμβατό με το OpenAI {#servers-that-offer-the-openai-compatible-api}

Το μοντέλο πρέπει να εκτελείται από έναν διακομιστή που προσφέρει το σημείο πρόσβασης `/v1/audio/transcriptions`, συμβατό με το OpenAI. Το προσφέρουν οι εξής:

| Διακομιστής | Τι είναι |
| --- | --- |
| [vLLM](https://docs.vllm.ai/en/latest/serving/online_serving/speech_to_text/) | Ένας διακομιστής μοντέλων υψηλών επιδόσεων. Εξυπηρετεί το Whisper στο `http://localhost:8000/v1` μόλις ξεκινήσει. |
| [Speaches](https://github.com/speaches-ai/speaches) | Ένας διακομιστής για μοντέλα ομιλίας, «το Ollama για την ομιλία», χτισμένος πάνω στο faster-whisper. Φορτώνει ένα μοντέλο την πρώτη φορά που του ζητείται. |
| [whisper.cpp](https://github.com/ggml-org/whisper.cpp) | Εκτελεί το Whisper αποδοτικά σε CPU, και σε Apple silicon. Ο `whisper-server` του ξεκινά με `--inference-path /v1/audio/transcriptions`. |
| [LocalAI](https://localai.io/) | Ένα άμεσο υποκατάστατο του OpenAI που εκτελεί τα μοντέλα τοπικά. |

Οποιοσδήποτε άλλος διακομιστής προσφέρει το ίδιο σημείο πρόσβασης λειτουργεί με τον ίδιο τρόπο. Αν ένας διακομιστής χρειάζεται κλειδί, εισαγάγετέ το όπως για μια υπηρεσία cloud.

Πριν βασιστείτε σε έναν διακομιστή, κάντε μια δοκιμαστική εγγραφή και δείτε την απομαγνητοφώνηση στο [παράθυρο Εγγραφές](/interface/recordings): μια συνομιλία σε γλώσσα που το μοντέλο γνωρίζει ελάχιστα το δείχνει αμέσως.
