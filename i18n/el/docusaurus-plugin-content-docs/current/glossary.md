---
title: Γλωσσάριο
sidebar_position: 99
description: Οι όροι της τηλεφωνίας IP και του AI Softphone που χρησιμοποιούνται σε αυτή την τεκμηρίωση, συγκεντρωμένοι σε ένα σημείο.
---

| Όρος | Σημασία |
| --- | --- |
| **Λογαριασμός** | Μια γραμμή: ένα όνομα χρήστη SIP σε ένα τηλεφωνικό κέντρο ή σε έναν πάροχο. Μπορείτε να είστε συνδεδεμένοι σε αρκετούς. Δείτε [Ρύθμιση λογαριασμού SIP](/sip-accounts/setup). |
| **BLF** (Busy Lamp Field) | Ένα κουμπί που καλεί ένα εσωτερικό και δείχνει με μια λυχνία αν είναι ελεύθερο, αν χτυπά ή αν είναι κατειλημμένο. Δείτε [Κουμπιά](/sip-accounts/buttons). |
| **Αναμονή κλήσης** | Τι κάνει το τηλέφωνο όταν κάποιος σας καλεί ενώ είστε ήδη σε κλήση. Δείτε [Ρυθμίσεις κλήσεων](/sip-accounts/calls#call-waiting). |
| **Καταγραφή** | Η εγγραφή μιας συνομιλίας που γίνεται σε άλλη εφαρμογή, όπως το Zoom, το Teams ή το Meet. Δείτε [Καταγραφή](/capture/). |
| **Κατηγορία** | Το θέμα μιας συνομιλίας· μία ανά συνομιλία. Δείτε [Λεξικά](/ai-processing/dictionaries). |
| **Κωδικοποιητής** | Ο τρόπος με τον οποίο κωδικοποιείται η φωνή για τη γραμμή. Το τηλέφωνο προσφέρει μια λίστα από αυτούς και το άλλο άκρο διαλέγει έναν. Δείτε [Ρυθμίσεις κλήσεων](/sip-accounts/calls#audio-formats). |
| **Διάσκεψη** | Κλήσεις που ενώθηκαν σε μία. |
| **CTI** | Ενοποίηση υπολογιστή και τηλεφωνίας: ένα πρόγραμμα στον υπολογιστή κάνει και παρακολουθεί κλήσεις. Δείτε [Τοπικό REST API](/integration/rest-api). |
| **DTMF** | Οι τόνοι του πληκτρολογίου, που στέλνονται κατά τη διάρκεια μιας κλήσης. |
| **Εσωτερικό** | Ο εσωτερικός αριθμός ενός ατόμου ή μιας συσκευής σε ένα τηλεφωνικό κέντρο. |
| **Τηλεφωνικό κέντρο IP** | Το τηλεφωνικό κέντρο ενός γραφείου, που λειτουργεί σε δίκτυο· λέγεται και softswitch. |
| **Γλωσσικό μοντέλο** | Η τεχνητή νοημοσύνη που διαβάζει μια απομαγνητοφώνηση και γράφει γι' αυτήν. Δείτε [Επεξεργασία](/ai-processing/processing). |
| **Οδηγία** | Αυτό που ζητείται από ένα γλωσσικό μοντέλο. Δείτε [Personal Prompt Studio](/ai-processing/prompt-studio). |
| **Αναγνωριστής** | Η υπηρεσία που μετατρέπει τον ήχο σε κείμενο (αναγνώριση ομιλίας). Δείτε [Απομαγνητοφώνηση](/ai-processing/transcription). |
| **Ένδειξη προσοχής** | Κάτι σε μια συνομιλία που χρειάζεται προσοχή, με την απόδειξη και τη χρονική στιγμή. Δείτε [Λεξικά](/ai-processing/dictionaries#red-flags). |
| **Καταχώριση** | Το τηλέφωνο λέει στο τηλεφωνικό κέντρο πού βρίσκεται, ώστε να το φτάνουν οι κλήσεις. Μια πράσινη κουκκίδα στον λογαριασμό σημαίνει ότι είναι καταχωρισμένος. |
| **Κανόνας** | Ένα βήμα που εκτελείται μόνο του, με σειρά, σε κάθε συνομιλία. Δείτε [Επεξεργασία](/ai-processing/processing#rules). |
| **SIP** | Το πρωτόκολλο με το οποίο τα τηλέφωνα και τα τηλεφωνικά κέντρα αποκαθιστούν κλήσεις. |
| **Ετικέτα** | Ένα σήμα· σε μία συνομιλία μπορεί να ισχύουν αρκετές. Δείτε [Λεξικά](/ai-processing/dictionaries#tags). |
| **Διακριτικό / μονάδα** | Δύο πράγματα: το **Διακριτικό** του τοπικού API, ένας κωδικός για άλλα προγράμματα· και οι μονάδες (tokens) που μετρά ένα γλωσσικό μοντέλο, η μονάδα μέτρησης του μηνιαίου **Ορίου μονάδων**. |
| **Απομαγνητοφώνηση** | Μια συνομιλία ως κείμενο, φράση προς φράση, σε συγχρονισμό με τον ήχο. |
| **Webhook** | Ένα αίτημα που στέλνει το τηλέφωνο σε άλλο σύστημα όταν μια κλήση ξεκινά, αλλάζει ή τελειώνει. Δείτε [Webhooks](/integration/webhooks). |
| **Ευρείας ζώνης** | Ένας κωδικοποιητής με ευρύτερο φάσμα ήχου από αυτό μιας τηλεφωνικής γραμμής, ώστε η φωνή να ακούγεται πιο καθαρά. |
