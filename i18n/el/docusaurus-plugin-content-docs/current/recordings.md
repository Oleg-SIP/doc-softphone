Οι **Ρυθμίσεις → Εγγραφή** αποφασίζουν ποιες κλήσεις γίνονται εγγραφές και για πόσο καιρό μένουν τα αρχεία. Μια κλήση που εγγράφηκε εμφανίζεται στο [παράθυρο Εγγραφές](/interface/recordings).

<Shot name="09_settings_recording" alt="Ρυθμίσεις → Εγγραφή" />

## Εγγραφή {#recording}

Η αναπτυσσόμενη λίστα επιλέγει ποιες κλήσεις εγγράφονται:

| Επιλογή | Εγγράφει |
| --- | --- |
| **Χειροκίνητα** | Μόνο όταν πατάτε εγγραφή στην κάρτα της κλήσης. Η προεπιλογή. |
| **Ρώτα σε κάθε κλήση** | Το τηλέφωνο ρωτά σε κάθε κλήση αν θα την εγγράψει. |
| **Κάθε κλήση** | Κάθε κλήση που απαντήθηκε, αυτόματα. Επιλεγμένο στην εικόνα. |
| **Επιλεγμένες γραμμές** | Τις κλήσεις στους λογαριασμούς που σημειώνετε στη λίστα που εμφανίζεται. |

Η εγγραφή ξεκινά όταν απαντηθεί η κλήση και ποτέ νωρίτερα, οπότε το κουδούνισμα και οι αριθμοί που πληκτρολογείτε δεν βρίσκονται στο αρχείο. Μια κλήση είναι ένα στερεοφωνικό αρχείο: εσείς στο ένα κανάλι και όλοι οι άλλοι στο άλλο.

## Συναίνεση {#consent}

Η αναπτυσσόμενη λίστα επιλέγει πώς ενημερώνεται ο συνομιλητής για την εγγραφή:

| Επιλογή | Τι ακούει ο συνομιλητής |
| --- | --- |
| **Μια ανακοίνωση** | Ένα σύντομο μήνυμα όταν ξεκινά η εγγραφή. Η προεπιλογή. Το **Επιλογή…** διαλέγει ένα δικό σας αρχείο ήχου· *αν δεν επιλεγεί τίποτα, το τηλέφωνο παίζει ένα σύντομο ηχητικό σήμα*. |
| **Ένας τόνος κάθε λίγα δευτερόλεπτα** | Ένα μπιπ σε διάστημα που ορίζετε με το ρυθμιστικό. |
| **Απολύτως τίποτα** | Τίποτα. Επιλεγμένο στην εικόνα. |

**Κράτα την ειδοποίηση μέσα στην εγγραφή** — η ανακοίνωση και ο τόνος παίζονται στους συμμετέχοντες της κλήσης· ενεργοποιήστε αυτή την επιλογή και θα βρίσκονται και στο αρχείο.

:::caution
Σε πολλά μέρη — στο μεγαλύτερο μέρος της Ευρώπης και σε αρκετές πολιτείες των ΗΠΑ — η εγγραφή μιας συνομιλίας χωρίς ενημέρωση του συνομιλητή είναι παράνομη. Η απόφαση είναι δική σας, και το πρόγραμμα το λέει κάτω από την αναπτυσσόμενη λίστα.
:::

## Διασκέψεις {#conferences}

**Ένα αρχείο για κάθε άτομο**, ενεργό από προεπιλογή. Σε μια διάσκεψη το δεύτερο κανάλι είναι μείξη όλων, οπότε ένα επιπλέον αρχείο ανά άτομο είναι αυτό που επιτρέπει σε μια απομαγνητοφώνηση να πει ποιος είπε τι.

## Διατήρηση {#retention}

<Shot name="09b_settings_recording_scrolled" alt="Ρυθμίσεις → Εγγραφή: διατήρηση" />

| Ρύθμιση | Προεπιλογή | Τι περιορίζει |
| --- | --- | --- |
| **Περίοδος διατήρησης** | Πάντα | Για πόσο καιρό φυλάσσεται μια εγγραφή. |
| **Όριο αποθήκευσης** | Χωρίς όριο | Πόσο χώρο επιτρέπεται να πιάνουν όλες οι εγγραφές μαζί. |
| **Αρχεία ανά άτομο** | Πάντα | Για πόσο καιρό φυλάσσονται τα επιπλέον αρχεία μιας διάσκεψης. |
| **Κατώφλι χώρου στον δίσκο** | 500 MB | Ένα κατώτατο όριο για τον ελεύθερο χώρο στον δίσκο. Οι εγγραφές που δεν έχετε καρφιτσώσει μπορούν να αφαιρεθούν ώστε ο χώρος να μένει πάνω από αυτό. |

Μια εγγραφή που έχετε καρφιτσώσει δεν διαγράφεται ποτέ από καμία από αυτές τις ρυθμίσεις, αλλά εξακολουθεί να μετράει στο όριο. Μία ώρα συνομιλίας πιάνει περίπου 30 MB.

Το μέρος του προγράμματος που εγγράφει τις κλήσεις, και ενημερώνει γι' αυτό τον συνομιλητή, μπορεί να απενεργοποιηθεί στις [Μονάδες](/application/modules).

Για να εγγράψετε μια συνάντηση που γίνεται σε άλλη εφαρμογή, δείτε την [Καταγραφή](/capture/).
