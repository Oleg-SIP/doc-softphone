title: Μονάδες
sidebar_position: 1
description: Τα μέρη από τα οποία αποτελείται το πρόγραμμα και πώς να απενεργοποιήσετε το καθένα.
---

Οι **Ρυθμίσεις → Μονάδες** παραθέτουν τα μέρη του προγράμματος. *Ό,τι κάνει αυτό το τηλέφωνο είναι ένα από αυτά.* Η απενεργοποίηση μιας μονάδας ισχύει αμέσως και αφήνει στη θέση τους όσα έχει ήδη αποθηκεύσει.

<Shot name="19_settings_modules" alt="Ρυθμίσεις → Μονάδες" />

Κάθε μονάδα έχει ένα πλαίσιο ελέγχου, ένα όνομα, μια γραμμή που λέει τι κάνει, και στα δεξιά την κατάστασή της — **Σε λειτουργία** για μια μονάδα που είναι ενεργή. Τα πλαίσια ελέγχου των δύο μονάδων από τις οποίες εξαρτώνται οι υπόλοιπες, της **Εφαρμογής** και της **Τοπικής βάσης δεδομένων**, είναι γκρι: δεν μπορούν να απενεργοποιηθούν.

<Shot name="19b_settings_modules_scrolled" alt="Ρυθμίσεις → Μονάδες: το υπόλοιπο της λίστας" />

| Μονάδα | Τι είναι |
| --- | --- |
| **Εφαρμογή** | Το κύριο παράθυρο, οι ρυθμίσεις, τα εικονίδια και ούτω καθεξής. |
| **Τοπική βάση δεδομένων** | Η βάση δεδομένων που χρησιμοποιείται ως τοπικός χώρος αποθήκευσης. |
| **Διεπαφή φυλλομετρητή** | Ορισμένες λειτουργίες σε έναν τοπικό φυλλομετρητή: οι σελίδες του [REST API](/integration/rest-api). |
| **Κουμπιά** | Τα [κουμπιά](/sip-accounts/buttons) δίπλα στο πεδίο κλήσης και οι λυχνίες τους. |
| **Καταγραφή** | Η [εγγραφή μιας συνομιλίας](/capture/) που γίνεται σε άλλη εφαρμογή. |
| **Διαγνωστικά** | Η καταγραφή SIP, τα στατιστικά πολυμέσων και οι μετρητές: [Διαγνωστικά](/troubleshooting/diagnostics). |
| **Λεξικά** | Κατηγορίες, ετικέτες και ενδείξεις προσοχής — οι κωδικοί στους οποίους παραπέμπουν όλα τα υπόλοιπα: [Λεξικά](/ai-processing/dictionaries). |
| **Κατάλογος** | Ο κατάλογος διευθύνσεων: [Επαφές](/interface/contacts-history). |
| **Ενσωμάτωση** | Το τοπικό API και τα webhooks: [Ενσωμάτωση](/integration/rest-api). |
| **Αποθήκη πολυμέσων** | Η βιβλιοθήκη των συνομιλιών και για πόσο καιρό φυλάσσονται: [Εγγραφές](/recordings/recordings-window). |
| **Επεξεργασία** | Οι οδηγίες και οι κανόνες που τις ενεργοποιούν: [Επεξεργασία](/ai-processing/processing). |
| **Εγγραφή** | Η εγγραφή κλήσεων και η ενημέρωση του συνομιλητή γι' αυτήν: [Εγγραφή κλήσεων](/recordings/call-recording). |
| **Τηλεφωνία** | Το SIP, οι λογαριασμοί, οι κλήσεις, το πεδίο κλήσης και το ιστορικό κλήσεων. |
| **Απομαγνητοφώνηση** | Οι αναγνωριστές, η ουρά που τους τροφοδοτεί και οι απομαγνητοφωνήσεις που παράγουν: [Απομαγνητοφώνηση](/ai-processing/transcription). |

Απενεργοποιήστε μια μονάδα και εξαφανίζεται: καμία ρύθμιση γι' αυτήν, καμία επιλογή στο μενού, τίποτα από αυτήν σε λειτουργία. Απενεργοποιήστε μια μονάδα που δεν σας χρειάζεται — για παράδειγμα την **Ενσωμάτωση** σε έναν υπολογιστή όπου τίποτα άλλο δεν επικοινωνεί με το τηλέφωνο — ή κρατήστε ένα τηλέφωνο που είναι μόνο τηλέφωνο, όπου αυτό είναι το μόνο που χρειάζεται ένα γραφείο. Το πακέτο είναι το ίδιο και στις δύο περιπτώσεις: δεν υπάρχει τίποτα να αγοράσετε και τίποτα να ξεκλειδώσετε.
