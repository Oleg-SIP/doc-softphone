Οι **Ρυθμίσεις** ανοίγουν ως καρτέλα στα δεξιά του τηλεφώνου, με μια λίστα καρτελών ρυθμίσεων στην αριστερή άκρη. Η λίστα χωρίζεται σε ομάδες με διαχωριστικές γραμμές: η **Επισκόπηση** μόνη της, μετά η τηλεφωνία, η τεχνητή νοημοσύνη, το ίδιο το πρόγραμμα και τέλος οι **Μονάδες** και η καρτέλα **Σχετικά**.

## Επισκόπηση {#overview}

<Shot name="04_settings_overview" alt="Ρυθμίσεις → Επισκόπηση: η λίστα ελέγχου με όσα έχουν ρυθμιστεί" />

Η **Επισκόπηση** είναι μια λίστα ελέγχου με όσα χρειάζονται για να αξιοποιήσετε στο έπακρο το πρόγραμμα. Στο πάνω μέρος μετρά τα βήματα — στην εικόνα *10 βήματα έγιναν* με πράσινη κουκκίδα και *απομένουν 8 βήματα* με κόκκινη — και μια μπάρα δείχνει το μέρος που έχει γίνει. Κάθε βήμα είναι μια γραμμή με μια κουκκίδα: πράσινη για βήμα που έγινε, κόκκινη για βήμα που απομένει.

*Πατήστε μια γραμμή για να διαβάσετε σε τι χρησιμεύει και να ανοίξετε εκεί όπου ρυθμίζεται.* Το βέλος στη δεξιά άκρη της γραμμής την αναπτύσσει.

| Ομάδα | Βήματα |
| --- | --- |
| **Κλήσεις** | Προσθήκη λογαριασμού· Πραγματοποίηση κλήσης· Απάντηση κλήσης· Καταγραφή κλήσης |
| **Σύλληψη από άλλες εφαρμογές** | Ενεργοποίηση σύλληψης· Σύλληψη μιας συνομιλίας· Δώστε της ένα όνομα |
| **Απομαγνητοφώνηση** | Προσθήκη αναγνωριστή· Απομαγνητοφώνηση συνομιλίας |
| **Επεξεργασία** | Προσθήκη μοντέλου· Επεξεργασία απομαγνητοφώνησης |
| **Εγγραφές** | Αναζήτηση σε όσα ειπώθηκαν· Εξαγωγή εγγραφής· Εξαγωγή περίληψης |
| **Εφαρμογή** | Εκκίνηση μαζί με τον υπολογιστή· Κρατήστε το ενημερωμένο |
| **Σχόλια** | Αποστολή της εκτεταμένης αναφοράς· Πείτε μας τη γνώμη σας |

<Shot name="04b_settings_overview_scrolled" alt="Το υπόλοιπο της λίστας ελέγχου Επισκόπηση" />

Τα βήματα είναι οδηγός, όχι υποχρέωση: ένα βήμα που δεν σας χρειάζεται μπορεί να μείνει κόκκινο.
