**Контакти** та **Історія** відкриваються як дві вкладки праворуч від телефона, тож номер можна знайти просто під час розмови.

## Контакти {#contacts}

<Shot name="03_contacts" alt="Вкладка Контакти" />

- **Пошук** фільтрує список, поки ви вводите текст.
- **Додати** створює контакт.
- Кожен контакт показано з ім'ям, а під ним — номер і обліковий запис, через який контакту дзвонять, наприклад *231 · 201 Офіс*.

Вхідний виклик зі знайомого номера показує ім'я контакту, так само як і списки нещодавніх викликів та журнал викликів, — так працює визначення абонента.

### Редагування контакту {#editing-a-contact}

<Shot name="03b_contact_edit" alt="Контакт, відкритий для редагування" />

Виберіть контакт, і праворуч у його рядку з'являться олівець і слухавка. Слухавка дзвонить контакту; олівець відкриває форму під рядком:

| Поле | Що вводити |
| --- | --- |
| **Назва** | Як показувати контакт. |
| **Номер** | Номер, який набирати. |
| Розкривний список під **Номер** | Обліковий запис, через який контакту дзвонять. |

**Зберегти** зберігає зміни, **Скасувати** відкидає їх, а **Видалити** вилучає контакт.

## Історія {#history}

<Shot name="21_history" alt="Вкладка Історія" />

Журнал викликів, від найновіших. Угорі:

- розкривний список, типово **Усі виклики**, звужує список до одного виду викликів;
- **Пошук** фільтрує за тим, що ви введете.

Кожен запис має значок виду виклику — вихідна слухавка або червона слухавка з годинником для пропущеного виклику, — ім'я іншої сторони (або номер), а під ним дату, чим закінчився виклик, його тривалість, номер і обліковий запис. Нещодавні виклики показано як *Учора, 22:33* або з днем тижня, давніші — з датою.

| Чим закінчився виклик | Як показано |
| --- | --- |
| Ви поговорили | **вихідний** або вхідний і тривалість, наприклад *48 с* |
| Вхідний виклик залишився без відповіді | **Пропущений** |
| Здійснений вами виклик не з'єднався | **Не пройшов** |

Виберіть запис, і праворуч від нього з'являться чотири кнопки:

| Кнопка | Що робить |
| --- | --- |
| Людина з плюсом | Додає номер до [Контактів](#contacts). |
| ▶ | Відтворює запис виклику, якщо його записано. |
| Кошик | Видаляє запис. |
| Слухавка | Передзвонює на номер. |

### Як довго зберігається журнал {#how-long-the-log-is-kept}

Журнал викликів — це доказ, тому з нього нічого не вилучається, доки ви цього не скажете: типово зберігається кожен виклик. Строк зберігання і кнопка **Очистити історію викликів** містяться в [Налаштуваннях викликів](../sip-accounts/calls.md#history).

Пропущені та відхилені виклики можна також прочитати через [локальний REST API](../integration/rest-api.md) (`/history?missed=true`, `/history?declined=true`).
