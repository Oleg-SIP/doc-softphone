**Налаштування** відкриваються як вкладка праворуч від телефона, зі списком вкладок налаштувань уздовж лівого краю. Список поділено на групи лініями: окремо **Огляд**, далі телефонія, ШІ, сама програма і наостанок **Модулі** та **Про програму**.

## Огляд {#overview}

<Shot name="04_settings_overview" alt="Налаштування → Огляд: контрольний список того, що вже налаштовано" />

**Огляд** — це контрольний список того, що потрібно, аби отримати від програми найбільше. Угорі він рахує кроки — на малюнку *10 кроків зроблено* із зеленою крапкою і *лишилося 8 кроків* із червоною, — а смуга показує виконану частку. Кожен крок — це рядок із крапкою: зеленою для виконаного кроку, червоною для того, що лишився.

*Натисніть на рядок, щоб прочитати, навіщо він, і відкрити, де це налаштовується.* Стрілка на правому краю рядка розгортає його.

| Група | Кроки |
| --- | --- |
| **Виклики** | Додати обліковий запис; Зателефонувати; Відповісти на виклик; Записати дзвінок |
| **Перехоплення з інших програм** | Увімкнути перехоплення; Перехопити розмову; Дати запису ім’я |
| **Розшифровка** | Додати розпізнавач; Розшифрувати розмову |
| **Обробка** | Додати модель; Обробити стенограму |
| **Записи** | Пошук у сказаному; Вивантажити запис; Вивантажити підсумок |
| **Програма** | Запускати разом з комп’ютером; Тримати в актуальному стані |
| **Відгук** | Надсилати розширений звіт; Розкажіть нам враження |

<Shot name="04b_settings_overview_scrolled" alt="Решта контрольного списку Огляд" />

Кроки — це орієнтир, а не обов'язок: крок, який вам не потрібен, може лишатися червоним.
