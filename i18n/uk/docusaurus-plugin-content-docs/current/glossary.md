---
title: Глосарій
sidebar_position: 99
description: Терміни IP-телефонії та AI Softphone, що вживаються в цій документації, в одному місці.
---

| Термін | Значення |
| --- | --- |
| **Обліковий запис** | Лінія: ім'я користувача SIP на АТС або в оператора. Можна бути підключеним до кількох одночасно. Див. [Налаштування SIP-облікового запису](/sip-accounts/setup). |
| **BLF** (Busy Lamp Field) | Кнопка, яка набирає внутрішній номер і лампочкою показує, чи він вільний, чи дзвонить, чи зайнятий. Див. [Кнопки](/sip-accounts/buttons). |
| **Очікування виклику** | Що робить телефон, коли хтось дзвонить, а ви вже розмовляєте. Див. [Налаштування викликів](/sip-accounts/calls#call-waiting). |
| **Захоплення** | Запис розмови, що відбувається в іншій програмі, як-от Zoom, Teams чи Meet. Див. [Захоплення](/capture/). |
| **Категорія** | Про що була розмова; одна на розмову. Див. [Довідники](/ai-processing/dictionaries). |
| **Кодек** | Спосіб кодування голосу для передавання лінією. Телефон пропонує їх перелік, а інша сторона вибирає один. Див. [Налаштування викликів](/sip-accounts/calls#audio-formats). |
| **Конференція** | Кілька викликів, об'єднаних в один. |
| **CTI** | Інтеграція комп'ютера й телефонії: програма на комп'ютері здійснює виклики і стежить за ними. Див. [Локальний REST API](/integration/rest-api). |
| **DTMF** | Тони клавіатури, що надсилаються під час виклику. |
| **Внутрішній номер** | Внутрішній номер людини або пристрою на АТС. |
| **IP-АТС** | Телефонна станція офісу, що працює в мережі; її ще називають softswitch. |
| **Мовна модель** | ШІ, який читає розшифровку і пише про неї. Див. [Обробка](/ai-processing/processing). |
| **Вказівка** | Те, про що просять мовну модель. Див. [Personal Prompt Studio](/ai-processing/prompt-studio). |
| **Розпізнавач** | Служба, яка перетворює звук на текст (розпізнавання мовлення). Див. [Розшифровка](/ai-processing/transcription). |
| **Червоний прапорець** | Те в розмові, що потребує уваги, з доказом і часом. Див. [Довідники](/ai-processing/dictionaries#red-flags). |
| **Реєстрація** | Телефон повідомляє АТС, де він є, щоб виклики могли до нього дійти. Зелена крапка біля облікового запису означає, що його зареєстровано. |
| **Правило** | Крок, що виконується сам, по черзі, для кожної розмови. Див. [Обробка](/ai-processing/processing#rules). |
| **SIP** | Протокол, яким телефони й АТС встановлюють виклики. |
| **Мітка** | Позначка; до однієї розмови може пасувати кілька. Див. [Довідники](/ai-processing/dictionaries#tags). |
| **Токен** | Дві речі: **Токен** локального API — пароль для інших програм; і токени, які рахує мовна модель, — одиниця місячної **Межі токенів**. |
| **Розшифровка** | Розмова у вигляді тексту, репліка за реплікою, синхронно зі звуком. |
| **Вебхук** | Запит, який телефон надсилає іншій системі, коли виклик починається, змінюється або закінчується. Див. [Вебхуки](/integration/webhooks). |
| **Широкосмуговий** | Кодек із ширшим діапазоном звуку, ніж має телефонна лінія, тож голос звучить чіткіше. |
