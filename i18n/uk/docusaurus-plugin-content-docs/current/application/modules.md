---

**Налаштування → Модулі** наводять частини програми. *Усе, що робить цей телефон, — це один із них.* Вимкнення набуває чинності одразу і лишає збережене там, де воно є.

<Shot name="19_settings_modules" alt="Налаштування → Модулі" />

Кожен модуль має прапорець, назву, рядок про те, що він робить, а праворуч — свій стан: **Працює** для ввімкненого модуля. Прапорці двох модулів, від яких залежать решта, — **Програма** і **Локальна база даних** — сірі: їх не можна вимкнути.

<Shot name="19b_settings_modules_scrolled" alt="Налаштування → Модулі: решта списку" />

| Модуль | Що це |
| --- | --- |
| **Програма** | Головне вікно, налаштування, значки тощо. |
| **Локальна база даних** | База даних, що слугує локальним сховищем. |
| **Інтерфейс браузера** | Деякі можливості в локальному браузері: сторінки [REST API](/integration/rest-api). |
| **Кнопки** | [Кнопки](/sip-accounts/buttons) поруч із набирачем і лампочки на них. |
| **Захоплення** | [Запис розмови](/capture/), що відбувається в іншій програмі. |
| **Діагностика** | Трасування SIP, статистика медіа і лічильники: [Діагностика](/troubleshooting/diagnostics). |
| **Довідники** | Категорії, мітки й червоні прапорці — коди, на які посилається все інше: [Довідники](/ai-processing/dictionaries). |
| **Довідник** | Адресна книга: [Контакти](/interface/contacts-history). |
| **Інтеграція** | Локальний API і вебхуки: [Інтеграція](/integration/rest-api). |
| **Медіасховище** | Бібліотека розмов і як довго вони зберігаються: [Записи](/interface/recordings). |
| **Обробка** | Вказівки і правила, які їх запускають: [Обробка](/ai-processing/processing). |
| **Запис** | Запис викликів і повідомлення про це іншої сторони: [Запис викликів](/recordings/call-recording). |
| **Телефонія** | SIP, облікові записи, виклики, набирач та історія викликів. |
| **Розшифровка** | Розпізнавачі, черга, що ними керує, і розшифровки, які вони створюють: [Розшифровка](/ai-processing/transcription). |

Вимкніть модуль — і його немає: ні налаштувань для нього, ні пункту меню, нічого з нього не працює. Вимкніть модуль, який вам не потрібен, — наприклад, **Інтеграція** на комп'ютері, де ніщо інше не звертається до телефона, — або тримайте телефон, який є лише телефоном, якщо робочому місцю більше нічого й не треба. Пакунок однаковий у будь-якому разі: нічого не треба купувати і нічого розблоковувати.
