**Налаштування → Розшифровка** — це список розпізнавачів: сервісів, які перетворюють звук на текст, для завершених розмов і, для [суфлера](../interface/prompter.md), під час розмови.

<Shot name="25_transcription" alt="Налаштування → Розшифровка: п’ять розпізнавачів" />

Розмова розшифровується, коли ви просите про це у [вікні записів](/interface/recordings), або сама, якщо в розділі [Обробка](/ai-processing/processing) увімкнено **Обробляти розмови автоматично**. Розпізнавач на вашій власній машині нічого не коштує; хмарний бере плату за хвилину звуку.

## Розпізнавачі {#recognisers}
Розпізнавач — це сервіс розпізнавання мовлення, якому телефон надсилає звук. **Додати** додає новий; кнопка **Перевірити** в його картці перевіряє, що сервіс справді відповідає. Кожен показано у списку з назвою, а під нею — модель і адреса його сервісу. На зображенні їх п’ять:

| Назва | Модель | Адреса |
| --- | --- | --- |
| **X.ai** | *(порожньо: типова модель сервісу)* | `https://api.x.ai/v1` |
| **ElevenLabs** | `scribe_v2` | `https://api.elevenlabs.io/v1` |
| **Deepgram** | `nova-2` | `https://api.deepgram.com/v1` |
| **OpenAI** | `gpt-4o-transcribe` | `https://api.openai.com/v1/` |
| **Vosk** | *(немає)* | `ws://localhost:2700`, сервер на цьому комп’ютері |

Два значки праворуч у рядку показують, для чого розпізнавач типовий. Годинник світиться біля типового **для розшифровок** — на зображенні це **X.ai**: його використовують, коли ви не обрали іншого. Блискавка світиться біля типового **для суфлера** — на зображенні це **Vosk**. Розпізнавачів можна мати кілька; випадний список над розшифровкою у [вікні записів](/interface/recordings#transcript-or-write-up-the-drop-down) показує розшифровки, зроблені кожним із них.

## Картка розпізнавача {#the-recognisers-card}
Натискання на розпізнавач відкриває його картку.

<Shot name="43_recogniser_card" alt="Картка розпізнавача X.ai: вид, дві адреси, ключ, «Перевірити» і типові значення" />

| Поле | Що це |
| --- | --- |
| **Назва** | Ім’я у списках. |
| **Вид** | Вид сервісу, від якого залежить, як телефон із ним розмовляє: **Сумісний з OpenAI (Whisper, OpenAI)**, **Deepgram**, **ElevenLabs (Scribe)**, **xAI (Grok)**, **AssemblyAI**, **Soniox**, **Speechmatics** і три, що працюють на вашій власній машині, — **Vosk**, **WhisperLive** і **NVIDIA Riva**. **Yandex SpeechKit** пропонується, коли в розділі [Про програму](../application/about.md) обрано країну Росію або одну з її сусідок. |
| **Адреса для розшифровок** | Куди надсилаються завершені розмови. |
| **Адреса для суфлера** | Куди йде живий звук під час розмови. *Порожнє визначається з адреси поруч*, як `wss://api.x.ai` на зображенні. |
| **Ключ** | Ключ сервісу. *Зберігається у сховищі ключів цього комп’ютера, ніколи у файлі налаштувань.* |
| **Перевірити** | Запитує сервіс і повідомляє, що він відповів, наприклад *Відповів і пропонує 3 моделі*. |
| **Модель для розшифровок** і **Модель для суфлера** | Модель — точно так, як її називає сервіс. *Порожнє не надсилає назви моделі*, і сервіс бере свою типову; якщо постачальник її публікує, картка її називає. Для виду, у якого вибору немає, поле не показується. |
| **Типовий для розшифровок** | Робить цей розпізнавач тим, який використовують, коли ви не обрали іншого. |
| **Типовий для суфлера** | Робить цей розпізнавач тим, яким слухає новий помічник суфлера. |
| **Увімкнено** | Вимкнений розпізнавач лишається у списку, але не використовується. |

**Додаткові налаштування** розкривають решту картки. Найважливіше в них:

<Shot name="43b_recogniser_advanced" alt="Додаткові налаштування розпізнавача: межі, як нарізаються репліки, мова" />

| Поле | Що робить |
| --- | --- |
| **Регіон** | Регіон сервісу, якщо їх у нього кілька. |
| **Надсилати дві сторони окремо** | Дзвінок записується так, що двоє співрозмовників лежать у двох каналах, — саме з цього розпізнавач розуміє, хто що сказав. Вимкніть для сервера, який заявляє, що вміє це, а насправді не вміє. |
| **Просити, хто говорить** | Розрізняє людей усередині одного каналу, якщо в ньому говорять кілька осіб. |
| **Писати числа цифрами** | Суми, дати й номери телефонів приходять записаними цифрами, а не словами. |
| **Межа вивантаження**, **Межа тривалості** | Найбільший файл у байтах і найдовший запис у секундах, які надішле телефон. |
| **Запитів водночас** | Скільки запитів може виконуватися одночасно. |
| **Завершувати репліку через**, **Склеювати короткі репліки в межах**, **Проміжок між репліками** | Для суфлера: скільки часу без нових слів завершує репліку, скільки коротка репліка чекає на наступну, щоб склеїтися з нею, і яка тиша завершує чергу мовця, якщо розпізнавач сам її не позначає. У мілісекундах. |
| **Мова** | Дволітерний код мови за ISO 639-1 (`en`, `de`, `es`, `fr`, `sr`…). Залиште порожнім — розпізнавач вирішить сам; це правильно, якщо тільки ваші розмови не йдуть мовою, яку він постійно плутає. |
| **Додаткове** | Параметри виду `name = value`, по одному в рядку, — передаються сервісу як є. Залиште порожнім, якщо сервер нічого такого не описує. |
| **Очікування, хвилини** | Скільки чекати розшифровку. Порожнє — очікування рахується за тривалістю запису. |
| **Ціна за хвилину** | Скільки коштує хвилина живого звуку — з прайс-листа сервісу. Суфлер показує, скільки коштував сеанс, і зупиняється на своїй [місячній межі](prompter.md#spending). |

## Живе розпізнавання для суфлера {#live-recognition-for-the-prompter}
[Суфлеру](../interface/prompter.md) потрібен розпізнавач, який слухає, поки людина говорить, — потоком, а не готовим файлом. Це вміють такі види: **Deepgram**, **ElevenLabs (Scribe)**, **xAI (Grok)**, **Сумісний з OpenAI** (з живою розшифровкою OpenAI), **AssemblyAI**, **Soniox** і **Speechmatics** у хмарі, **Yandex SpeechKit** там, де він пропонується, і **Vosk**, **WhisperLive** та **NVIDIA Riva** на вашій власній машині. Розпізнавач на вашій власній машині залишає голос співрозмовника всередині й нічого не коштує.

Щоб ним скористатися, відкрийте його картку, перевірте **Адреса для суфлера** (або залиште її визначатися), оберіть **Модель для суфлера**, якщо сервіс пропонує кілька, — живі моделі часто відрізняються від моделей для файлів, наприклад `scribe_v2_realtime` в ElevenLabs, — і натисніть **Перевірити**. Позначте **Типовий для суфлера**, щоб нові помічники слухали саме ним.

Що варто знати до вибору:

- **Розшифровки чи суфлер.** Модель для живого мовлення не приймає готовий файл, а більшість моделей для файлів не вміє слухати наживо. Тому в картці два поля — **Модель для розшифровок** і **Модель для суфлера**.
- **Розмір файлу.** OpenAI приймає файли до 25 МБ, X.ai — до 500 МБ. Довга розмова може виявитися більшою, ніж приймає хмарний сервіс.
- **Ціна.** Хмарні сервіси беруть плату за хвилину звуку, тарифи залежать від моделі й змінюються; дивіться їх на сторінці сервісу, перш ніж перемикатися. Розпізнавач на вашій власній машині нічого не коштує.
- **Мови.** У кожного сервісу свій список; перевірте свій і вкажіть код у полі **Мова** в додаткових налаштуваннях розпізнавача, якщо він вгадує неправильно.

Список моделей сервісів змінюється часто. Якщо потрібної моделі тут немає, актуальний список — у документації сервісу: [OpenAI](https://developers.openai.com/api/docs/guides/speech-to-text), [Deepgram](https://developers.deepgram.com/docs/models-languages-overview), [ElevenLabs](https://elevenlabs.io/docs/capabilities/speech-to-text), [Speechmatics](https://docs.speechmatics.com/speech-to-text/models), [X.ai](https://docs.x.ai/developers/model-capabilities/audio/speech-to-text), [Soniox](https://soniox.com/docs/stt/models), [AssemblyAI](https://www.assemblyai.com/docs/getting-started/models), [Yandex SpeechKit](https://yandex.cloud/en/docs/speechkit/stt/models), [Vosk](https://alphacephei.com/vosk/models), [WhisperLive](https://github.com/collabora/WhisperLive), [NVIDIA Riva](https://docs.nvidia.com/deeplearning/riva/user-guide/docs/asr/asr-overview.html); **Модель** — це назва точно так, як її дає сервіс.

## Ваші власні моделі {#your-own-models}

Розпізнавач не мусить бути хмарною службою. Телефон може використовувати **будь-яку модель, яку обслуговують через API, сумісний з OpenAI**, — інтерфейс `POST /v1/audio/transcriptions`, — хоч би вона працювала локально на вашому комп'ютері, хоч на вашому власному сервері. Звук ніколи не залишає ваших приміщень, за хвилини нічого не платиться, і обсяг нічим не обмежений.

Щоб додати таку модель, натисніть **Додати** і вкажіть:

- **адресу** сервера аж до `/v1` включно, наприклад `http://localhost:8000/v1` для самого комп'ютера або `http://asr.local:8080/v1` для сервера у вашій мережі;
- назву **моделі** точно так, як її наводить сервер, наприклад `openai/whisper-large-v3-turbo`.

### Що можна використати {#what-can-be-used}

Звичний вибір — **Whisper**, відкрита модель розпізнавання мовлення від OpenAI. Вона безкоштовна, розуміє близько сотні мов і буває кількох розмірів: мала модель працює на звичайному комп'ютері, великі помітно точніші, і для них найкраще мати відеокарту.

| Модель | Примітки |
| --- | --- |
| `whisper-large-v3` | Найточніший Whisper. Для сервера з GPU. |
| `openai/whisper-large-v3-turbo` | Швидша версія `large-v3` з невеликою втратою точності. |
| `Systran/faster-whisper-large-v3` | `large-v3`, перетворена для рушія faster-whisper; швидша й ощадливіша щодо пам'яті. |
| `medium`, `small`, `base` | Менші моделі Whisper, для комп'ютера без відеокарти. |

Саме навколо Whisper побудовано ці сервери. Деякі з них можуть обслуговувати й інші моделі розпізнавання мовлення, як-от NVIDIA Parakeet.

### Сервери, що пропонують API, сумісний з OpenAI {#servers-that-offer-the-openai-compatible-api}

Модель має запускати сервер, який пропонує сумісну з OpenAI кінцеву точку `/v1/audio/transcriptions`. Ось такі сервери:

| Сервер | Що це |
| --- | --- |
| [vLLM](https://docs.vllm.ai/en/latest/serving/online_serving/speech_to_text/) | Високопродуктивний сервер моделей. Після запуску обслуговує Whisper за адресою `http://localhost:8000/v1`. |
| [Speaches](https://github.com/speaches-ai/speaches) | Сервер для мовленнєвих моделей, «Ollama для мовлення», побудований на faster-whisper. Завантажує модель, коли її вперше запитують. |
| [whisper.cpp](https://github.com/ggml-org/whisper.cpp) | Ефективно запускає Whisper на CPU, зокрема на Apple silicon. Його `whisper-server` запускають з `--inference-path /v1/audio/transcriptions`. |
| [LocalAI](https://localai.io/) | Пряма заміна OpenAI, що запускає моделі локально. |

Будь-який інший сервер, що пропонує ту саму кінцеву точку, працює так само. Якщо серверу потрібен ключ, введіть його, як для хмарної служби.

Перш ніж покладатися на сервер, зробіть пробний запис і подивіться на розшифровку у [вікні Записи](/interface/recordings): розмова мовою, яку модель знає погано, одразу це покаже.
