**Налаштування → Розшифровка** визначають, як звук стає текстом: якою мовою і яким розпізнавачем.

<Shot name="25_transcription" alt="Налаштування → Розшифровка: мова і чотири розпізнавачі" />

Розмову розшифровують, коли ви про це попросите у [вікні Записи](/recordings/recordings-window), або самі собою, якщо в розділі [Обробка](/ai-processing/processing) увімкнено **Обробляти розмови автоматично**. Розпізнавач на вашому власному комп'ютері нічого не коштує в роботі; хмарний бере плату за хвилину звуку.

## Мова {#language}

**Мова** — це двобуквений код мови за ISO 639-1 (`en`, `de`, `es`, `fr`, `sr`…). Залиште поле порожнім, і розпізнавач вирішить сам, — це правильно, якщо тільки ваші виклики не ведуться мовою, яку він постійно недочуває.

## Розпізнавачі {#recognisers}

Розпізнавач — це служба перетворення мовлення на текст, якій телефон надсилає звук. Натисніть **Додати**, щоб додати розпізнавач; кнопка **Перевірити** у формі перевіряє, що служба справді відповідає. Кожен розпізнавач наведено з назвою, а під нею — модель і адреса його служби. На малюнку їх чотири:

| Назва | Модель | Адреса |
| --- | --- | --- |
| **X.ai** | *(порожньо: типова модель служби)* | `https://api.x.ai/v1` |
| **ElevenLabs** | `scribe_v2` | `https://api.elevenlabs.io/v1` |
| **Deepgram** | `nova-2` | `https://api.deepgram.com/v1` |
| **OpenAI** | `gpt-4o-transcribe` | `https://api.openai.com/v1/` |

Той, що позначений **Типовий** праворуч у своєму рядку (на малюнку — **X.ai**), використовується, коли ви не вибираєте іншого. Можна тримати кілька. Розкривний список над розшифровкою у [вікні Записи](/recordings/recordings-window#the-transcript-and-the-write-up) показує розшифровки, зроблені кожним розпізнавачем.

Модель можна залишити порожньою. Тоді служба використовує власну типову модель.

## Яку модель вибрати {#which-model-to-choose}

Таблиця наводить моделі перетворення мовлення на текст чотирьох служб із малюнка. **Жирним** виділено моделі, налаштовані на малюнку. Для розпізнавача X.ai модель порожня, тому використовується типова модель служби — **`grok-voice-transcribe-2.0`**.

| Служба та адреса | Модель | Для чого вона |
| --- | --- | --- |
| **OpenAI**<br />`https://api.openai.com/v1` | `gpt-transcribe` | Модель, яку OpenAI рекомендує для записаного мовлення його оригінальною мовою. |
| | **`gpt-4o-transcribe`** | Розшифровка загального призначення. |
| | `gpt-4o-mini-transcribe` | Легший і дешевший варіант попередньої. |
| | `gpt-4o-transcribe-diarize` | Позначає, хто коли говорить. Використовуйте її, лише якщо це вам потрібно. |
| | `whisper-1` | Старіша модель Whisper, збережена для особливих застосувань, як-от часові мітки слів і субтитри. |
| **ElevenLabs**<br />`https://api.elevenlabs.io/v1` | **`scribe_v2`** | Розшифровка загального призначення понад 90 мовами, з розділенням мовців. |
| | `scribe_v2_medical` | Те саме, налаштоване на клінічні записи. |
| | `scribe_v1` | Перше покоління; застаріла, використовуйте `scribe_v2`. |
| **Deepgram**<br />`https://api.deepgram.com/v1` | `nova-3` | Найкраща модель Deepgram загального призначення — для зустрічей, шумних і багатомовних записів. |
| | **`nova-2`** | Попереднє покоління; залиште її для мов, яких `nova-3` ще не підтримує. |
| | `enhanced` | Старіший рівень із меншою кількістю помилок, ніж `base`. |
| | `base` | Найстаріший рівень, для великих обсягів. |
| | `whisper` | Whisper, який запускає Deepgram. |
| **X.ai**<br />`https://api.x.ai/v1` | **`grok-voice-transcribe-2.0`** | Типова модель; 25 мов. |
| | `grok-voice-transcribe-1.0` | Застаріла: служба перенаправляє її на `2.0`. |

Що варто знати, перш ніж вибирати:

- **Розмір файлу.** OpenAI приймає файли до 25 МБ; X.ai — до 500 МБ. Довга розмова може бути більшою, ніж приймає хмарна служба.
- **Ціна.** Хмарні служби беруть плату за хвилину звуку, а тарифи залежать від моделі й змінюються; перш ніж переходити, прочитайте їх на сторінці самої служби.
- **Мови.** Кожна служба має власний перелік; перевірте свій і задайте код [Мова](#language), якщо розпізнавач помиляється у здогадах.
- **Моделі реального часу**, як-от `scribe_v2_realtime` або `flux` від Deepgram, створено для живих потоків, і їх немає в таблиці: телефон розшифровує готові записи.

Перелік моделей служби часто змінюється. Якщо потрібної моделі тут немає, актуальний перелік є в документації самої служби — [OpenAI](https://developers.openai.com/api/docs/guides/speech-to-text), [ElevenLabs](https://elevenlabs.io/docs/capabilities/speech-to-text), [Deepgram](https://developers.deepgram.com/docs/models-languages-overview), [X.ai](https://docs.x.ai/developers/model-capabilities/audio/speech-to-text), — а **Модель** — це назва точно в тому вигляді, у якому її подає служба.

## Ваші власні моделі {#your-own-models}

Розпізнавач не мусить бути хмарною службою. Телефон може використовувати **будь-яку модель, яку обслуговують через API, сумісний з OpenAI**, — інтерфейс `POST /v1/audio/transcriptions`, — хоч би вона працювала локально на вашому комп'ютері, хоч на вашому власному сервері. Звук ніколи не залишає ваших приміщень, за хвилини нічого не платиться, і обсяг нічим не обмежений.

Щоб додати таку модель, натисніть **Додати** і вкажіть:

- **адресу** сервера аж до `/v1` включно, наприклад `http://localhost:8000/v1` для самого комп'ютера або `http://asr.local:8080/v1` для сервера у вашій мережі;
- назву **моделі** точно так, як її наводить сервер, наприклад `openai/whisper-large-v3-turbo`.

### Що можна використати {#what-can-be-used}

Звичний вибір — **Whisper**, відкрита модель розпізнавання мовлення від OpenAI. Вона безкоштовна, розуміє близько сотні мов і буває кількох розмірів: мала модель працює на звичайному комп'ютері, великі помітно точніші, і для них найкраще мати відеокарту.

| Модель | Примітки |
| --- | --- |
| `whisper-large-v3` | Найточніший Whisper. Для сервера з GPU. |
| `openai/whisper-large-v3-turbo` | Швидша версія `large-v3` з невеликою втратою точності. |
| `Systran/faster-whisper-large-v3` | `large-v3`, перетворена для рушія faster-whisper; швидша й ощадливіша щодо пам'яті. |
| `medium`, `small`, `base` | Менші моделі Whisper, для комп'ютера без відеокарти. |

Саме навколо Whisper побудовано ці сервери. Деякі з них можуть обслуговувати й інші моделі розпізнавання мовлення, як-от NVIDIA Parakeet.

### Сервери, що пропонують API, сумісний з OpenAI {#servers-that-offer-the-openai-compatible-api}

Модель має запускати сервер, який пропонує сумісну з OpenAI кінцеву точку `/v1/audio/transcriptions`. Ось такі сервери:

| Сервер | Що це |
| --- | --- |
| [vLLM](https://docs.vllm.ai/en/latest/serving/online_serving/speech_to_text/) | Високопродуктивний сервер моделей. Після запуску обслуговує Whisper за адресою `http://localhost:8000/v1`. |
| [Speaches](https://github.com/speaches-ai/speaches) | Сервер для мовленнєвих моделей, «Ollama для мовлення», побудований на faster-whisper. Завантажує модель, коли її вперше запитують. |
| [whisper.cpp](https://github.com/ggml-org/whisper.cpp) | Ефективно запускає Whisper на CPU, зокрема на Apple silicon. Його `whisper-server` запускають з `--inference-path /v1/audio/transcriptions`. |
| [LocalAI](https://localai.io/) | Пряма заміна OpenAI, що запускає моделі локально. |

Будь-який інший сервер, що пропонує ту саму кінцеву точку, працює так само. Якщо серверу потрібен ключ, введіть його, як для хмарної служби.

Перш ніж покладатися на сервер, зробіть пробний запис і подивіться на розшифровку у [вікні Записи](/recordings/recordings-window): розмова мовою, яку модель знає погано, одразу це покаже.
