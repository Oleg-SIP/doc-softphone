**Réglages → Modules** liste les parties du programme. *Tout ce que fait ce téléphone est l'un d'eux.* En désactiver un prend effet aussitôt et laisse en place ce qu'il a déjà enregistré.

<Shot name="19_settings_modules" alt="Réglages → Modules" />

Chaque module a une case, un nom, une ligne qui dit ce qu'il fait, et à droite son état — **En marche** pour un module activé. Les cases des deux modules dont dépend tout le reste, **Application** et **Base locale**, sont grises : ils ne peuvent pas être désactivés.

<Shot name="19b_settings_modules_scrolled" alt="Réglages → Modules : la suite de la liste" />

| Module | Ce que c'est |
| --- | --- |
| **Application** | La fenêtre principale, les réglages, les icônes, etc. |
| **Base locale** | La base de données utilisée comme stockage local. |
| **Interface navigateur** | Certaines fonctions dans un navigateur local : les pages de l'[API REST](/integration/rest-api). |
| **Boutons** | Les [boutons](/sip-accounts/buttons) à côté du numéroteur, et leurs voyants. |
| **Capture** | [L'enregistrement d'une conversation](/capture/) qui se tient dans une autre application. |
| **Diagnostic** | La trace SIP, les statistiques média et les compteurs : [Diagnostic](/troubleshooting/diagnostics). |
| **Dictionnaires** | Catégories, étiquettes et signaux — les codes auxquels tout le reste renvoie : [Dictionnaires](/ai-processing/dictionaries). |
| **Annuaire** | Le carnet d'adresses : [Contacts](/interface/contacts-history). |
| **Intégration** | L'API locale, et les webhooks : [Intégration](/integration/rest-api). |
| **Stockage média** | La bibliothèque des conversations et leur durée de conservation : [Enregistrements](/recordings/recordings-window). |
| **Traitement** | Les invites et les règles qui les déclenchent : [Traitement](/ai-processing/processing). |
| **Enregistrement** | L'enregistrement des appels, et l'information du correspondant : [Enregistrer les appels](/recordings/call-recording). |
| **Téléphonie** | SIP, comptes, appels, numéroteur et journal des appels. |
| **Transcription** | Les reconnaissances, la file qui les alimente et les transcriptions qu'elles produisent : [Transcription](/ai-processing/transcription). |

Désactivez un module et il disparaît : plus de réglages pour lui, plus d'entrée de menu, plus rien de lui ne tourne. Désactivez un module dont vous n'avez pas l'usage — par exemple **Intégration** sur un ordinateur où rien d'autre ne parle au téléphone — ou gardez un téléphone qui n'est qu'un téléphone, quand c'est tout ce dont un poste de travail a besoin. Le paquet est le même dans tous les cas : il n'y a rien à acheter ni rien à débloquer.
