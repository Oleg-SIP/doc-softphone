**Réglages → Démarrage** décide comment le programme démarre, ce que fait la fermeture de sa fenêtre, et ce qui se passe quand vous cliquez sur un numéro de téléphone dans un autre programme.

<Shot name="15_settings_startup" alt="Réglages → Démarrage" />

## Démarrage automatique {#autostart}

| Réglage | Par défaut | Ce qu'il fait |
| --- | --- | --- |
| **Démarrer le téléphone à l'ouverture de session** | désactivé | Démarre le programme avec votre session, pour qu'il prenne les appels dès que vous vous installez. |
| **Démarrer réduit, sans fenêtre** | désactivé | Le démarre sans afficher de fenêtre. Disponible uniquement avec le réglage ci-dessus. |

## Fermeture {#close}

**Laisser le téléphone tourner quand la fenêtre est fermée**, activé par défaut. Une fenêtre fermée n'est pas un téléphone raccroché : les appels arrivent toujours, et l'icône de la zone de notification (la barre des menus sous macOS) fait revenir la fenêtre. Désactivez ce réglage et fermer la fenêtre quitte le programme.

## Liens d'appel {#call-links}

Un lien qui commence par `tel:`, `callto:` ou `sip:` — un numéro de téléphone sur une page web, dans un e-mail ou dans un CRM — peut être ouvert par ce programme.

- **Ouvrir les liens d’appel avec ce téléphone** fait du programme celui qui les ouvre. Le bouton est gris quand c'est déjà le cas.
- **Appeler tout de suite, sans appuyer sur Appeler** — désactivé par défaut. Un numéro cliqué arrive dans le numéroteur et y attend ; activez ce réglage pour l'appeler dès son arrivée.
