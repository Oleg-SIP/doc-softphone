**Réglages → Apparence** change l'aspect du programme et l'emplacement de ses fenêtres.

<Shot name="14_settings_appearance" alt="Réglages → Apparence" />

## Disposition {#layout}

Six agencements, chacun dessiné sous forme de petite image ; celui qui est sélectionné est encadré.

| Disposition | |
| --- | --- |
| **Deux fenêtres** | Le téléphone dans une fenêtre, tout le reste dans une autre. |
| **Plusieurs fenêtres** | Le téléphone, et une fenêtre propre à chacune des autres sections. |
| **Compact** | Un petit téléphone, et une fenêtre à côté. |
| **Une fenêtre** | Le téléphone et tout le reste dans une seule fenêtre. C'est la disposition utilisée dans les captures d'écran de cette documentation. |
| **Barre de bord** | Le téléphone sous forme de barre le long du bord de l'écran, avec une fenêtre en dessous. |
| **Icône seule** | Aucune fenêtre tant que vous ne l'appelez pas depuis la zone de notification, ou avec le [raccourci](/program/shortcuts). |

Chaque agencement contient les mêmes fenêtres ; ce qui change, c'est leur emplacement. **Le téléphone se ferme et se rouvre pour en changer** — avec le bouton **Appliquer et redémarrer le téléphone**.

## Langue {#language}

La liste déroulante choisit la langue de l'interface ; **Comme cet ordinateur** est la valeur par défaut. Cela ne concerne que l'interface. La langue parlée lors d'un appel est un réglage distinct, et elle arrive avec les transcriptions — voir [Transcription](/ai-processing/transcription#language).

Les invites, les règles et les dictionnaires livrés avec le programme restent dans leur langue quand vous en changez. **Rétablir les valeurs par défaut** dans [Traitement](/ai-processing/processing#defaults) et dans [Dictionnaires](/ai-processing/dictionaries#defaults) les fait passer dans la nouvelle.

## Thème {#theme}

La liste déroulante choisit clair ou sombre ; **Comme cet ordinateur** est la valeur par défaut. La langue et le thème prennent effet tous deux immédiatement, pendant un appel comme en dehors.

## Icônes {#icons}

Deux listes déroulantes règlent les images des boutons d'appel : la première le style (**Plein** sur l'image), la seconde la taille (**Normale**). C'est une affaire de goût : les deux graisses sont les mêmes dessins, et la taille change la grandeur à laquelle ils sont dessinés plutôt que le dessin utilisé.
