---

**Seaded → Moodulid** loetleb programmi osad. *Kõik, mida see telefon teeb, on üks neist.* Ühe väljalülitamine mõjub kohe ja jätab paigale selle, mis ta on juba salvestanud.

<Shot name="19_settings_modules" alt="Seaded → Moodulid" />

Igal moodulil on märkeruut, nimi, rida selle kohta, mida see teeb, ja paremal selle olek — **Töötab** sisselülitatud mooduli puhul. Nende kahe mooduli, millest ülejäänud sõltuvad, **Rakendus** ja **Kohalik andmebaas**, märkeruudud on hallid: neid ei saa välja lülitada.

<Shot name="19b_settings_modules_scrolled" alt="Seaded → Moodulid: loendi ülejäänud osa" />

| Moodul | Mis see on |
| --- | --- |
| **Rakendus** | Peaaken, seaded, ikoonid ja nii edasi. |
| **Kohalik andmebaas** | Kohaliku hoidlana kasutatav andmebaas. |
| **Brauseriliides** | Mõned funktsioonid kohalikus brauseris: [REST API](/integration/rest-api) lehed. |
| **Nupud** | Valija kõrval olevad [nupud](/sip-accounts/buttons) ja nende tuled. |
| **Hõivamine** | Teises rakenduses toimuva [vestluse salvestamine](/capture/). |
| **Diagnostika** | SIP-jälg, meediastatistika ja loendurid: [Diagnostika](/troubleshooting/diagnostics). |
| **Sõnastikud** | Kategooriad, sildid ja hoiatussignaalid — koodid, millele kõik muu viitab: [Sõnastikud](/ai-processing/dictionaries). |
| **Kataloog** | Aadressiraamat: [Kontaktid](/interface/contacts-history). |
| **Sidumine** | Kohalik API ja veebikonksud: [Sidumine](/integration/rest-api). |
| **Meediahoidla** | Vestluste teek ja nende säilitamise aeg: [Salvestised](/interface/recordings). |
| **Töötlemine** | Juhised ja neid käivitavad reeglid: [Töötlemine](/ai-processing/processing). |
| **Salvestamine** | Kõnede salvestamine ja sellest teisele osapoolele teatamine: [Kõnede salvestamine](/recordings/call-recording). |
| **Telefonia** | SIP, kontod, kõned, valija ja kõnede ajalugu. |
| **Ülestähendus** | Tuvastajad, neid käitav järjekord ja nende tehtud ülestähendused: [Ülestähendus](/ai-processing/transcription). |

Lülitage moodul välja ja see on kadunud: pole selle seadeid, menüükirjet ega midagi sellest töötamas. Lülitage välja moodul, mida te ei vaja — näiteks **Sidumine** arvutis, kus miski muu telefoniga ei suhtle —, või jätke alles telefon, mis on ainult telefon, kui töökoht muud ei vaja. Pakett on mõlemal juhul sama: pole midagi osta ega midagi avada.
