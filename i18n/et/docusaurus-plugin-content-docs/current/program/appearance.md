**Seaded → Välimus** muudab programmi välimust ja seda, kus selle aknad asuvad.

<Shot name="14_settings_appearance" alt="Seaded → Välimus" />

## Paigutus {#layout}

Kuus paigutust, igaüks joonistatud väikese pildina; valitul on raam.

| Paigutus | |
| --- | --- |
| **Kaks akent** | Telefon ühes aknas, kõik muu teises. |
| **Mitu akent** | Telefon ja iga muu jaotise jaoks oma aken. |
| **Kompaktne** | Väike telefon ja aken selle kõrval. |
| **Üks aken** | Telefon ja kõik muu ühes aknas. See on paigutus, mida kasutatakse selle dokumentatsiooni ekraanipiltidel. |
| **Servariba** | Telefon ribana ekraani servas ja aken selle all. |
| **Ainult salv** | Aknaid pole, kuni te selle salvest või [otseteega](/program/shortcuts) esile kutsute. |

Igas paigutuses on samad aknad; erinev on ainult nende asukoht. **Telefon sulgub ja avaneb uuesti, et paigutust muuta** — nupuga **Rakenda ja käivita telefon uuesti**.

## Keel {#language}

Ripploend valib kasutajaliidese keele; vaikimisi on **Nagu see arvuti**. See puudutab ainult kasutajaliidest. Keel, milles kõnes räägitakse, on eraldi seade ja see tuleb koos ülestähendustega — vaadake [Ülestähendus](/ai-processing/transcription#the-recognisers-card).

Programmiga kaasa tulnud juhised, reeglid ja sõnastikud jäävad keele vahetamisel oma keelde. **Taasta vaikeväärtused** jaotistes [Töötlemine](/ai-processing/processing#defaults) ja [Sõnastikud](/ai-processing/dictionaries#defaults) toob need uude keelde.

## Teema {#theme}

Ripploend valib heleda või tumeda; vaikimisi on **Nagu see arvuti**. Keel ja teema jõustuvad mõlemad kohe, nii kõne ajal kui ka väljaspool seda.

## Ikoonid {#icons}

Kaks ripploendit määravad kõnenuppude pildid: esimene stiili (pildil **Täidetud**), teine suuruse (**Tavaline**). See on maitse asi: mõlemad joonepaksused on samad joonistused ja suurus muudab seda, kui suurelt neid joonistatakse, mitte seda, millist joonistust kasutatakse.
