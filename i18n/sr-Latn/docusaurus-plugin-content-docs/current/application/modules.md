**Podešavanja → Moduli** navodi delove programa. *Sve što ovaj telefon radi jeste jedan od njih.* Isključivanje važi odmah i ostavlja ono što je već sačuvano tamo gde jeste.

<Shot name="19_settings_modules" alt="Podešavanja → Moduli" />

Svaki modul ima polje za potvrdu, naziv, red o tome šta radi, a desno svoje stanje — **Radi** za uključen modul. Polja za potvrdu dva modula od kojih ostali zavise, **Aplikacija** i **Lokalna baza podataka**, siva su: ne mogu da se isključe.

<Shot name="19b_settings_modules_scrolled" alt="Podešavanja → Moduli: ostatak spiska" />

| Modul | Šta je |
| --- | --- |
| **Aplikacija** | Glavni prozor, podešavanja, ikone i tako dalje. |
| **Lokalna baza podataka** | Baza podataka koja se koristi kao lokalno skladište. |
| **Sučelje u pregledaču** | Neke funkcije u lokalnom pregledaču: stranice [REST API-ja](/integration/rest-api). |
| **Dugmad** | [Dugmad](/sip-accounts/buttons) pored polja za biranje i lampice na njima. |
| **Hvatanje** | [Snimanje razgovora](/capture/) koji teče u drugoj aplikaciji. |
| **Dijagnostika** | SIP trag, statistika medija i brojači: [Dijagnostika](/troubleshooting/diagnostics). |
| **Rečnici** | Kategorije, oznake i upozorenja — kodovi na koje pokazuje sve ostalo: [Rečnici](/ai-processing/dictionaries). |
| **Imenik** | Adresar: [Kontakti](/interface/contacts-history). |
| **Povezivanje** | Lokalni API i veb-kuke: [Povezivanje](/integration/rest-api). |
| **Skladište zapisa** | Biblioteka razgovora i koliko se dugo čuvaju: [Snimci](/recordings/recordings-window). |
| **Obrada** | Uputstva i pravila koja ih okidaju: [Obrada](/ai-processing/processing). |
| **Snimanje** | Snimanje poziva i obaveštavanje druge strane o tome: [Snimanje poziva](/recordings/call-recording). |
| **Telefonija** | SIP, nalozi, pozivi, polje za biranje i istorija poziva. |
| **Prepisivanje** | Prepoznavači, red koji ih pokreće i prepisi koje prave: [Prepisivanje](/ai-processing/transcription). |

Isključite modul i nema ga: nema podešavanja za njega, nema stavke menija, ništa od njega ne radi. Isključite modul koji vam ne treba — na primer **Povezivanje** na računaru gde ništa drugo ne razgovara sa telefonom — ili zadržite telefon koji je samo telefon, ako je to sve što radnom mestu treba. Paket je u oba slučaja isti: nema šta da se kupi ni otključa.
