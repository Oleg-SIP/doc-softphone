**Ustawienia → Skróty** wymienia skróty klawiszowe telefonu.

<Shot name="16_settings_shortcuts" alt="Ustawienia → Skróty klawiszowe" />

| Czynność | Skrót w macOS | **Wszędzie** |
| --- | --- | --- |
| **Odbierz połączenie** | ⌃⌥A | wyłączone |
| **Rozłącz** | ⌃⌥E | wyłączone |
| **Zawieś lub wznów** | ⌃⌥H | wyłączone |
| **Wycisz mikrofon** | ⌃⌥M | wyłączone |
| **Pokaż lub ukryj telefon** | ⌃⌥S | włączone |

(⌃ to Control, a ⌥ to Option.)

## Zmiana skrótu {#changing-a-shortcut}

Kliknij skrót i naciśnij nową kombinację. Ponowne kliknięcie lub naciśnięcie Escape go czyści.

**Wszędzie** to pole wyboru obok każdego skrótu. Wyłączone — skrót działa, gdy telefon jest programem, którego używasz. Włączone — działa z każdego programu: *zabiera kombinację reszcie pulpitu*, więc inne programy już jej nie dostają. Tylko **Pokaż lub ukryj telefon** jest domyślnie globalny, bo musi przywołać telefon, gdziekolwiek jesteś.

**Przywróć domyślne** przywraca wszystkie pięć.
