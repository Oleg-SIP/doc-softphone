---

**Ustawienia → Moduły** wymienia części programu. *Wszystko, co ten telefon robi, to jeden z nich.* Wyłączenie jednego działa od razu i zostawia to, co już zapisał, na miejscu.

<Shot name="19_settings_modules" alt="Ustawienia → Moduły" />

Każdy moduł ma pole wyboru, nazwę, wiersz o tym, co robi, a po prawej swój stan — **Działa** dla modułu włączonego. Pola wyboru dwóch modułów, od których zależą pozostałe, **Aplikacja** i **Lokalna baza danych**, są szare: nie można ich wyłączyć.

<Shot name="19b_settings_modules_scrolled" alt="Ustawienia → Moduły: reszta listy" />

| Moduł | Co to jest |
| --- | --- |
| **Aplikacja** | Okno główne, ustawienia, ikony i tak dalej. |
| **Lokalna baza danych** | Baza danych używana jako lokalny magazyn. |
| **Interfejs przeglądarki** | Niektóre funkcje w lokalnej przeglądarce: strony [REST API](/integration/rest-api). |
| **Przyciski** | [Przyciski](/sip-accounts/buttons) obok pola wybierania i ich lampki. |
| **Przechwytywanie** | [Nagrywanie rozmowy](/capture/) toczącej się w innej aplikacji. |
| **Diagnostyka** | Śledzenie SIP, statystyki mediów i liczniki: [Diagnostyka](/troubleshooting/diagnostics). |
| **Słowniki** | Kategorie, etykiety i sygnały ostrzegawcze — kody, na które wskazuje wszystko inne: [Słowniki](/ai-processing/dictionaries). |
| **Katalog** | Książka adresowa: [Kontakty](/interface/contacts-history). |
| **Integracja** | Lokalne API i webhooki: [Integracja](/integration/rest-api). |
| **Magazyn mediów** | Biblioteka rozmów i jak długo są przechowywane: [Nagrania](/interface/recordings). |
| **Przetwarzanie** | Polecenia i reguły, które je uruchamiają: [Przetwarzanie](/ai-processing/processing). |
| **Nagrywanie** | Nagrywanie połączeń i informowanie o tym drugiej strony: [Nagrywanie połączeń](/recordings/call-recording). |
| **Telefonia** | SIP, konta, połączenia, pole wybierania i historia połączeń. |
| **Transkrypcja** | Rozpoznawacze, kolejka, która je napędza, i transkrypcje, które tworzą: [Transkrypcja](/ai-processing/transcription). |

Wyłącz moduł, a zniknie: żadnych jego ustawień, żadnej pozycji w menu, nic z niego nie działa. Wyłącz moduł, który nie jest ci potrzebny — na przykład **Integracja** na komputerze, na którym nic innego nie rozmawia z telefonem — albo zostaw telefon, który jest tylko telefonem, jeśli to wszystko, czego potrzebuje stanowisko. Pakiet jest w obu przypadkach ten sam: nie ma nic do kupienia ani do odblokowania.
