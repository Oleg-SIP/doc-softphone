---
title: Słowniczek
sidebar_position: 99
description: Pojęcia telefonii IP i AI Softphone używane w tej dokumentacji, zebrane w jednym miejscu.
---

| Pojęcie | Znaczenie |
| --- | --- |
| **Konto** | Linia: nazwa użytkownika SIP w centrali lub u operatora. Możesz być zalogowany na kilku. Zobacz [Konfigurowanie konta SIP](/sip-accounts/setup). |
| **Pomocnik** | To, czym sufler ma być, gdy słucha: napisami, tłumaczeniem albo podpowiedziami, co powiedzieć. Zobacz [Ustawienia suflera](/ai-processing/prompter#assistants). |
| **BLF** (Busy Lamp Field) | Przycisk, który wybiera numer wewnętrzny i lampką pokazuje, czy jest wolny, dzwoni, czy jest zajęty. Zobacz [Przyciski](/sip-accounts/buttons). |
| **Połączenie oczekujące** | To, co robi telefon, gdy ktoś dzwoni, kiedy już rozmawiasz. Zobacz [Ustawienia połączeń](/sip-accounts/calls#call-waiting). |
| **Przechwytywanie** | Nagrywanie rozmowy prowadzonej w innej aplikacji, takiej jak Zoom, Teams czy Meet. Zobacz [Przechwytywanie](/capture/). |
| **Kategoria** | O czym była rozmowa; jedna na rozmowę. Zobacz [Słowniki](/ai-processing/dictionaries). |
| **Kodek** | Sposób kodowania głosu na potrzeby linii. Telefon oferuje ich listę, a druga strona wybiera jeden. Zobacz [Ustawienia połączeń](/sip-accounts/calls#audio-formats). |
| **Konferencja** | Połączenia złączone w jedno. |
| **CTI** | Integracja telefonii z komputerem: program na komputerze, który wykonuje i obserwuje połączenia. Zobacz [Lokalne REST API](/integration/rest-api). |
| **DTMF** | Tony klawiatury wysyłane podczas rozmowy. |
| **Numer wewnętrzny** | Wewnętrzny numer osoby lub urządzenia w centrali. |
| **Centrala IP** | Centrala telefoniczna biura działająca w sieci; nazywana też softswitchem. |
| **Model językowy** | SI, która czyta transkrypcję i pisze o niej. Zobacz [Przetwarzanie](/ai-processing/processing). |
| **Polecenie** | To, o co prosi się model językowy (ang. prompt). Zobacz [Personal Prompt Studio](/ai-processing/prompt-studio). |
| **Sufler** | Okno, które podczas połączenia pokazuje to, co się mówi, w chwili gdy się to mówi, oraz podpowiedzi, co odpowiedzieć. Zobacz [Okno suflera](/interface/prompter). |
| **Rozpoznawacz** | Usługa, która zamienia dźwięk w tekst (rozpoznawanie mowy). Zobacz [Transkrypcja](/ai-processing/transcription). |
| **Sygnał ostrzegawczy** | Coś w rozmowie, co wymaga uwagi, wraz z dowodem i momentem. Zobacz [Słowniki](/ai-processing/dictionaries#red-flags). |
| **Próba** | Odtworzenie suflerowi nagranej rozmowy zamiast połączenia, żeby wypróbować pomocnika. Zobacz [Okno suflera](/interface/prompter#rehearsing-on-a-recording). |
| **Rejestracja** | Telefon informuje centralę, gdzie się znajduje, aby docierały do niego połączenia. Zielona kropka przy koncie oznacza, że jest zarejestrowane. |
| **Reguła** | Krok, który działa sam, po kolei, przy każdej rozmowie. Zobacz [Przetwarzanie](/ai-processing/processing#rules). |
| **SIP** | Protokół, którego telefony i centrale używają do zestawiania połączeń. |
| **Etykieta** | Oznaczenie; do jednej rozmowy może pasować kilka. Zobacz [Słowniki](/ai-processing/dictionaries#tags). |
| **Token** | Dwie rzeczy: **Token** lokalnego API, czyli hasło dla innych programów; oraz tokeny liczone przez model językowy, jednostka **Granica tokenów, miesięcznie**. |
| **Transkrypcja** | Rozmowa w postaci tekstu, wypowiedź po wypowiedzi, zsynchronizowana z dźwiękiem. |
| **Webhook** | Żądanie, które telefon wysyła do innego systemu, gdy połączenie się zaczyna, zmienia lub kończy. Zobacz [Webhooki](/integration/webhooks). |
| **Szerokopasmowy** | Kodek o szerszym zakresie dźwięku niż linia telefoniczna, dzięki czemu głos jest wyraźniejszy. |
