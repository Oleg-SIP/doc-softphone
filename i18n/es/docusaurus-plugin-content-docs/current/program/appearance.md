**Ajustes → Apariencia** cambia el aspecto del programa y dónde se colocan sus ventanas.

<Shot name="14_settings_appearance" alt="Ajustes → Apariencia" />

## Disposición {#layout}

Seis disposiciones, cada una dibujada como una pequeña imagen; la seleccionada tiene un marco.

| Disposición | |
| --- | --- |
| **Dos ventanas** | El teléfono en una ventana, todo lo demás en otra. |
| **Varias ventanas** | El teléfono, y una ventana propia para cada una de las demás secciones. |
| **Compacto** | Un teléfono pequeño, y una ventana a su lado. |
| **Una ventana** | El teléfono y todo lo demás en una sola ventana. Es la disposición usada en las capturas de pantalla de esta documentación. |
| **Barra lateral** | El teléfono como una barra a lo largo del borde de la pantalla, con una ventana debajo. |
| **Solo el icono** | Ninguna ventana hasta que la llame desde la bandeja, o con el [atajo](/program/shortcuts). |

Todas las disposiciones contienen las mismas ventanas; lo que cambia es dónde se colocan. **El teléfono se cierra y se vuelve a abrir para cambiarla** — con el botón **Aplicar y reiniciar el teléfono**.

## Idioma {#language}

El desplegable elige el idioma de la interfaz; **Como este ordenador** es el valor por defecto. Es solo la interfaz. El idioma en que se habla en una llamada es un ajuste aparte, y llega con las transcripciones — consulte [Transcripción](/ai-processing/transcription#language).

Las instrucciones, las reglas y los diccionarios que vienen con el programa se quedan en su idioma cuando cambia. **Restaurar los valores por defecto** en [Procesamiento](/ai-processing/processing#defaults) y en [Diccionarios](/ai-processing/dictionaries#defaults) los pasa al nuevo.

## Tema {#theme}

El desplegable elige claro u oscuro; **Como este ordenador** es el valor por defecto. El idioma y el tema surten efecto al momento, tanto durante una llamada como fuera de ella.

## Iconos {#icons}

Dos desplegables ajustan los dibujos de los botones de llamada: el primero el estilo (**Relleno** en la imagen), el segundo el tamaño (**Normal**). Es cuestión de gustos: los dos grosores son los mismos dibujos, y el tamaño cambia lo grandes que se dibujan, no qué dibujo se usa.
