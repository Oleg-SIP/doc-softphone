**Ajustes** se abre como una pestaña a la derecha del teléfono, con una lista de las pestañas de ajustes en su borde izquierdo. La lista está en grupos separados por líneas: el **Resumen general** solo, luego la telefonía, la IA, el propio programa y, por último, **Módulos** y **Acerca de**.

## Resumen general {#overview}

<Shot name="04_settings_overview" alt="Ajustes → Resumen general: la lista de comprobación de lo que está configurado" />

El **Resumen general** es una lista de comprobación de lo necesario para sacar el máximo partido al programa. Arriba cuenta los pasos — en la imagen *10 pasos hechos* con un punto verde y *quedan 8 pasos* con uno rojo — y una barra muestra la parte hecha. Cada paso es una línea con un punto: verde para un paso hecho, rojo para uno pendiente.

*Pulse una línea para leer para qué sirve y abrir donde se configura.* La flecha al final de la línea la despliega.

| Grupo | Pasos |
| --- | --- |
| **Llamadas** | Añadir una cuenta; Hacer una llamada; Contestar una llamada; Grabar una llamada |
| **Captura de otras aplicaciones** | Activar la captura; Capturar una conversación; Poner nombre a una captura |
| **Transcripción** | Añadir un reconocedor; Transcribir una conversación |
| **Procesamiento** | Añadir un modelo; Procesar una transcripción |
| **Grabaciones** | Buscar en lo que se dijo; Exportar una grabación; Exportar un resumen |
| **Aplicación** | Arrancar con el ordenador; Mantenerlo al día |
| **Comentarios** | Enviar el informe ampliado; Díganos qué le parece |

<Shot name="04b_settings_overview_scrolled" alt="El resto de la lista de comprobación Resumen general" />

Los pasos son una guía, no una obligación: un paso que no le sirva puede quedarse en rojo.
