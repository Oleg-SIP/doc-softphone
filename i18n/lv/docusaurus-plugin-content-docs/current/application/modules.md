---

**Iestatījumi → Moduļi** uzskaita programmas daļas. *Viss, ko šis telefons dara, ir viens no tiem.* Viena izslēgšana stājas spēkā uzreiz un atstāj vietā to, ko tas jau ir saglabājis.

<Shot name="19_settings_modules" alt="Iestatījumi → Moduļi" />

Katram modulim ir izvēles rūtiņa, nosaukums, rinda par to, ko tas dara, un labajā pusē tā stāvoklis — **Darbojas** ieslēgtam modulim. Abu moduļu, no kuriem atkarīgi pārējie, **Lietotne** un **Vietējā datubāze**, izvēles rūtiņas ir pelēkas: tos nevar izslēgt.

<Shot name="19b_settings_modules_scrolled" alt="Iestatījumi → Moduļi: saraksta atlikusī daļa" />

| Modulis | Kas tas ir |
| --- | --- |
| **Lietotne** | Galvenais logs, iestatījumi, ikonas un tā tālāk. |
| **Vietējā datubāze** | Datubāze, ko izmanto kā vietējo krātuvi. |
| **Pārlūka saskarne** | Dažas funkcijas vietējā pārlūkā: [REST API](/integration/rest-api) lapas. |
| **Pogas** | [Pogas](/sip-accounts/buttons) blakus numura sastādītājam un to lampiņas. |
| **Tveršana** | Citā lietotnē notiekošas [sarunas ierakstīšana](/capture/). |
| **Diagnostika** | SIP izsekošana, mediju statistika un skaitītāji: [Diagnostika](/troubleshooting/diagnostics). |
| **Vārdnīcas** | Kategorijas, birkas un brīdinājuma signāli — kodi, uz kuriem norāda viss pārējais: [Vārdnīcas](/ai-processing/dictionaries). |
| **Katalogs** | Adrešu grāmata: [Kontakti](/interface/contacts-history). |
| **Integrācija** | Vietējais API un tīmekļa āķi: [Integrācija](/integration/rest-api). |
| **Mediju krātuve** | Sarunu bibliotēka un to glabāšanas ilgums: [Ieraksti](/interface/recordings). |
| **Apstrāde** | Norādījumi un kārtulas, kas tos palaiž: [Apstrāde](/ai-processing/processing). |
| **Ierakstīšana** | Zvanu ierakstīšana un paziņošana par to otrai pusei: [Zvanu ierakstīšana](/recordings/call-recording). |
| **Telefonija** | SIP, konti, zvani, numura sastādītājs un zvanu vēsture. |
| **Pieraksts** | Atpazinēji, rinda, kas tos darbina, un to veidotie atšifrējumi: [Pieraksts](/ai-processing/transcription). |

Izslēdziet moduli, un tā vairs nav: nav tā iestatījumu, nav izvēlnes ieraksta, nekas no tā nedarbojas. Izslēdziet moduli, kas jums nav vajadzīgs — piemēram, **Integrācija** datorā, kurā nekas cits ar tālruni nesazinās —, vai paturiet tālruni, kas ir tikai tālrunis, ja darba vietai vairāk nekā nevajag. Pakotne abos gadījumos ir tā pati: nav nekā, ko pirkt, un nekā, ko atbloķēt.
